# 模板库 (04-Templates)

标准化模板文件，用于快速创建新项目、任务、话题、项目规则。

## 模板分类

| 模板 | 用途 |
|------|------|
| [project/](./project/) | 项目五文件模板（WORKSPACE / STATE / ACTIONS / CONTEXT / REFERENCES） |
| [project-rules-template.md](./project-rules-template.md) | PROJECT-RULES.md 项目规则模板 |

## 使用方式

### 新建项目
从 `project/` 目录复制五个标准文件到新项目目录，按实际修改。

### 新建项目规则
复制 `project-rules-template.md` 到项目根目录，重命名为 `PROJECT-RULES.md`，按实际填写。

### 新建任务/话题
使用对应模板文件创建。
