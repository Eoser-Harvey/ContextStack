# 嵌入式AI岗位市场调研报告（2026年5月）

## 一、核心结论（先说结论）

**嵌入式AI岗位需求量大、薪资高、缺口明显，是2026年最紧缺的技术方向之一。**

你的转型方向完全正确，当前学习计划覆盖了约 **60%** 的市场需求，但存在 **4个关键缺口** 需要补充。

## 四、技能要求：企业到底要什么？

### 4.1 硬性门槛（几乎所有JD都要求的）

| 技能 | 要求程度 | 你目前状态 |
|------|---------|-----------|
| **C/C++ 精通** | 必须 | ✅ 已有 |
| **Python 熟练** | 必须 | ⚠️ 需要加强 |
| **至少一种推理框架** | 必须 | ⚠️ 学习中（TFLM） |
| **模型量化（INT8/FP16）** | 必须 | ⚠️ 计划中有 |
| **模型压缩（剪枝/蒸馏）** | 必须 | ❌ 计划中缺失 |
| **Embedded Linux** | 必须 | ⚠️ 需要加强 |
| **ARM架构理解** | 必须 | ✅ 已有 |

### 4.2 高频推理框架要求（从JD中统计）

| 框架 | 出现频率 | 适用场景 |
|------|---------|----------|
| **TensorRT** | 极高 | NVIDIA Jetson/GPU |
| **ONNX Runtime** | 极高 | 跨平台通用 |
| **TensorFlow Lite / TFLM** | 高 | MCU/低功耗 |
| **NCNN** | 高 | 国产替代、ARM |
| **RKNN（瑞芯微）** | 高 | 瑞芯微平台 |
| **MNN** | 中 | 阿里系、端侧 |
| **OpenVINO** | 中 | Intel平台 |
| **SNPE/QNN（高通）** | 中 | 高通平台 |

### 4.3 高频硬件平台要求

| 平台 | 出现频率 | 备注 |
|------|---------|------|
| **NVIDIA Jetson (Orin/Xavier/Nano)** | 极高 | 机器人、自动驾驶首选 |
| **瑞芯微 RK系列 (RK3588/RK3566等)** | 极高 | 国产替代主流 |
| **STM32/ARM Cortex-M** | 高 | MCU级别AI |
| **高通骁龙** | 中 | 手机/高端IoT |
| **华为海思** | 中 | 国产化需求 |
| **地平线** | 中 | 自动驾驶 |
| **ESP32** | 中低 | IoT入门 |

### 4.4 加分项（决定薪资上限的）

| 技能 | 价值 |
|------|------|
| **CUDA编程** | 薪资+30%~50% |
| **端侧大模型（LLM）部署** | 最新风口，极度稀缺 |
| **自定义算子开发** | 芯片原厂必备 |
| **多传感器融合** | 机器人/自动驾驶必备 |
| **端云协同架构** | AIoT架构师方向 |
| **RISC-V架构** | 新兴方向 |

## 七、课程补充方案

### 7.1 必须补充的内容（插入现有计划）

#### 补充1：模型剪枝与知识蒸馏（插入 Week 4）

```
在 Week 4 量化内容之后，增加 2 天：
- 模型剪枝原理：结构化剪枝 vs 非结构化剪枝
- 知识蒸馏：Teacher-Student 框架
- 实践：用 PyTorch 对 MNIST 模型做剪枝，对比前后精度和大小
- 目标：模型压缩率 > 50%，精度损失 < 2%
```

#### 补充2：Embedded Linux 强化（插入 Week 2-3）

```
在环境搭建阶段增加：
- Linux 内核裁剪与交叉编译基础
- Buildroot/Yocto 构建系统概念
- 设备树（Device Tree）基础
- 实践：用交叉编译链编译一个 ARM 可执行文件
```

#### 补充3：TensorRT 入门（插入 Week 6 之后，新增 Week 6.5）

```
新增半周内容：
- TensorRT 核心概念：Builder、Engine、Context
- ONNX → TensorRT 转换流程
- FP16/INT8 量化对比
- 实践：在 PC 上用 TensorRT 加速 ResNet-18 推理
```

### 7.2 建议新增的独立模块

#### 新增模块A：传感器数据链路（1周，可插入 Month 2）

```
内容：
- 摄像头数据采集：V4L2框架、MIPI CSI接口
- 图像预处理管线：Resize、Normalize、颜色空间转换（NV12/RGB）
- 麦克风音频采集：I2S接口、PCM格式
- 实践：ESP32-S3 摄像头采集 + 预处理 + 推理全链路打通
```

#### 新增模块B：端侧大模型入门（1周，作为 Month 3 后的进阶）

```
内容（前瞻储备，不要求3个月内掌握）：
- LLM 推理优化：KV Cache、投机采样
- llama.cpp / TinyLLM 等端侧推理方案
- 量化方案对比：GPTQ、AWQ、GGUF
- 了解即可，面试中能说出概念就是加分
```
