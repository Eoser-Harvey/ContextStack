# 工作台模板库

这个文件夹存放工作台系统的各种模板文件，用于快速创建标准化工作台。

## 关键文件

- [[project-template]] - 项目工作台模板
- [[task-template]] - 任务工作台模板
- [[topic-template]] - 话题工作台模板

## 模板说明

- **项目工作台模板**: 包含项目信息、当前任务、会话历史等标准字段
- **任务工作台模板**: 用于具体任务跟踪，包含任务描述、进度、结果
- **话题工作台模板**: 用于技术话题讨论，包含问题分析、解决方案、参考资料

## 使用方法

1. 创建新工作台时选择合适的模板
2. 复制模板内容到新文件
3. 根据实际需求修改占位符内容
4. 保持工作台格式的统一性
