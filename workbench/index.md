# 工作台系统

这个文件夹存放 ContextStack 协作框架的工作台系统，实现 Session 持久化和话题切换。

## 关键目录

- [[projects/index|项目工作台]] - 所有项目的工作台文件
- [[topics/index|话题工作台]] - 技术话题和讨论记录
- [[tasks/index|任务工作台]] - 临时任务执行跟踪
- [[history/index|历史归档]] - 已完成或暂停的会话记录
- [[templates/index|模板库]] - 工作台模板文件

## 关键文件

- [[README]] - 工作台系统说明文档
- [[workbench-guide]] - 工作台使用指南

## 系统功能

- **Session持久化**: 保存当前工作状态，支持随时切换
- **话题切换**: 快速在不同项目/话题间切换
- **状态管理**: 记录任务进度、待办事项、会议记录
- **版本控制**: 每个工作台包含版本历史

## 使用场景

1. **项目开发**: 使用项目工作台跟踪开发进度
2. **问题排查**: 使用话题工作台记录问题分析过程
3. **会议记录**: 使用工作台记录会议内容和行动项
4. **学习笔记**: 使用工作台记录学习过程和心得
