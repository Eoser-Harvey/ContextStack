## 核心工具

### 网络调试
- **Wireshark**: 抓包分析，支持pcap/.pcapng格式
- **tcpdump**: 命令行抓包工具
- **ping/traceroute**: 基础网络连通性测试

### 串口调试
- **SecureCRT**: 专业终端仿真，支持SSH/串口/Telnet
- **MobaXterm**: 多功能终端，集成X11服务器
- **Putty**: 轻量级终端工具

### 烧写工具
- **CH系列烧写器**: 常用MCU烧写工具
- **J-Link**: ARM调试器
- **ST-Link**: STM32系列调试器

## 调试流程

### 1. 准备工作
1. **环境搭建**
   - 安装必要调试工具（Wireshark、串口工具等）
   - 配置网络连接（IP地址、子网掩码、网关）
   - 准备调试线缆（网线、串口线、USB线）

2. **信息收集**
   - 设备型号、硬件版本、软件版本
   - 网络拓扑图、接线图
   - 故障现象描述、重现步骤

### 2. 分层调试方法论
```
物理层 → 数据链路层 → 网络层 → 传输层 → 应用层
  ↓         ↓          ↓        ↓        ↓
硬件连接   MAC地址    IP配置    端口状态  协议交互
```

**物理层检查**
- 网线/光纤连接是否正常
- 指示灯状态（电源、连接、活动）
- 接口是否有损坏

**数据链路层检查**
- MAC地址学习是否正常
- VLAN配置是否正确
- STP/MSTP状态

**网络层检查**
- IP地址配置（静态/DHCP）
- 路由表是否正常
- 邻居发现协议（ARP/NDP）

**传输层检查**
- TCP/UDP端口状态
- 连接建立情况
- 丢包/重传统计

**应用层检查**
- 协议交互是否正常
- 应用逻辑是否正确
- 配置参数是否合理

### 3. 问题定位流程
```
现象描述
    ↓
重现问题
    ↓
收集日志（设备日志、抓包数据）
    ↓
分层分析（从物理层到应用层）
    ↓
定位根本原因
    ↓
验证解决方案
    ↓
记录解决方案
```

### 4. 常用调试命令

#### 网络设备
```bash
# 查看接口状态
show interface

# 查看路由表
show ip route

# 查看MAC地址表
show mac address-table

# 查看VLAN配置
show vlan brief

# 查看日志
show log
```

#### 嵌入式设备
```bash
# 查看系统信息
uname -a
cat /proc/version

# 查看内存使用
free -h

# 查看CPU使用
top
htop

# 查看网络配置
ifconfig
ip addr show

# 查看进程
ps aux
```
