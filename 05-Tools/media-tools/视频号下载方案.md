# 视频号视频下载方案

> 微信 PC 版视频号视频下载，全部免费方案。

## 方案一：wx_channel（推荐，最简单）

| 项目 | 详情 |
|---|---|
| 仓库 | [nobiyou/wx_channel](https://github.com/nobiyou/wx_channel) v5.6.9 |
| Fork | [Eoser-Harvey/wx_channel](https://github.com/Eoser-Harvey/wx_channel) |
| 原理 | MITM 代理 + 页面注入下载按钮 |
| 风险 | 装自签证书 + 管理员权限，用完关掉即可 |

### 操作

1. 下载 exe → 右键管理员运行
2. 自动装证书 + 配置代理
3. 微信 → 视频号 → 播放视频 → 红色下载按钮出现
4. 用完 `Ctrl+C` 退出（自动清理）

### 增强功能

- Web 控制台：`http://127.0.0.1:2025/console`
- 批量下载、断点续传、多清晰度

## 方案二：wechatVideoDownload（功能最全）

| 项目 | 详情 |
|---|---|
| 仓库 | [qiye45/wechatVideoDownload](https://github.com/qiye45/wechatVideoDownload) |
| Fork | [Eoser-Harvey/wechatVideoDownload](https://github.com/Eoser-Harvey/wechatVideoDownload) |
| 原理 | HTTPS 流量嗅探 |
| 特点 | 便携版免安装、支持直播录制、4K、断点续传 |

### 操作

1. 解压便携版 → 运行 exe
2. 点击"开始监听" → 打开视频号播放视频
3. 自动捕获 → 选择清晰度下载

| 项目 | 详情 |
