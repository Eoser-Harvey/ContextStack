## 完整工作流

```
视频号视频 → wx_channel 下载 → 剪映/Vibe 转文字 → Markdown 文档
```

## 快速开始

- **只管下载视频号** → 装 [wx_channel](https://github.com/nobiyou/wx_channel) 增强版，右键管理员运行，视频页出现红色下载按钮
- **日常转文字** → 剪映专业版，完全免费无限时长
- **隐私敏感内容转文字** → 装 [Vibe](https://github.com/thewh1teagle/vibe)，44MB 离线运行
