## 本地离线工具

### Vibe（首选）

| 项目 | 详情 |
|---|---|
| 官网 | [thewh1teagle.github.io/vibe](https://thewh1teagle.github.io/vibe/) |
| 安装包 | ~44MB，无需 Python |
| 模型 | 支持 large-v3-turbo |
| 许可 | MIT，完全免费 |
| 更新 | 2026-03-13（活跃维护） |

**操作：** 下载安装 → 首次启动自动引导下载模型 → 拖入文件 → 选中文 → 转录 → 导出 TXT/SRT/MD

**支持格式：** MP3、MP4、WAV、M4A、MKV、MOV、AVI、FLAC、OGG

**特色：** GPU 加速、批量转录、实时麦克风、YouTube 下载、AI 总结

### Buzz

| 项目 | 详情 |
|---|---|
| 安装 | `winget install ChidiWilliams.Buzz` |
| 特点 | MIT 许可，支持文件批量/实时麦克风/YouTube |
| 导出 | TXT / SRT / VTT / CSV |

### WhisperDesktop（不推荐）

> 已停更 3 年（最后版本 2023-07），只支持 medium 模型。用 Vibe 替代。

## 剪映操作步骤

1. 剪映专业版 → 开始创作 → 导入视频
2. 文本 → 智能字幕 → 语音转字幕 → 中文 → 开始识别
3. 全选字幕 → 右键复制 → 粘贴到 Markdown
4. 或：导出 → 取消"导出视频" → 只勾选"导出字幕" → TXT
