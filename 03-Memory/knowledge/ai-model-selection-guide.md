## 选型决策

### 主力模型：DeepSeek V4 Pro
**适用**：日常编程、框架架构、嵌入式AI学习、复杂调试

- **优势**：代码生成最准确、逻辑推理最强、指令遵循最优
- **场景**：80% 日常任务

### 轻量备选：DeepSeek V4-flash
**适用**：简单代码修改、快速生成、低复杂度任务

- **优势**：速度快、成本低
- **场景**：简单增删改查、文件操作

### 中文强援：GLM-5V-Turbo
**适用**：大量中文文档处理、中文推理、中文技术方案撰写

- **优势**：中文理解最优、多模态能力、指令遵循强
- **场景**：中文技术文档、方案报告、中文综述
- **注意**：替代原 GLM-5.1 / GLM-5.0V 等旧版 GLM 模型

### 长文档专家：Kimi K2.6
**适用**：大量源码阅读（如 TFLM 1843 文件）、长篇对比分析

- **优势**：超长上下文窗口，单次可加载大量文件
- **场景**：源码通读、批量文档分析

### ❌ 不推荐：MiniMax M2.7
- **原因**：创意写作强，编程推理弱，不适合编程场景

## 使用策略

```
日常编码/调试      → DeepSeek V4 Pro
简单快速任务       → DeepSeek V4-flash
中文文档/方案     → GLM-5V-Turbo
大量源码读取     → Kimi K2.6
❌ 编程不选      → MiniMax M2.7
```
