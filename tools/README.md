# Tools 工具库

ContextStack 框架维护工具脚本库，按功能分类管理。

## 🗂️ 分类结构

### 🔧 编码处理 (encoding/)
处理文件编码和乱码修复的工具：
- `scan_garbled.py` - 扫描乱码文件
- `fix_encoding.py` - 修复编码问题（Python）
- `analyze_encoding.py` - 分析文件编码
- `check_bytes.py` - 检查文件字节
- `test_encoding.py` - 测试编码转换
- `fix_encoding.ps1` - PowerShell编码修复

### 💾 备份管理 (backup/)
系统备份和文件保护工具：
- `compress_backup.ps1` - **推荐** 压缩备份脚本 (方案B：直接压缩为ZIP)
- `daily_backup.ps1` - 原始每日备份脚本 (文件夹复制)
- `restore_from_backup.ps1` - 备份恢复工具
- `check_backup_task.bat` - 备份任务状态检查
- `test_compress_backup.bat` - 压缩备份测试脚本
- `run_backup_task.bat` - 定时任务执行器 (系统使用)

## 📋 分类规则

### 1. 新增脚本分类原则
1. **按功能分类**：根据脚本主要功能放入对应子目录
2. **中英文说明**：每个脚本应有清晰的注释说明
3. **版本管理**：重要工具应标注版本和更新历史
4. **依赖说明**：如果脚本有外部依赖，必须在 README 中说明

### 2. 分类目录说明
- `encoding/` - 编码转换、乱码修复、字符集处理
- `backup/` - 备份恢复、数据保护、版本管理
- `diagnostics/` - 系统诊断、性能分析、问题排查
- `fileops/` - 文件操作、批量处理、目录管理
- `utilities/` - 通用工具、辅助脚本（如果不符合上述分类）

### 3. 文件命名规范
- 使用英文小写和连字符：`fix-encoding.py`
- 保持扩展名：`.py`、`.ps1`、`.bat`
- 避免空格和特殊字符

## 🚀 使用指南

1. **查找工具**：根据功能需求进入对应分类目录
2. **查看说明**：阅读脚本文件头部的注释说明
3. **执行工具**：按需运行脚本（注意权限要求）
4. **反馈改进**：记录使用问题和改进建议

## 📝 维护责任

- 定期整理和更新工具库，删除过时工具
