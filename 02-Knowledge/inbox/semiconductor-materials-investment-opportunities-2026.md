## 1. 核心逻辑：为什么是半导体材料

### 文章核心观点

> **找上游瓶颈中的瓶颈，还有国产替代。**

### 关键数据

| 指标 | 数据 |
|------|------|
| 高端光刻胶自给率 | **不足10%** |
| 日本四家企业垄断 | **92%** 市场份额 |
| 半导体靶材国产化率 | 2025年约37% → 2026年近45% → 2028目标60%+ |
| ABF载板2028年缺口 | **42%** |
| 12大核心材料高端领域 | 普遍低于20%，部分不足5% |

### 驱动因素

1. **国产替代紧迫性**: 海外出口管制收紧，国内晶圆厂安全库存持续走低
2. **下游需求爆发**: AI芯片、新能源汽车、5G驱动半导体需求持续增长
3. **政策强力支持**: 国家大基金重仓押注半导体材料赛道
4. **产能缺口**: 味之素ABF产能已被预定到2027年，交期超6个月

## 2. 五大紧缺材料赛道

### 赛道一：氮化镓 (GaN)

| 维度 | 详情 |
|------|------|
| **特性** | 3.4eV宽禁带、高电子迁移率、耐高温300℃+ |
| **优势** | 损耗降低20-30%、体积缩小 |
| **应用** | 快充、5G基站、雷达、新能源汽车 |
| **催化事件** | 2026年6月12日最高法裁定：英飞凌GaN产品**全面禁止在华销售** |

### 赛道二：靶材

| 维度 | 详情 |
|------|------|
| **用途** | 芯片金属布线、存储电容制造刚需耗材 |
| **国产化率** | 2025年37% → 2026年45% → 2028年60%+ |
| **技术突破** | 6N+超高纯、大尺寸绑定、纳米多层靶材达国际水平 |
| **核心标的** | 江丰电子（龙头） |

### 赛道三：硅微粉

| 维度 | 详情 |
|------|------|
| **用途** | 半导体封装材料填充 |
| **特点** | 高纯度、超细粒度要求 |
| **替代逻辑** | 替代日本进口 |

### 赛道四：ABF板和膜

| 维度 | 详情 |
|------|------|
| **用途** | AI封装刚需，FC-BGA封装核心材料 |
| **现状** | 味之素垄断，产能预定到2027年 |
| **缺口** | 2028年缺口42% |
| **替代窗口** | 2026-2028年黄金替代期 |

### 赛道五：光刻胶

| 维度 | 详情 |
|------|------|
| **垄断格局** | JSR、信越化学、东京应化、富士胶片四家占92% |
| **自给率** | 高端ARF光刻胶不足10% |
| **紧迫性** | 国产化优先级最高的材料 |

## 4. 美股投资机会

### Wolfspeed (WOLF) — 碳化硅/氮化镓

| 维度 | 详情 |
|------|------|
| **定位** | 全球碳化硅龙头 |
| **最新动态** | 2026年6月15日推出第五代SiC MOSFET技术，盘前大涨13% |
| **股价** | ~$48.71（2026-06-15） |
| **历史** | 曾因中国大陆产能过剩担忧股价大跌82% |
| **催化** | AI数据中心新型碳化硅封装 |

**投资逻辑**：
- 第五代SiC技术面向1200V和750V应用
- AI数据中心带来新增长点
- 但需警惕：中国大陆碳化硅产能过剩风险

**风险**：
- 中国大陆竞争者（天岳先进、三安光电）产能扩张
- 碳化硅价格下行压力
- 公司历史上波动极大

## 6. 投资策略建议

### 核心策略："白毛女神Serenity"逻辑

> 找上游瓶颈中的瓶颈，还有国产替代。

### 优先级排序

| 优先级 | 标的 | 逻辑 | 配置建议 |
|--------|------|------|---------|
| **P0** | 江丰电子 | 靶材龙头，业绩已验证，国产替代最直接 | 核心仓位 |
| **P1** | 三安光电 | 氮化镓最大催化（英飞凌被禁），但波动大 | 趋势仓位 |
| **P1** | 南大光电 | 光刻胶长期逻辑好，但短期增速慢 | 观察仓位 |
| **P2** | Wolfspeed | 美股碳化硅龙头，技术领先但有中国竞争风险 | 小仓位博弈 |

### 与现有持仓的协同

你目前持仓：
- **MRVL**（迈威尔）— AI半导体，与材料赛道同属半导体大主题
- **DRAM** — 存储芯片，受益于半导体景气周期
- **SPCX** — 太空探索，独立主题
- **优必选** — 机器人，AI应用端

**协同效应**：半导体材料（江丰电子/三安光电）+ AI芯片（MRVL）+ 存储（DRAM）形成半导体产业链上中下游组合。

### 入场时机

| 策略 | 说明 |
|------|------|
| **趋势确认** | 等待氮化镓概念回调后企稳再入场三安光电 |
| **业绩验证** | 江丰电子Q2财报（预计7-8月发布）确认高增长持续性 |
| **事件驱动** | 关注英飞凌禁令后续执行情况、新的出口管制政策 |

## 7. 风险提醒

| 风险 | 说明 | 应对 |
|------|------|------|
| **概念炒作** | 半导体材料概念容易被热炒后回调 | 不追高，等回调 |
