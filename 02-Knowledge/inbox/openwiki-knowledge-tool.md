## 核心问题：收藏夹是内容黑洞

| 数据 | 说明 |
|------|------|
| 收藏量 | 估计每年收藏 600+ 条 |
| 回头看 | < 20 条 |
| 浪费率 | **97% 的收藏从未再看** |

> "微信文件传输助手、推特书签、YouTube 稍后再看、浏览器收藏夹——每个平台都有收藏按钮，每个按钮背后都是一个黑洞。"

---

## OpenWiki 是什么

**一句话定位**：复制任何内容 → AI 自动采集整理 → 私人知识库

**特点**：
- macOS 桌面应用，常驻菜单栏
- 所有数据存在本地，开源免费
- GitHub: github.com/kdsz001/OpenWiki

---

## 核心功能

### 1. 零摩擦保存
- 复制内容 → 屏幕角落弹出浮窗 → 10秒倒计时
- 想保存：点一下 | 不想保存：什么都不做自动消失
- 支持快捷键 ⌘⇧C 手动唤出快速保存窗口

### 2. AI 自动处理

| 功能 | 说明 |
|------|------|
| **全文提取** | 自动抓取链接原文（公众号、推特、YouTube、网页） |
| **编译成 Wiki** | AI 将零散内容整理成结构化 Wiki 页面 |
| **知识图谱** | 可视化页面间关系，发现关联和空白 |
| **AI 对话搜索** | "上个月存过一篇关于xxx的文章"，AI 帮你找到并总结 |
| **健康检查** | 自动检测孤立页面、断裂链接、结构问题 |

### 3. 七维注意力分析（杀手锏）

每周 AI 生成洞察报告，分析七个维度：

| 维度 | 内容 |
|------|------|
| **总览** | 本周保存了什么，整体画面 |
| **潜意识偏好** | 你反复在关注的方向（自己可能没意识到） |
| **被遗忘的内容** | 存了但没回看的，可能值得重看 |
| **认知盲区** | 基于阅读模式，可能忽略的领域 |
| **热点趋势** | 关注主题在升温还是降温 |
| **注意力热力图** | 注意力在哪些领域最密集 |
| **行动建议** | 基于分析的具体下一步建议 |

> "这不只是一个知识库。它是一面镜子，让你看清自己到底在关心什么——包括你自己都没意识到的部分。"

### 4. AI 接入

| 支持 | 说明 |
|------|------|
| **模型** | Claude、OpenAI、Google Gemini |
| **模式** | Auto 模式自动选择（简单用快模型，深度用强模型） |
| **MCP 协议** | 可与 Claude Desktop 联动 |

## 核心理念

> "那些「这个有用」的瞬间，其实是我们最真实的判断力在工作。但收藏夹把这些判断力全浪费了——存了等于没存。"

**OpenWiki 想做的事**：让每一次「这个值得留下」的直觉，真正变成知识。

## 与 ContextStack 的关联

| OpenWiki 功能 | ContextStack 对应 |
|--------------|-----------------|
| 零摩擦保存 | inbox 收集系统 |
| AI 自动编译 Wiki | 手动整理结构化文档 |
| 知识图谱 | 知识分区 + 索引系统 |
| AI 对话搜索 | MEMORY.md 索引 |
| **七维注意力分析** | ❌ ContextStack 没有，可借鉴！ |

---

## 可借鉴的点

### 1. 七维注意力分析
- ContextStack 可以增加定期的「注意力回顾」功能
- 统计 inbox 处理量、各分类占比、遗忘内容提醒

### 2. AI 自动整理
- OpenWiki 用 AI 自动将链接编译成 Wiki
- ContextStack 可以考虑增加 AI 辅助整理功能

### 3. 知识图谱可视化
- 展示各知识领域的关联和密度
- 发现学习中的空白领域

### 4. 理念借鉴
- **收藏 ≠ 知识**：存了不代表消化了
- **AI 应该接管整理**：人只做判断，AI 做执行
- **定期回顾**：被遗忘的内容可能比新内容更有价值

## 局限与思考

| 局限 | 说明 |
|------|------|
| **仅 macOS** | Windows 用户无法使用 |
| **本地存储** | 多设备同步需自己解决 |
| **AI 依赖** | 需要 API 成本 |
| **vs ContextStack** | OpenWiki 更偏「收藏+搜索」，ContextStack 更偏「结构化积累+成长」 |

---

## 总结

| 维度 | OpenWiki | ContextStack |
|------|----------|--------------|
| **定位** | 收藏 + AI 整理 | 结构化积累 + AI 协作 |
| **核心** | 解决「找不到」 | 解决「不成长」 |
| **AI 作用** | 自动整理 | 辅助工作 |
| **适合** | 被动收集大量信息 | 主动规划学习路径 |

**借鉴价值**：七维注意力分析 + AI 自动整理思路，可以融入 ContextStack 的进化中。
