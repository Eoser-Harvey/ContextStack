## 三、海力士暴跌复盘（半导体周期见顶的经典案例）

### 3.1 暴跌背景

- **6 月底 7 月初**：美光财报毛利率高达 **85%**
- 部分基金经理判断：**毛利率到顶 = 半导体股价周期见顶**（"万物皆周期"逻辑）
- 于是：**做空存储相关标的 + 做空韩国指数**

### 3.2 暴跌传导机制（高杠杆踩踏）

```
机构中签美股海力士 ADR
   ↓ 需要从韩国股市抽资金
   ↓ 同时做空韩指
第一波下跌
   ↓ 引发高杠杆产品踩踏
五倍杠杆雪崩
   ↓ 传导
两倍、三倍杠杆强制平仓
   ↓
造成大幅下跌，很多杠杆投资者被套
```

**核心教训**：**杠杆踩踏有传导链**——从最高杠杆（5x）开始雪崩，依次传导到低杠杆（2x/3x）平仓。第一波下跌本身不大，但**高杠杆产品的连锁平仓放大了跌幅**。

## 五、可借鉴的核心认知

1. **看基本面要看经营现金流，不是看融资叙事**——云厂商 35% 现金流增速打破了"AI 烧钱必死"的逻辑
2. **"毛利率到顶"是半导体周期见顶的领先指标**——美光 85% 毛利率是信号
3. **杠杆踩踏有传导链**——5x → 2x/3x 依次平仓，跌幅被放大。**你的信用卡杠杆必须警惕这类尾部风险**
4. **存储 LTA 供给格局稳定**——但"稳定"不等于"股票不会跌"，趋势判断还要看价格（宝哥的道氏理论）

## 六、股票魔法师投资方法（本次分享核心增量）

> 来自《股票魔法师》（Mark Minervini）第一本，本次分享的核心选股框架。

### 6.1 基本面筛选："代码 33"规则

**三个核心指标，连续 3 个季度向上增长：**

| 指标 | 要求 |
|------|------|
| 销售同比增速 | 连续 3 季向上 |
| 盈利同比增速 | 连续 3 季向上 |
| 利润率 | 连续 3 季向上 |
| **股价状态** | **横盘标的**（基本面好但股价未启动） |

**补充筛选条件**：会议纪要完整版强调——选"**股价横盘**"的标的，且若增长为**可持续有机增长**、现金流/应收/存货健康则更优。

**筛选到的好标的案例**：
- **盛虹科技**：24 年连续四季度相关指标上行 → 25 年股价大幅上涨

**必须排除伪增长（真实性核查）：**
| 伪增长来源 | 检查项 |
|-----------|--------|
| 一次性损益 | 排除非经常性收益 |
| 现金流 | 看经营现金流是否匹配利润 |
| 应收账款 | 警惕利润上升但应收暴增（可能虚增） |
| 存货 | 警惕存货高企（产品滞销） |

### 6.2 技术面：企业生命周期四阶段

```
第一阶段 底部盘整（危险，别买）
第二阶段 业绩加速 + 行业景气主升浪 ✅ 只做这个
第三阶段 顶部出货（别追）
第四阶段 下跌趋势（别抄底）
```

**第二阶段判断标准：**
| 条件 | 说明 |
|------|------|
| 股价 > 50/120/200 日均线 | 三条长期均线上方 |
| 均线向上发散 | 短期均线在长期均线之上且向上 |
| 相对强度 RS 跑赢全市场 70%+ | 强势股 |

### 6.3 VCP（Volatility Contraction Pattern，波动收敛三角）

**用于在第二阶段寻找突破买点：**
- **下跌缩量**：回调时成交量萎缩
- **回撤幅度逐步收窄**：每一次回调的低点比前一次高

VCP 本质：**波动率收敛 = 多方蓄力**，突破时放量即为买点。

### 6.4 与宝哥/你现有体系的对照

| 维度 | 股票魔法师 | 宝哥道氏 | 你的现况 |
|------|-----------|---------|---------|
| **筛选** | 代码33（基本面+真实性核查） | 道氏定大方向 | **你基本靠消息/直觉选标的** |
| **买入** | VCP 收敛突破 | 3+2 突破确认 | 情绪化/越跌越买 |
| **阶段** | 只做第二阶段 | 只做上升趋势 | 你在 CRCL 第三/四阶段仍重仓 |
| **均线** | 50/120/200 日 | EMA20/MA20 | MA120 定投 |

**核心差异**：股票魔法师是"右侧+强势股"打法，**和你的左侧定投同样冲突**（和 UT Bot 一样，本质都是趋势跟踪）。

### 6.5 对你最实用的部分（批判性）

1. **代码33 是你可以立刻用的过滤器**——你选 CRCL/MRVL 之前，先套一遍"销售/盈利/利润率连续3季向上 + 排除伪增长"，能筛掉很多"看起来便宜/热门"但基本面走坏的标的
2. **"只做第二阶段"直击你的 CRCL 问题**——如果你的 CRCL 处在第三阶段（顶部）或第四阶段（下跌），股票魔法师会让你**坚决离场**，而不是越跌越买
3. **相对强度 RS > 70%**——这是筛选强势股的核心，你可以拿持仓逐个查 RS，淘汰跑输大盘的
4. **VCP 收敛突破**——和宝哥 3+2 突破确认是同一思路（都要求突破时放量 + 回撤收窄），可作为你未来加仓的时机确认

> **但注意**：股票魔法师是纯右侧成长股打法，你的家庭财务结构（生育计划、信用卡 40 万杠杆）决定了**你不能全仓跟随**。它的价值在于给你"选标的的过滤器"，而不是"全部交易系统"。

### 7.1 近期市场复盘补充

**海力士暴跌复盘：**
- "毛利率见顶"（美光 85%）被视为半导体周期见顶信号 → 做空
- 美股 ADR 中签机构从韩国股市抽资 + 同步做空韩指 → **杠杆踩踏**扩大跌幅

**当前 A 股观察（2026-08）：**

- 参考对比：**2022 年创业板去杠杆 40% 跌幅**

### 7.2 "新登堡预兆"暴跌预警指标（浙商策略团队）

**触发条件（需同时关注）：**
| 信号 | 说明 |
|------|------|
| 市场上涨但新高、新低企业数量**同时扩散** | 背离 |
| 下跌企业多于上涨企业但指数仍向上 | 指数失真 |
| 机构超配单一行业 | 如上半年机构电子行业配置**超 43%** |

**成功率约 60%**，多指标同时触发时风险更高。

> **对你的意义**：你重仓 CRCL + 机构超配 AI 电子（43%）——如果"新登堡预兆"的背离信号出现，是减仓警示。

### 7.3 止损逻辑（非线性亏损的数学）

> **跌 90% 需要涨 10 倍才能回本**——亏损是非线性的，止损必须设。

**四层止损判断：**
| 层面 | 判断 |
|------|------|
| 价格 | 破 20 日线 |
| 时间 | 长时间不涨 |
| 行为 | 持仓心态恶化 |
| 基本面 | 逻辑改变 |

**纪律**：分批建仓 + **盈利后上移止损位**（锁利）。下跌趋势结束形成新平台后可重新关注。

### 7.4 德鲁肯米勒案例（2000 科网泡沫）

**传奇投资人的纠错过程：**
```
做空亏损 → 快速翻多赚 40%
  → 清仓后忍不住追高又亏 17%
  → 直接清仓去非洲休假调整
  → 回来后基于新证据做多美债
  → 四季度赚 40%，全年转正
```

**核心教训**：
- 趋势不对要及时离场，**避免执念**
- 状态不好时**先离场调整**（去非洲休假），回来再战
- 每次进场基于**新证据**，不是旧执念

**补充（会议纪要完整版）**：
- 初期做空失败后**快速认错反手做多**（认错要快）
- 估值过高时**清仓**
- 泡沫破裂亏损后**果断离场休整**
- 之后基于**新的宏观证据**（利率、油价上涨，经济恶化迹象）转向做多美债获利

### 7.5 沧海志五步交易法（实盘投资人）

| 步骤 | 内容 |
|------|------|
| 1. 锁定赛道 | 从上而下锁定**高景气赛道** |
| 2. 生活验证 | 结合生活观察验证景气度 |
| 3. 财务验证 | 订单、营收、利润率增长 |
| 4. 分配仓位 | **三倍空间 30%、两倍 20%、一倍 10%** |
| 5. 分批建仓 | 结合 EXPMA 等趋势指标 |

**卖出条件**：业绩断层 / 逻辑改变 / 达到目标价

### 7.6 后续方向提示（A股 2026-08）

### 7.7 策略一致性（最重要的一条纪律）

> **应保持策略的一致性（如坚持趋势跟踪或价值投资），避免因情绪频繁切换策略。**

**这是全套方法论里对你冲击最大的一条**：
- 宝哥 / UT Bot / 股票魔法师 = **趋势跟踪**（右侧）
- 你现在的 MA120 / 左侧定投 = **价值/左侧**
- **两套策略不可兼得**，频繁切换会两头挨打

**你的真实问题**：
- 6/24 情绪化清仓 BTC = 从"价值左侧"临时切到"恐慌离场"
- CRCL 越跌越买 = 又在"趋势走坏"时坚持左侧
- **你在左侧/右侧之间反复横跳，没有一致性**

**纪律要求**：
1. **先选一条路**：趋势跟踪（宝哥系）还是价值/左侧（你现状）
2. 选定后**至少执行 1-2 年**再评估，不要因短期盈亏切换
3. 切换前**书面记录理由**，不是情绪驱动

## 八、全套方法论对你（CRCL）的综合批判

把股票魔法师 + 宝哥 + 沧海志 + 止损逻辑全部叠到你现在的 CRCL 持仓上：

| 方法 | 对 CRCL 39.5% 的裁决 |
|------|---------------------|
| 股票魔法师"只做第二阶段" | 若 CRCL 非第二阶段 → **离场** |
| 宝哥道氏"只做上升趋势" | 若周线破位 → **离场** |

**结论**：**几乎所有方法论都指向同一个点——你的 CRCL 仓位要么有明确的基本面 + 趋势支撑，要么需要削减 + 设止损。你现在是"重仓 + 无止损 + 无阶段判断"的三无状态。**
