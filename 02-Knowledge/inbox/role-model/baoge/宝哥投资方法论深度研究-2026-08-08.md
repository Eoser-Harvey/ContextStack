## 三、道氏理论详解（PPT 第 10-21 页，主体内容）

道氏理论是宝哥的主工具，他强调"**道氏定大方向，斐波那契找回调关键支撑压力，EMA20/MA20 作为入场离场过滤器**"（PPT 第 14 页）。

### 三大趋势

| 趋势 | 时长 | 特征 |
|------|------|------|
| **主要趋势** | 1 年以上 | 牛市：一浪高过一浪；熊市：一浪低过一浪 |
| **次级趋势** | 几周-数月 | 大牛市的大跌回调；熊市的反弹 |
| **短期波动** | 几周-几天 | 最易被操纵，最没意义 |

### 六条核心原则

1. **平均价格包容一切**：消息/财报/政策/地缘都已反映在价格里
2. **主要趋势不会轻易反转**：延续性强，反转需要明确信号
3. **牛市确认**：指数创出新高 + 回调低点高于前一波回调低点
4. **熊市确认**：指数创出新低 + 反弹高点小于前一波反弹高点
5. **成交量验证**：大涨放量、回调缩量是健康趋势；反之趋势虚弱
6. **趋势持续到反转信号**：不要提前抄底/逃顶，**拒绝左侧判断**

### 短板（PPT 第 15 页）

- **滞后性**：反转信号出现时行情已走了一段
- **震荡市频繁假信号**：不适合横盘
- **不能测算目标价**：需要搭配斐波那契

## 五、你提到的 4 个技术方法展开

PPT 里只展开了道氏理论。均线、BBI、斐波那契只提到名字，下面系统补充这 4 个方法，并标注宝哥可能的应用方式。

### 5.1 均线（MA / EMA）

| 类型 | 全称 | 特点 | 适用场景 |
|------|------|------|---------|
| **MA** | Simple Moving Average 简单移动平均 | 滞后但平滑 | 长期趋势 |
| **EMA** | Exponential Moving Average 指数移动平均 | 近期权重高，更敏感 | 短期趋势 |
| **SMA** | Simple MA 同 MA | — | 同 MA |

**宝哥用法（PPT 第 14 页）**：`EMA20 / MA20 作为入场/离场过滤器`——即趋势确认后，回调到 20 均线附近才买入。

#### 经典均线系统

| 组合 | 含义 |
|------|------|
| **MA5** | 超短趋势 |
| **MA10** | 短趋势 |
| **MA20** | 月线，宝哥指定过滤器 |
| **MA60** | 季线 |
| **MA120** | 半年线，**你目前 P1 在用的定投触发线** |
| **MA250** | 年线，牛熊分界 |

#### 实战规则
- **金叉**：短期均线上穿长期均线 → 买入信号
- **死叉**：短期均线下穿长期均线 → 卖出信号
- **多头排列**：MA5 > MA10 > MA20 > MA60 > MA120 → 强趋势
- **空头排列**：反向 → 弱趋势

#### 局限
- **滞后**：均线是历史价格的平均，对剧烈反转反应慢
- **震荡市假信号多**：和道氏理论一样，区间行情频繁触发假信号
- **参数敏感**：用 5/10/20 还是 8/21/55 不同流派结果不同

---

### 5.2 BBI 指标（Bull And Bear Index，多空指标）

#### 计算公式
```
BBI = (MA3 + MA6 + MA12 + MA24) / 4
```

即把 3 日、6 日、12 日、24 日四条均线取算术平均。**宝哥在 PPT 中未展开 BBI，但隐含在"过滤器"思路里。**

#### 用法
| 信号 | 含义 |
|------|------|
| **收盘价上穿 BBI** | 多头信号 |
| **收盘价下穿 BBI** | 空头信号 |
| **BBI 向上** | 多头市场确认 |
| **BBI 向下** | 空头市场确认 |

#### 优势 vs 普通均线
- **平滑性更好**：4 条均线平均，过滤掉单条均线的抖动
- **多周期共振**：3/6/12/24 同时考虑，确认趋势的稳定性

#### 局限
- **滞后性更强**：4 条均线平均 = 比单条均线更滞后
- **震荡市依然没用**：本质是均线衍生品，震荡市会反复穿越 BBI 产生假信号
- **参数固定**：3/6/12/24 是固定参数，不能调整适配不同周期

#### 与宝哥体系的衔接
BBI 可以作为宝哥"过滤器"的补充——先用道氏理论定大方向，再用 EMA20/MA20 做入场，BBI 可作为"是否真的多头市场"的二次确认。

### 5.3 斐波那契法（Fibonacci Retracement）

#### 核心数字
```
0.236 (23.6%)
0.382 (38.2%)
0.50 (50%)
0.618 (61.8%) ← 最关键，黄金分割
0.786 (78.6%)
1.0
1.618 (161.8%) ← 扩展位
2.618
```

#### 用法 1：回调支撑/压力位
画一段趋势的起点到终点，回调 23.6/38.2/50/61.8/78.6% 处常出现支撑/压力。

**宝哥用法（PPT 第 14 页）**：`斐波那契找回调关键支撑压力`——主升浪后用斐波那契找回调入场点。

#### 用法 2：扩展位预测目标价
突破后用 1.618/2.618 测算下一目标位（宝哥 PPT 提到"无法测算目标价格，搭配斐波那契"即此用法）。

#### 实际应用示例
- BTC 从 17000 涨到 70000
- 0.382 回调位 ≈ 51400
- 0.5 回调位 ≈ 43500
- 0.618 回调位 ≈ 35600

如果回调在 0.5-0.618 区间企稳，往往是绝佳买入点（这也是午饭投资"熊市囤 BTC"的数学依据）。

#### 局限
- **不是因果规律**：是统计学上的"市场记忆"，不是物理定律
- **画法敏感**：从哪个低点/高点开始画，结果完全不同
- **多种比率并存**：到底是 0.382 还是 0.618 起作用？事后才知道
- **宝哥短板**：道氏定方向 + 斐波那契找位置 = "双盲"决策，事后看都对

### 5.4 道氏理论 123 法则（Three-Step Trend Reversal）

> **注**：宝哥 PPT 提到"道氏理论"，但"123 法则"是更具体的实战派版本，由 Victor Sperandeo 在《专业投机原理》中提出，作为道氏理论的实战化。

#### 123 法则定义
判断趋势反转的"三步法"——必须三步全部成立才能确认反转：

**步骤 1：趋势线被突破**
- 上升趋势的下轨支撑线被有效跌破
- 下降趋势的上轨压力线被有效向上突破

**步骤 2：上升/下跌不再创新高/低**
- 上升趋势中：反弹不能突破前一波高点
- 下降趋势中：下跌不能跌破前一波低点

**步骤 3：前低/前高被跌破/突破**
- 上升趋势中：价格跌破前一波回调低点
- 下降趋势中：价格升破前一波反弹高点

#### 与宝哥道氏理论的关系
| 维度 | 经典道氏 | 123 法则 |
|------|---------|---------|
| 趋势确认 | 牛市：新高+回调低点抬高 | 趋势线+两个不再创新 |
| 趋势反转 | 熊市：新低+反弹高点降低 | 三步全满足才反转 |
| 适用周期 | 长周期（年/月） | 中短周期（周/日） |
| 操作性 | 定大方向 | 找具体入场/离场点 |

#### 实战示例（上升趋势反转）
```
上升趋势中：
1. 跌破上升趋势线 ✅
2. 反弹未突破前高 ❌ → 继续观察
3. 跌破前低 ✅ → 反转确认
```
**三步全部成立才确认反转**，否则只是"回调"。

#### 局限
- **极端行情失效**：闪崩/跳空高开可能跳过某些步骤
- **主观画线**：趋势线画法有主观成分
- **震荡市陷阱**：横盘整理时频繁假触发

## 十四、UT Bot Alerts（TradingView 指标）

### 一句话
**基于 ATR（平均真实波幅）的动态趋势跟踪指标**，本质是 **SuperTrend（超级趋势）的增强版**——在价格穿越基础上额外加了 **EMA 交叉确认**，减少假信号。

### 核心公式

```
ATR = SMA(TR, c)             // 波动率，c 默认 10
nLoss = a × ATR              // 动态止损距离，a 默认 1.0
上边界 up  = Close + nLoss
下边界 dn  = Close - nLoss
止损线 = 递归跟踪（趋势向上时取 max，向下取 min）
```

### 买卖信号（双重确认）

| 信号 | 条件（需同时满足） |
|------|------------------|
| **做多** | ① `收盘价 > 止损线` ② `EMA(Close,1)` 上穿止损线 |
| **做空** | ① `收盘价 < 止损线` ② `EMA(Close,1)` 下穿止损线 |

### 关键参数

| 参数 | 默认 | 作用 |
|------|:---:|------|
| `a` 关键值 | 1.0 | 止损灵敏度。越小越紧（信号多但噪音大），越大越宽（信号稳但滞后） |
| `c` ATR周期 | 10 | 波动率窗口。短=灵敏，长=平滑 |
| `h` Heikin Ashi | False | 是否用 Heikin Ashi 蜡烛平滑价格（减少噪音） |

### 场景参数建议

| 场景 | 参数调整建议 |
|------|-------------|
| **强趋势市场** | a=1.5-2.0，c=10-14，h=False |
| **震荡市场** | a=2.0-3.0，c=7-10，降低灵敏度 |
| **减少噪音** | h=True，使用Heikin Ashi平滑 |
| **快速反应** | a=0.5-1.0，c=5-7 |

### 和 SuperTrend 的区别

```
UT Bot Alerts = SuperTrend逻辑 + EMA交叉过滤 + 可选Heikin Ashi
```

| 维度 | UT Bot | SuperTrend |
|------|--------|-----------|
| 信号确认 | 价格穿越 + **EMA交叉**双确认 | 仅价格穿越 |
| 价格源 | 收盘价 | 典型价格 (H+L+C)/3 |
| 噪音过滤 | ✅ EMA 交叉过滤 | ❌ 无 |
| 信号质量 | 更严格、更少假信号 | 更宽松、更多噪音 |

### 和宝哥体系的衔接

**这是宝哥让你用它的原因**——UT Bot 的"双重确认"哲学和他自己的 **3+2 突破确认法**高度一致：

| 宝哥的 3+2 | UT Bot 的对应 |
|-----------|--------------|
| 收盘突破前高 | 收盘价 > 止损线 |
| 3 日内再创新高 | EMA 交叉（趋势延续确认） |
| 过滤假突破 | 价格 + EMA 双条件，过滤假穿越 |

**区别**：宝哥的 3+2 需要手动盯（RS + 成交额确认），UT Bot 可以**自动画出止损线 + 弹出警报**，把"纪律"程序化。

### 实操要点（会议现场演示补充）

**① 信号是"状态性"而非"瞬时动作"**
- UT Bot 的 Buy/Sell 不是一次性指令，而是一个**持续的持仓状态**
- **出现 Buy 信号后，只要未出现 Sell 信号 = 持续可持有/做多状态**
- 出现 Sell 信号才考虑离场
- **必须严格遵循信号，避免情绪化操作**——这是工具的核心价值（无情绪干扰）

**② 多周期结合**
- 建议**周线 + 日线**为主做中长期趋势判断
- 4 小时线用于更短周期
- 不同周期信号需**互相配合**：周线定大方向，日线找入场
- 信号是状态性的，不是瞬时触发动作

**③ 工具回测验证**
- 现场用美光、盛虹科技等标的回测
- 验证指标的有效性和及时性

**④ 工具不是 100% 准确**
- 任何工具都不是 100% 准确
- **需先小额尝试适应**，避免因迷信工具而一次性重仓（呼应宝哥 PPT 第 41 页"新手法则"）

### ⚠️ 对你最重要的冲突

**UT Bot 是趋势跟踪指标，和你的 MA120 左侧定投逻辑冲突**：
- UT Bot 会在 BTC 回调时发"做空/离场"信号
- 你的策略恰恰要在回调时加仓
- **两个系统会打架**——这正是宝哥强调"选一条路专精"的原因
- 你不能同时用趋势跟踪 + 左侧定投，否则会在关键位置自我矛盾

## 十五、周线视角（宝哥："至少周线"）

### 为什么宝哥说"至少周线"

**核心原因：他的所有工具在日线以下全是噪音。**

| 宝哥工具 | 在日线/分钟线的表现 | 在周线/月线的表现 |
|---------|------------------|------------------|
| **道氏趋势线** | 高高低低频繁变化，假突破多 | 趋势清晰，高高低低一眼看出 |
| **3+2 突破确认** | 3 天内随时摸高又跌回，假信号多 | 周线级别的"前高"才是真压力 |
| **UT Bot** | 参数调不好就来回打脸 | a 值可放宽，信号稳定 |
| **斐波那契回调** | 回调 0.5/0.618 天天触发 | 大级别的 0.618 才是关键支撑 |
| **EMA20** | 日线 EMA20 被毛刺骗 | 周线 EMA20 是强支撑 |

**宝哥 PPT 第 11-21 页反复强调的"短期波动最易被操纵、最没意义"——这个"短期"指的就是日线以下。周线是过滤这些噪音的最低门槛。**

> "做大趋势，忽略小周期"
> "趋势一旦形成，惯性极强，不会轻易反转"
> "不猜顶，不抄底，没有明确反转信号前切勿主观臆测"

**周线才能体现"惯性"**。日线随便一个消息就能画出一根大阴线骗你，但周线如果还在上升趋势线之上、EMA20 之上，那些日线波动只是"次级趋势"，不影响"主要趋势"。

**"至少周线"是一记重锤**：CRCL 重仓恰恰是你在日线尺度上"越跌越买"，违反"只做上升趋势"铁律的结果。
