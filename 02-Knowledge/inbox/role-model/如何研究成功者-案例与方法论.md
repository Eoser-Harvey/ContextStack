# 普通人研究成功者进而成功的案例与方法论

> 回答一个元问题：有没有"普通人深入研究一个成功者→自己获得成功"的案例？他们是怎么研究的？怎么执行的？
> 此文档整合6个经典案例 + 6条可操作的研究方法论 + 3条对你当前阶段的执行建议。

## 一、核心结论

**答案是：有，极多，而且历史反复验证。** 但有条件——不是"看几篇文章"就成功，而是**深度研究 + 长期模仿 + 结合自身实际创新**。

"我的剑传给能挥舞它的人。" — 查理·芒格

## 二、6个经典案例

### 案例1：富兰克林 — 通过阅读传记"尚友古人"

**做了什么**：富兰克林年轻时极度贫穷（印刷学徒），没机会上学，但他把传记当作"没有见面的人生导师"。他特别研究了苏格拉底的辩证法和艾迪生的写作风格。

**怎么执行的**：
1. 读《旁观者》杂志，**逐句抄写+重写+对比原版**，反复练习直到自己的写作能和原文媲美
2. 制定"13项美德清单"（节制、缄默、秩序等），**每周专注一项**，13周一个循环，每年4轮
3. 把前人的方法拆解为**可执行的日常动作**，不是泛泛而读

**结果**：从印刷学徒→出版商→科学家→外交官→美国开国元勋。100美元纸币上印着他的头像。

**关键方法论**：**拆解→模仿→内化→创新**。不是崇拜，是把别人的技能拆成可以训练的动作。

---

### 案例2：格雷厄姆→巴菲特→段永平→黄峥（最清晰的传承链）

这是投资界最著名的**四代传承链**，每一代都是"深入研究上一代→结合自身实际"的结果：

**第一代：本杰明·格雷厄姆**（"价值投资之父"）
- 著作：《聪明的投资者》《证券分析》
- 核心思想：安全边际（margin of safety）、市场先生比喻

**第二代：沃伦·巴菲特**（格雷厄姆的学生+员工+继承人）
- **怎么研究**：19岁读到《聪明的投资者》，说自己"像看到一道光"。去找格雷厄姆读研究生，主动要求去他的公司工作（不要薪水）
- **怎么执行**：早期完全照搬格雷厄姆的"捡烟蒂"策略→后来受芒格影响，升级为"用合理价格买好公司"
- **结果**：全球最富有的投资者

**第三代：段永平**（"中国巴菲特"）
- **怎么研究**：深度研究巴菲特的价值投资理念。2006年花62万美元拍下巴菲特午餐
- **怎么执行**：从实业家（小霸王/步步高/OPPO/vivo）转型投资者。把巴菲特的理念用于中国——"敢为天下后，后中争先"
- **结果**：个人投资资产超千亿，投资苹果、茅台、网易等获得巨大回报

**第四代：黄峥**（拼多多创始人）
- **怎么研究**：段永平带他去参加巴菲特的午餐。他深入研究了段永平的"本分"哲学和巴菲特的长期主义
- **怎么执行**：把零售"Costco+迪士尼"的模型搬到中国电商，用社交裂变（拼团）做差异化。**复制理念而非复制产品**
- **结果**：拼多多成为中国第三大电商，黄峥一度成为中国首富

**这条链的关键规律**：
```
研究前人 → 理解核心原则 → 在自己的领域创新应用 → 形成自己的方法论 → 传给下一代
```

每一代都不是简单的"抄作业"，而是**理解底层逻辑后，在自己的土壤上种自己的树**。

### 案例3：查理·芒格 — "研究失败比研究成功更重要"

芒格专门研究"为什么聪明人会犯愚蠢的错误"，他收集了人类历史上大量失败案例，形成一套"人类误判心理学"（25种认知偏误）。

**怎么研究**：
1. 阅读大量传记，特别是**失败的传记**（不是成功的）
2. 跨学科学习：物理（临界质量）、生物（进化论）、心理学（认知偏误）、历史（帝国兴衰）
3. 总结出"反过来想，总是反过来想"的逆向思维框架

**怎么执行**：
- 投资决策前，先列出"这个投资一定会失败的N种方式"，逐一排查
- 不碰自己不懂的行业
- 用"多元思维模型"检查每个决策

**结果**：巴菲特的合伙人，伯克希尔50年复合增长20%+的幕后大脑。

**关键方法论**：**失败研究 > 成功研究**。成功有运气成分，但失败的规律是确定的。

### 普通人案例4：Ryan Holiday — 19岁大学生→无薪学徒→畅销书作家

历史级大佬的案例虽然经典，但离我们太远。以下是真正从零起步的普通人案例：

### 普通人案例1：Ryan Holiday — 19岁辍学大学生→当学徒→全球畅销书作家

**起点**：19岁大学生，没有任何背景和资源。

**做了什么**：大二读到罗伯特·格林（《权力的48条法则》作者）的书，深受震撼。他主动联系格林，请求做他的**研究助理**（无薪）。格林答应了。

**怎么执行的**：
- 每天为格林做大量研究工作：整理历史案例、查找一手资料、验证引用
- 格林教他"如何写书、如何思考书、如何研究书、如何营销书"——**从零到一把写作每个环节都教给他**
- 不是泛泛而读格林的书，是**参与格林写书的全过程**，看大师怎么操作
- 后来把格林的"策略思维/历史案例"方法论和自己的Stoic哲学兴趣结合，开创了自己的写作方向

**结果**：30岁前出了10本畅销书（《障碍即道路》《自我是敌人》等），全球销量数百万册。在德州开了一家独立书店。年收入估计数百万美元。

**关键方法**：**学徒制**。不是看书学习，是直接给大佬打工，零距离观察他的每一个决策和操作。

### 普通人案例2：Eric Jorgenson — 粉丝整理纳瓦尔碎片→成为畅销书作者

**起点**：完全不知名的普通人，纳瓦尔的推特粉丝之一。

**做了什么**：花了**两年时间**系统阅读纳瓦尔的所有推特（数千条）、播客文字稿、访谈记录。

**怎么执行的**：
1. 把所有碎片化内容按主题重新归类：财富哲学、幸福观、读书方法、决策原则
2. 不是复制粘贴，是**重新组织+提炼核心观点+补充自己的理解**
3. 联系纳瓦尔获取授权，纳瓦尔同意了（因为整理得太好）
4. 用Kickstarter众筹出版，一炮而红

**结果**：《纳瓦尔宝典》（The Almanack of Naval Ravikant）成为全球畅销书，被翻译成30多种语言。Eric从"一个不知名的读者"变成知名作者，年收入数百万美元。

**关键方法**：**系统化提炼**。把一个高价值人物的碎片化输出整理成结构化知识体系，本身就是巨大的价值创造。

## 三、6条可操作的研究方法论

基于上述6个案例，提炼出普通人可复用的研究方法：

| 方法 | 来源 | 具体操作 |
|------|------|----------|
| **1. 逐句模仿法** | 富兰克林 | 找到榜样的一篇好文章，**抄写→不看去重写→对比原版→找出差距→再写**。不是读，是"复刻" |
| **2. 一本书读10遍法** | 老薛（学李笑来） | 选一本你认为最值得学的书，**不是读完就算，是读10遍，做笔记，每遍侧重不同** |
| **3. 付费约见法** | 老薛（见刘大猫）、段永平（拍巴菲特午餐） | 用钱直接买时间。约见不需要复杂准备，就问一个最想解决的问题 |
| **4. 逆向研究法** | 芒格 | 不只研究成功原因，更要**研究失败原因**。问"如果我想失败，我该怎么做？"然后避开这些做法 |
| **5. 跨学科类比法** | 王川 | 用不同领域的理论套用当前问题。物理规律→社会规律，生物进化→商业竞争。找到**底层规律的共性** |
| **6. 系统提炼法** | Eric/《纳瓦尔宝典》 | 把对方所有碎片化输出（文章/播客/推特）**按主题重新归类整理**，形成你自己的"教材" |
