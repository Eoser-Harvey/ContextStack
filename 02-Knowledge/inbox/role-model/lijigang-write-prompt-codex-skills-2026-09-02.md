## 三、核心方法论（可迁移的思想）

1. **技能工程化**：技能不是散文档，是产品——org-mode/md 双分支、skills CLI 一键安装、版本自动 bump、MIT 分发。**对比 ContextStack 的 02-Knowledge/skills/：他是"可安装可分发"，我们是"文档沉淀"，P1 待办「自检清单 Skill 化」可参考此模式。**
2. **认知方法论 × 技能**：追本之箭（纵向深钻本质）、降秩引擎（找领域不可再少生成器）、约束引擎（揪出假墙）、八方向概念解剖——把思维工具全部封装成可复用技能，对应 harve 的「四步回答法（本质→实践→坑→思考）」。
3. **输出闭环**：读书 → 认知工具化 → 公众号传播 → GitHub 沉淀，一条龙；个人 IP 三件套（博客+公众号+GitHub）。
4. **兼容生态**：org-mode 用户但提供 md 分支——工具链信仰不影响对外兼容，这个意识值得学。
