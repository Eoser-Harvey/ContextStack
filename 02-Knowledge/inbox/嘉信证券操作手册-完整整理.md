## 1. 开户全流程（2025最新）

### 1.1 嘉信理财简介
- 全称：嘉信理财集团（Charles Schwab Corporation，NYSE：SCHW）
- 总部：美国加州旧金山，1971年创办
- 2019年收购德美利证券（TD Ameritrade），美国最大在线券商之一

### 1.2 优缺点

**优点**：
- 安全性高：FINRA、SEC、SIPC成员
- 美股、ETF在线交易0佣金
- 免费使用顶级交易软件 thinkorswim
- 中文客服：400-120-6217
- 无开户门槛（但建议至少入金1,000美元防关户）

**缺点**：
- 开户流程繁琐
- 入金需电汇或Wise（无美国银行卡）
- 大陆用户无法申请Debit卡
- 融资利率较高
- 仅支持美股市场

### 1.3 准备材料
1. **护照**（有效期内的护照）
2. **地址证明**：国内地址的信用卡、银行或水电煤账单（中文即可）
3. **邮箱**：推荐 Gmail、iCloud 等境外邮箱
4. **手机号**：需能接收境外短信，推荐境外号码

### 1.4 开户步骤

1. **进入国际站入口**：https://international.schwab.com/open-account-intro （切勿用主站或香港站）
2. **选择地区**：China
3. **选择账户类型**：Individual Account
4. **邀请码**：有则填，无则直接「Get Started」
5. **同意声明** → **填写个人信息**：必须用护照英文/拼音，禁用中文
6. **证件**：推荐护照。身份证选 Other government ID
7. **邮箱验证** → **设置登录账号密码**
8. **填写居住地址**：英文，必须与地址证明一致
9. **账户目的**：General purposes / 资金来源：工资
10. **工作信息**：英文填写（在职/自雇/学生等）
11. **合规声明**：高管/证券机构职员 → 选 No
12. **账户功能选择（关键！）**：
    - **Margin（融资）**：建议 Yes
    - **Option Trading（期权）**：建议 Yes，选 Level 2 或 3
    - **thinkorswim**：必选 Yes
    - ⚠️ 一次性勾选，事后开权限极难
13. **财务状况**（填大一些）：
    - 净资产：200,000
    - 流动资产：100,000
    - 年收入：50,000
    - 经验年限：6年
    - 年交易次数：70~100笔
    - 平均交易额：5,000~10,000
    - 经验水平：Extensive 或 Good
14. **协议签署**：全勾，选 Nonprofessional
15. **上传材料**：护照照片页 + 地址证明（中文即可）→ ⚠️ 文件名不能含中文
16. **提交审核** → **立即填写 W-8BEN**（有中文界面）

### 1.5 入金方式

| 方式 | 说明 |
|------|------|
| 美国卡 | ACH 出入金 |

## 2. 上车攻略补遗

### 基础限制
- 不支持港股，仅能交易美股市场

### 审核通过标志
- 收到"账户开通确认邮件"才算真正通过（期权权限开通邮件 ≠ 账户开通）

### 收不到验证短信的4种解决方式
1. **电话验证**：登录时选"致电嘉信"，国内拨打 400-120-6217
2. **多设备App信任验证**：多设备装嘉信App/thinkorswim，开启生物识别登录
3. **Symantec VIP**：安装后致电客服绑定
4. **境外手机号（推荐）**：低成本养卡如 giffgaff

### 期权权限
- 首次申请极易通过，事后升级很困难 → 开户时一并勾选

### 软件选择
- **强烈建议只用 thinkorswim**，内置简/繁体中文

## 3. 如何开第二个账户

- 美股券商支持开多个账户
- 用途：期权交易账户 与 长期持仓账户 分离

### 步骤
1. 登录嘉信 → 顶部「Accounts」→「Open An Account」
2. 选择国家：中国
3. 选 Individual Account
4. 填写与第一个账户**完全相同**的个人资料
5. 系统识别已开过户 → 用现有账户登录
6. 补充信息 → 上传护照首页 + 地址证明
7. 提交等待审核（约一周）

## 4. 多账户间资产转移

### 规则
- **现金**：可与外部账户互相转移
- **持仓**：只能嘉信内部账户间转移
- **手续费**：完全免费

### 操作入口
登录 → 「Move Money」→「Online Transfer」

### 现金转移
选「Cash only」→ 输入金额和频率 → Review → Submit

### 持仓转移
选「Position Only」→ 表格中填入转移份额 → Review → Submit

### 时效
| 提交时间 | 执行时间 |
|----------|----------|
| 美东 19:00 前 | 立即 |
| 美东 19:00 ~ 次日 00:00 | 次日 00:01 后 |
| 美东 19:00 后 | 下一交易日 |

### 查询
「Move Money」→「Recent Transfer Activity」

## 7. W8 续签

### 关键步骤
1. 点邮件链接进入续签页面 → **不建议选中文**（翻译质量差）
2. 选「个体」身份，核对修正个人信息
3. 获取确认码并记录
4. 确认非美国居民
5. 税务编号：中国居民身份证号
6. 税收优惠协定：选中"中国"
7. 额外优惠条例：通常跳过
8. 一路打勾确认 → 提交

### 提醒
- W8 正确填写是享受中美税收优惠的前提
- 来年开始嘉信不会自动帮申请10%股息预扣税退税

## 8. 购买美债

### 操作流程
1. 登录 → 「Trade」→「Bonds」→ 同意协议
2. 选「U.S. Treasuries」（附息国债）或「U.S. Treasuries Zeros」（零息国债）
3. 筛选到期日（3个月 / 2年 / 10年 / 30年+）
4. 关注：票面利率、到期日、YTM（到期收益率）、Min/Max（购买量门槛）
5. 点 Buy → 填数量 → Review Order → Place Order

### 注意事项
- 券商买美债是**二级市场交易**，注意比较 YTM
- 门槛高（如 Min 250 张 = 最低25万美元）
- 小资金建议通过**美债 ETF** 间接持有

## 9. 订单类型详解（thinkorswim）

在 PC 端 `Order Entry Tools` → `Order` 下拉框切换订单类型。

| 类型 | 机制 | 场景 |
|------|------|------|
| **Market（市价单）** | 当前市价尽快成交，不保证最优价格 | 紧急止损 |
| **Limit（限价单）** | 按指定价格或更优价成交 | **日常交易首选** |
| **Stop（止损单）** | 触及止损价后转市价单 | 预设止损 |
| **Stop Limit（限价止损）** | 触及止损价后转限价单 | 止损+价格保护 |
| **Trail Stop（跟踪止损）** | 随价格上涨动态上移止损价 | 追踪趋势、放大利润 |
| **Trail Stop Limit** | 跟踪止损+限价保护 | 趋势止盈+滑点保护 |

### Trail Stop 示例
持有股票现价 $100，设 Link: MARK, Price: -2%
- 股价涨至 $200 → 止损价自动上移至 $196
- 跌破 $196 → 触发市价单

## 10. 盈透证券转仓到嘉信

### 特点
- 双方均免费
- 支持整个账户或部分仓位/现金转仓

### 步骤
1. 嘉信网页端 → 「Move Money」→「Transfer Account」
2. 搜索 **`interactive broker`**（⚠️ 缩写 IBKR 搜不到）
3. 账户类型：Individual / 盈透账号：U + 8位数字
4. 选择目标嘉信账户
5. 选择转仓方式：
   - 整个账户转仓
   - 部分：填现金金额 + 搜索添加资产 + 填转出份额
6. 确认两边账户同名 → 核对概览 → 勾选协议 → 提交

## 核心提醒汇总

1. **开户信息全部用英文/拼音**，地址必须与证明完全一致
2. **期权+融资+thinkorswim 开户时一次性勾选**，事后升级极难
3. **日常交易优先用限价单**
4. **DRIP 没有全局开关**，需逐只持仓设置
5. **W8 正确填写**是享受中美税收优惠的前提
6. **入金建议**：港卡 FPS 汇港币最方便
7. **软件推荐**：只用 thinkorswim，别用嘉信自家App
