## 1. ai-agent-book — 最火：AI Agent 工程实战书

| 项目 | 信息 |
|------|------|
| GitHub | https://github.com/bojieli/ai-agent-book |
| Star | 25K+ |
| 作者 | 李博杰（华为诺亚方舟实验室研究员，清华博士） |
| 协议 | 开源免费 |
| 全名 | 《深入理解 AI Agent：设计原理与工程实践》 |

**核心内容**：不是零散教程，而是把上下文、记忆、工具、评估等问题系统讲了一遍。全书 10 章正文，每章配有完整的、可直接跑起来的实验代码，共 88 个实验。围绕一个核心公式组织全书结构。

**适合人群**：想系统理解 AI Agent 设计原理与工程实践的开发者。被评价为"AI Agent 领域的最佳开源学习资源，没有之一"。

## 3. code-review-graph — AI 读代码前加一层关系图

| 项目 | 信息 |
|------|------|
| GitHub | https://github.com/tirth8205/code-review-graph |
| Star | 21.2K - 26K+ |
| 协议 | 开源（MCP 原生） |
| 定位 | 本地优先的代码智能图谱工具，专为 MCP 协议和 AI 编程助手设计 |

**核心思路**："Stop burning tokens"——先把函数、调用、依赖和测试关系画成图（用 Tree-sitter 解析代码库），再让 AI 只读取这次改动真正影响到的部分，而不是反复读整个仓库。可减少 71 倍 token 消耗。

**适合人群**：大仓库 code review、使用 Claude Code / MCP 协议的 AI 编程用户。本地部署，给代码库建一张"活地图"。

## 4. kimi-code — 把 Kimi 放进终端和真实项目

| 项目 | 信息 |
|------|------|
| GitHub | 月之暗面（Moonshot AI）官方 |
| Star | 8.4K |
| 协议 | Apache-2.0 |
| 定位 | 终端里的 AI 编程代理，对标 Claude Code 和 Gemini CLI |

**核心功能**：基于 Kimi K3 模型的 CLI 编程工具。K3 是 2.8 万亿参数的全球最大开放权重模型，权重已于 7月27日开放。在 FrontierCode 1.1 评测基准上，是首款性能逼近前沿水准的开源模型。已接入 Devin 桌面客户端与命令行工具。

**适合人群**：想试 Kimi K3 写代码的人。可通过 CLI 终端和桌面端两种方式使用，支持全局配置和动态模型切换（/model 命令）。

## 5. DeepTutor — 最实用：Agent-native 学习伴侣

| 项目 | 信息 |
|------|------|
| GitHub | https://github.com/HKUDS/DeepTutor（港大 HKUDS 实验室） |
| Star | 29.6K |
| 定位 | Agent 原生架构的个性化学习系统 |

**核心功能**：不是普通聊天机器人，而是长期个性化学习系统。支持上传教科书、研究论文、技术手册等文档构建 AI 驱动知识库；多 Agent 问题求解；集问答、可视化讲解、出题、研究于一体。Agent 原生架构，模块化设计 + 统一上下文管理，实现从知识获取到深度理解的全流程。

**适合人群**：需要长期个性化学习支持的开发者、研究人员、学生。被誉为"集问答、可视化、出题于一身的 AI 超级导师"。
