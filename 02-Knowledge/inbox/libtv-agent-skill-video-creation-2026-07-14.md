## 一、核心产品

**LibTV**（liblib.tv）：AI 视频创作平台，底层接入 Seedance 2.0 等视频生成模型，提供画布+节点专业工具链，并支持 Agent + Skill 模式。

**官网**：liblib.tv（已更名为 LibTV，原 LiblibAI）

---

## 二、核心功能：公众号转短视频 Skill

苍何用 Codex + LibTV Agent 制作了一个 Skill，发布到 LibTV Skill 市场，名为 **「公众号转爆款短视频」**。

### 使用流程

1. 在 LibTV Skill 市场添加该 Skill
2. 将公众号文章 Markdown 文件丢给 Agent
3. 确认配置（画幅、时长、风格、配音、字幕、音乐、封面），也可全用默认
4. Agent 自动完成：
   - 生成口播脚本
   - 生成分镜（沿用公众号图片素材）
   - 生成视频封面（提炼爆款封面要素）
   - 生成配音和背景音乐
   - 在画布中合成视频，可直接导出

### 配套工具

苍何还有一个 **canghe-wechat-article-extractor** 技能，丢个文章链接就能自动下载公众号文章到本地 Markdown 文件。

## 四、创建自己的 Skill

1. LibTV → Skill → 我的 → 创建 Skill
2. 用 Codex 或 WorkBuddy 制作好 Skill 后上传文件夹
3. 填写信息，测试
4. 发布到 Skill 市场

> 注意：目前 LibTV Agent 不支持 Skill 中带脚本，上传时需注意。

---

## 五、核心洞察

> **模型是基础，Skill 是杠杆。** 普通人给再强的生成器也不知道提示词怎么写、镜头怎么编排、节奏怎么卡。Skill 把专业创作者的经验封装成可复用的能力，让模型的天花板真正被普通人够到。

## 六、对你的参考价值

### 自媒体层面
- 如果你后续要运营公众号/视频号，可以用这个 Skill 把文章一键转视频，多平台分发
- 苍何的 **canghe-wechat-article-extractor** 技能可以辅助下载文章

### 端侧AI方向
- LibTV 的 Skill 生态是"AI Agent 降低创作门槛"的典型案例，和你的端侧AI创业方向（如儿童AI陪伴）有类似逻辑
- Seedance 2.0 是 AI 视频生成的前沿模型，值得关注其技术进展

### 投资层面
- LibTV 背后是原 LiblibAI 团队，AI 视频赛道正在快速成熟
- Skill 市场的商业模式（平台抽成/付费Skill）值得关注
