#### 交叉对比：达尔文12号 vs 超级玛丽15号

> 以30岁男性50W保额30年交保终身为例

| 对比维度 | 达尔文12号（复星联合） | 超级玛丽15号（君龙人寿） |
|----------|----------------------|------------------------|
| 年保费(基础) | ¥6,710 | ¥6,875 |
| 重疾种类 | 120种 | 110种 |
| **重疾后轻中症继续赔** | ✅ 不分组、无间隔期 | ✅ 分组继续赔 |
| **意外重疾额外赔** | ✅ 自带+35%（独有） | ❌ 无 |
| 45岁前重疾翻倍赔 | ❌ 无 | ✅ 自带2倍 |
| 60岁后住院津贴 | ✅ 500元/天（独有） | ❌ 无 |
| 顶梁柱关爱金 | ✅ 可选+30%(癌症) | ❌ 无 |
| 结节专属保障 | 一般 | ✅ 肺/乳/甲结节 |
| 癌症特药金 | ❌ 无 | ✅ 自带50%保额 |
| 肺结节核保 | 较友好 | ✅ 非常友好(<8mm有机会标体) |

**结论：韩伟选达尔文12号，薛燕视健康状况决定**

- 韩伟：达尔文12号基础50W（¥6,710/年）+ 顶梁柱关爱金（¥85/年），意外重疾135%赔付+重疾后轻中症不分组继续赔，精准匹配「男性+家庭支柱+有房贷+有孩子+有老人」
- 薛燕：如有肺/乳腺/甲状腺结节，优先超级玛丽15号（核保更宽松+结节专属保障+女性特定癌症优势）；否则达尔文12号或完美人生8号均可

> ⚠️ **重要：不要加重疾险的身故责任！** 重疾险身故责任额外¥1,800+/年只赔50W，远不够覆盖¥180W房贷。正确做法：重疾险不加身故（省¥1,800）+ 单独买定期寿险¥1,500-2,500/年赔200W，花费差不多，身故保障翻4倍。
