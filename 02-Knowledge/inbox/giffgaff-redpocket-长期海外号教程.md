# giffgaff vs RedPocket：长期海外手机号终极指南

> 更新时间：2026-07-18
> 背景：需要一个长期稳定、低成本、能收验证码的海外手机号，用于注册海外平台、绑定支付、接码验证。

---

## 一句话结论

**首选 giffgaff（英国号）**，零月租、eSIM 秒激活、10 英镑能用 50 年。如果必须用美国号，选 RedPocket $45/年。

## 二、giffgaff 完整教程（推荐）

### 2.1 你需要准备

- 一部支持 eSIM 的手机（iPhone XS 及以上、大部分近年安卓旗舰）
- 一张 Visa 或 Mastercard 信用卡
- 一个稳定的邮箱（Gmail/Outlook，不要用临时邮箱）
- 英国节点代理（仅激活 WiFi Calling 时需要）

### 2.2 三步开通

**第一步：下载 App 注册**

在 App Store 或 Google Play 下载 **giffgaff** App，用邮箱注册账号。

**第二步：选择 eSIM 并充值**

- 在 App 中选择 "Order a SIM" → 选择 eSIM
- 套餐选择 **"Pay as you go"**（不要选月租套餐）
- 充值 **£10**（最低金额）
- 填写英国地址（用随机地址生成器即可，不需真实地址）
- 用 Visa/Mastercard 支付

**第三步：扫码激活**

支付成功后，App 会显示 eSIM 二维码。用手机设置中的"添加 eSIM"扫码即可。收到 giffgaff 欢迎短信即激活成功。

全程耗时：**15-30 分钟**。

### 2.3 激活后必做设置

1. **关闭移动数据**：在中国漫游时流量 £0.2/MB，会快速消耗余额
2. **关闭语音信箱**：这是隐藏扣费坑。在 App 的 Help 页面搜索 "voicemail"，按指引关闭。未接来电触发语音信箱会扣费
3. **关闭自动更新**：防止后台偷跑流量

### 2.4 保号方法（核心）

**规则**：每 6 个月内必须产生一次余额变动，否则号码作废。

**最省钱方案 — 刷流量**：

1. 每 5-6 个月（建议设日历提醒），打开 giffgaff 数据网络
2. 关闭 WiFi，访问 `example.com`（页面极小，几乎零流量）
3. 看到文字后立刻关闭流量
4. 单次扣费约 £0.01-0.05

**备用方案 — 发短信**：

每 6 个月发一条短信，扣 £0.3。

**£10 能用多久**：理论上每年只花 £0.2 左右，10/0.2 = 50 年。即使每年发一条短信（£0.3），也能用 33 年。

### 2.5 WiFi Calling 开启方法（可选）

WiFi Calling 让你在中国也能用英国 IP 打电话/发短信，按英国本地资费计费。

1. 打开代理工具（如小火箭），全局路由设为代理，连接**英国节点**
2. 设置 → 隧道 → 开启"包括所有网络"和"包括蜂窝网络"
3. 在 giffgaff 设置中打开 WiFi 通话
4. 开启飞行模式 → 关闭 WiFi → 重新打开 WiFi
5. 等待状态栏出现 "Wi-Fi Calling" 或 "giffgaff WiFiCall"

注意：只有英国节点能拉起 WiFi Calling。

### 2.6 国际格式说明

注册海外平台时，填写号码格式：
- 国家代码：**+44**（英国）
- 号码：去掉前面的 0，填后面 10 位
- 示例：本地显示 `07123456789` → 国际格式 `+447123456789`

## 三、RedPocket 教程（需要美国号时）

### 3.1 套餐介绍

- 年费：**$45/年**（原 $30，2024 年 11 月涨价）
- 老用户续费仍是 $30/年，但加 $12 监管费，实际约 $42
- 每月含：200 分钟通话、1000 条短信、200MB 流量
- 支持 WiFi Calling（在中国可漫游使用）
- 免费拨打 20 个国家（含中国大陆、英国）

### 3.2 获取方式

**方式一 — eBay 购买实体卡（推荐）**：

1. 在 eBay 搜索 "RedPocket $45 Annual Plan GSMT"
2. 直邮中国运费约 $17.9
3. 收到实体卡后，在 redpocket.com/activate 激活
4. 可选：在官网花 $2 购买 GSMT eSIM 转换为 eSIM

**方式二 — 官网直接买 eSIM**：

1. 在 redpocket.com 购买 $10/月 GSMT eSIM 套餐
2. 激活 eSIM
3. 再从 eBay 购买 $45 年套餐的 Activation Code
4. 在官网 PIN Code 处填入激活码，转为年套餐

### 3.3 保号

- 每年续费一次，在 redpocket.com/refill 使用 PIN Code
- 有效期不叠加，建议到期前几天再续
- 支持携号转网（建议转入 Google Voice 靓号，避免 RedPocket 回收号码的骚扰电话）

### 3.4 WiFi Calling

- 需要联系网页在线客服（Live Chat）开通，支持中文
- 开通后在中国境内通过 WiFi Calling 打电话/发短信等同在美国境内
- 2022 年 8 月后新激活卡可能无法漫游开通 WiFi Calling，需联系客服

## 四、选哪个？决策树

```
你需要的是美国号还是英国号？
├── 英国号就够了 → giffgaff（零月租，最佳选择）
├── 必须美国号（注册美区服务、美国银行等）
│   ├── 纯粹收验证码 → giffgaff 也能注册大部分美区平台
│   └── 必须美国号码 → RedPocket $45/年
└── 两个都要 → 先 giffgaff，有需要再上 RedPocket
```

**绝大多数情况，giffgaff 足够**。ChatGPT、Telegram、Google、TikTok、PayPal、海外 AI 平台等，英国号都能注册。美国号的优势场景主要是：美国银行开户、Stripe 验证、部分强制美国号码的平台。
