## 一、两大核心共识

### 共识1：Agent 是未来十年最大的机会

> "Agent 会颠覆几乎所有的行业，所有的服务，所有的产品。"

生财有术从"All in AI"升级为 **"All in Agent"**。AI 工具只是手段，Agent 才是终局——它不是工具，是"数字员工"。

### 共识2：FDE 是普通人最关键的机会角色

**FDE** = Frontend Deployed Engineer（前端部署工程师），由 Planteer 提出，现已被 OpenAI、Cloud、飞书等大厂广泛招募。

亦仁认为：**FDE 不是大厂的专属，反而是普通人、超级个体的巨大机会。** 一个优秀的 FDE 可以同时服务数十家企业，实现个人价值几十倍放大。

**成为 FDE 的核心能力**：不是精通代码，而是掌握"AI 工程能力"——能定义问题、利用 AI 编程工具（尤其 Codex）将解决方案从零到一落地为生产级产品。

## 二、生财有术内部的 Agent 化改造

### 2.1 "数字员工"体系

亦仁亲自搭建了**几十个 AI Agent**，全部投入生产线，接手公司内部大量实际工作。所有 Agent 集成在飞书左侧导航栏，替代传统功能入口（会议纪要、云文档等）。

### 2.2 Agent 职能部门化

| Agent 角色 | 职责 | 启示 |
|-----------|------|------|
| **Agent 架构师** | 拥有亦仁全部权限，每日分析工作流，识别哪些工作可被 AI 替代或一键化 | Agent 可以"管理"Agent |
| **Agent 运维官** | 定时自动维护和修复所有 Agent 的权限、授权等问题 | 维护工作也可以自动化 |
| **Agent 审核官** | 每天审核十几个新 Agent 上线申请，检查权限合规和风险 | Agent 可以"审核"Agent |
| **技术专家 Agent** | 专门修理复杂 Agent 技术故障 | Agent 可以"修理"Agent |

### 2.3 杀手级应用：多平台转录 Agent（"小弟"）

亦仁个人使用频率最高的 Agent：
- 将主流视频/音频平台的长视频、播客一键转录为**干净、无口水话、保留全部细节**的文稿
- 基于对亦仁身份和兴趣的深度理解，**自动标注重点内容**
- 亦仁表示：即使一年付费一万元也愿意使用

### 2.4 业务覆盖范围

Agent 已覆盖：内部运营（周报/财务/微信日报）、内容生产（专题/改写/发布）、社群管理（精华帖筛选/用户画像分析/标签打标）。

## 六、核心方法论

### 6.1 "言出法随" — AI 时代的创业方法论

> 旧模式：想法 → 评审 → PRD → 设计 → 开发（数周/数月）
> 新模式：**想法诞生的瞬间，Demo 在一两个小时内出现**

**关键洞察**：最高效的方式是**老板/合伙人亲自用 AI 做 Demo**——他们最懂用户和需求。Demo 可以瞬间统一团队认知、定义审美和标准，然后将迭代交给工程团队。

### 6.2 Token 消耗量 = AI 能力标尺

亦仁提出"日耗十亿 Token"目标。逻辑：
- 高 Token 消耗不代表绝对厉害，但**不消耗 Token 大概率不厉害**
- 强行设定 Token 消耗目标 → 倒逼思考哪些工作可被 Agent 取代 → 推动工程能力和项目管理指数级提升
- 社区顶级玩家日耗 20-30 亿 Token，背后是多项目、多线程并发

**核心工程概念**：
- **Loop**：人对 AI 的管理循环（发现问题 → 下达指令 → 检查结果 → 修正方向）
- **Harness**：AI 基建上下文（给 AI 准备好所有必要的背景信息）

### 6.3 人在 Agent 时代的角色转变

| 旧角色 | 新角色 |
|--------|--------|
| 执行者 | **问题定义者** — 找到有价值的"好问题"并清晰定义 |
| 评估者 | **快速判断者** — 多个 Agent 并行时，在关键节点做出精准决策 |
| 验收者 | **审美标准制定者** — 定义什么是"好东西"，传达给 AI |
| 操作者 | **风险兜底者** — 最终决策责任和法律风险由人承担 |

> 亦仁认为：绝大多数人遇到的"幻觉"问题，是因为模型能力不足或人对 AI 的掌控力不够、上下文工程没做好。
