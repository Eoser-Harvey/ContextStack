## 一、核心概念定义

**Autonomous self-improving loops（自主自我改进循环）**

> "接下来的AI使用，如果不能实现让我成为一个智能系统，然后自动变聪明，那一定有问题。"
> — 金马

这不是简单的"AI帮我做事"，而是：
- **你 + AI 构成一个智能系统**
- **这个系统能自动变聪明**
- **每次使用后比上次更好**

与"自住进化"、"递归进化"属于同一类概念。

## 二、关键系统与框架

### 1. Self-Improving Coding Agents（Addy Osmani, Google）

**核心思想**: 让 Claude Code 等工具在持续循环中自动改进并交付代码，在你熟睡时工作。

**持续编码循环（Ralph Wiggum 技术）**:
```
提取任务 → 实现代码 → 验证测试 → 提交代码 → 记录经验 → 重置上下文 → 重复
```

**关键设计**:
| 设计 | 说明 |
|------|------|
| 小任务+明确标准 | 原子级用户故事，有明确的通过/失败标准 |
| 隔离迭代 | 每次迭代都是全新状态，避免上下文污染 |
| AGENTS.md | 持久化上下文文件，记录模式、坑点、风格偏好 |
| 复合循环 | 分析循环 → 规划循环 → 执行循环 |

**四通道记忆**:
1. Git 提交历史
2. 进度日志 (progress.txt)
3. 任务状态 (prd.json)
4. 智能体知识 (AGENTS.md)

> "每一次改进都让未来的改进更容易，因为智能体积累了关于代码库的知识库。"

### 2. Hermes Agent（Nous Research）

**GitHub**: ~50,000 stars | 240+ 贡献者 | 8个大版本（2026年2月发布）

**核心差异化**: 把任何 LLM 变成能从自己完成的任务中学习的持久化自主助手。

**"用得越多越聪明"的闭环**:

#### 四层记忆体系

| 层级 | 名称 | 职责 | 存储位置 |
|------|------|------|----------|
| L1 | 提示记忆 | 始终在线，每次会话自动注入 | ~/.hermes/memories/MEMORY.md |
| L2 | 会话搜索 | 按需检索历史上下文 | SQLite + FTS5 |
| L3 | 技能(程序性记忆) | 可复用的工作流指令 | ~/.hermes/skills/ |
| L4 | Honcho用户建模 | 跨会话构建用户画像 | 可选，默认关闭 |

#### 四个进化齿轮

**齿轮一: 定期自省(Periodic Nudge)**
- 自动回顾近期活动
- 判断信息重要性：重要→MEMORY.md，特定话题→SQLite存档
- 让 agent 自己决定什么值得保留

**齿轮二: 自主技能创建(Autonomous Skill Creation)**
触发条件：
- 使用了5次以上工具调用
- 从错误中恢复
- 用户纠正，agent学到更好做法
- 走了非显而易见但有效的工作流

> 技能不是日志，是可复用的指令集，遵循 agentskills.io 开放标准

**齿轮三: 技能自我优化(Skill Self-Improvement)**
- 使用 patch 而非 edit 更新技能
- 只修改变化部分，token消耗更低
- 技能是"活的"——随使用经验迭代

**齿轮四: 跨会话搜索与LLM摘要**
- FTS5全文索引历史对话
- LLM摘要后注入当前上下文
- 只带入相关内容，不是整段旧对话

#### 三层飞轮（独一无二）

```
用户使用 Hermes Agent
    ↓
agent 积累技能和记忆（运行时进化 - 快循环）
    ↓
使用轨迹导出为训练数据
    ↓
DSPy + GEPA 系统级优化技能库和提示（慢循环）
    ↓
训练出更好的 Hermes 模型
    ↓
新模型让 agent 基础能力更强
    ↓
更好的基础能力产生更高质量的轨迹数据
    ↓
（循环）
```

> "进化的不是'大脑'，而是'工作方法'。"

## 三、与 ContextStack 的关联

### 您已在做的事（框架层面）

| ContextStack 机制 | 对应 Self-Improving 概念 |
|-------------------|-------------------------|
| `recent-sessions.md` 会话沉淀 | L2 会话搜索 / 进度日志 |
| `session-template.md` 经验模板 | L3 技能创建 |
| `AGENTS.md` 项目约定 | AGENTS.md 模式记录 |
| 四个索引文件同步 | 复合学习循环 |
| `auto_push_home.ps1` 自动化 | 编排循环 |

### 可强化的方向

**P0: 技能化（Skill Creation）**
- 把重复任务（如"归档流程"、"投资记录更新"）提取为可复用 Skill
- 每次执行后自动优化 Skill 内容

**P1: 记忆分层（Memory Layering）**
- L1: 全局规则（始终加载）
- L2: 项目规则（按需加载）
- L3: 会话经验（搜索加载）
- L4: 个人偏好（长期建模）

**P2: 自省机制（Periodic Nudge）**
- 每次会话结束时自动回顾
- 判断哪些经验值得持久化
- 自动更新索引和模板

**P3: 进化飞轮（Evolution Loop）**
- 快循环：每次会话积累经验
- 慢循环：定期复盘优化框架结构
- 模型层：使用轨迹反哺下一代框架设计

## 四、实践建议

### 立即可做

1. **审视当前流程**: 哪些任务是重复性的？能否提取为 Skill？
2. **建立 AGENTS.md**: 记录项目约定、坑点、风格偏好
3. **会话结束自省**: 每次对话后问自己：这次做对了什么？下次怎么更快？

### 中期建设

4. **技能库建设**: 把高频任务（归档、投资记录、文章总结）标准化为 Skill
5. **记忆分层**: 区分"始终需要"和"按需检索"的信息
6. **自动化编排**: 让脚本承担重复执行，人只做决策和审查

### 长期目标

7. **系统自我进化**: 框架能自动识别改进点、提出优化建议、验证效果
8. **人机共生**: 你不是在使用 AI，你和 AI 构成了一个自动变聪明的系统
