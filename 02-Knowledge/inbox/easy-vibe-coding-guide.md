## 项目概述

**Easy-Vibe** 是 Datawhale 中国出品的开源 Vibe Coding 教程，面向零基础用户，通过 3 个阶段从「不会写代码」到「独立开发 AI 产品」。

- **定位**: 零基础 AI 编程入门指南
- **核心理念**: 会说话就能做产品，不看专业、不看出身
- **特色**: 游戏化入门 + 真实项目驱动 + 中文教程

---

## 三阶段学习路径

### Stage 1: 零基础入门

> 没有技术背景？正好。

| 模块 | 内容 | 产出 |
|------|------|------|
| **学习地图** | 从零基础到全栈开发的完整学习路径 | 明确每个阶段目标和收获 |
| **游戏化入门** | 用 AI 制作贪吃蛇等小游戏 | 打破对代码的恐惧 |
| **产品原型实战** | Vibe Coding 工作流，从想法到可交互原型 | 独立完成高保真 Web 应用 |

---

### Stage 2: 初中级开发

> 一个人，就是一支团队。从前端到后端，从数据库到上线。

| 模块 | 内容 | 技术栈 |
|------|------|--------|
| **素材生成 Agent** | 搭建素材生产工作流和绘图 Agent | Lovart、Nanobanana |
| **Figma 与 MasterGo** | 专业 UI 设计工具基础操作 | Figma、MasterGo |
| **设计稿转代码** | 设计原型转前端代码，减少手工重搭 | Design-to-Code |
| **真实数据项目** | 数据表设计和权限，真实读写操作 | Supabase |
| **部署上线** | 从代码到公网访问的完整流程 | CloudBase、Vercel、Zeabur |
| **AI 知识库集成** | 构建 AI 应用和知识库，接入检索增强 | Dify |

---

### Stage 3: 高级开发

> 产品和结果，我全都要。突破时间与设备限制。

| 模块 | 内容 | 技术栈 |
|------|------|--------|
| **跨平台桌面应用** | 一次开发，多平台运行 | Electron |
| **AI 智能体团队** | 多代理协作完成大型任务 | Claude Agent Teams |
| **长效稳定执行** | 循环脚本和插件管理长时间任务 | Ralph 插件、Claude Code |
| **个人品牌与输出** | 搭建个人网站与技术博客 | 静态站点生成 |
