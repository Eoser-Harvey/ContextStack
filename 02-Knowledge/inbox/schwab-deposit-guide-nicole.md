## 四种入金方式详解

### 方式一: Wise 美元入金（推荐）

| 维度 | 内容 |
|------|------|
| **前提** | Wise 美元账户已绑定嘉信 |
| **费用** | 约 1.12 USD/笔（有用户反馈） |
| **到账** | 秒到（自动扣款） |
| **流程** | 登录嘉信 → 资金转移 → 网上转账 → 勾选仅现金 → 选择 Wise 美元账户 → 一次性 → 提交 |

**操作步骤**:
1. 登录嘉信后台，点击「资金转移」
2. 选择「网上转账」，勾选「仅现金」
3. 选择从 Wise 美元账户转到嘉信账户
4. 频率选择「一次性」，点击继续
5. 检查信息，点击提交
6. 绑定授权自动扣款，资金秒到

> ⚠️ 国内银行直接汇款到 Wise 已不太稳定，有时汇款失败

---

### 方式二: iFAST 英镑入金

| 维度 | 内容 |
|------|------|
| **费用** | 0 元（iFAST 英国境内付款） |
| **到账** | 4-5 小时 |
| **汇率损耗** | 有（嘉信平台自动换汇，约 0.7% 损耗） |
| **收款行** | 花旗银行伦敦支行（嘉信本土账户，降低汇损） |

**操作步骤**:
1. 嘉信 → 资金转移 → 资金传送号码与直接存款 → 外币 → 货币专用电汇指示
2. 找到英镑账户信息（花旗伦敦支行）
3. 打开 iFAST → 汇款 → 英国境内付款
4. 付款目的选「金融投资」
5. **汇款参考**: 姓名拼音 + 嘉信 8 位数账号（必须填写）
6. 收款人账户类型选「商业」
7. 确认转账，等待到账

> 💡 实测 5 英镑到账 6.72 美元，实时汇率约 6.77 美元，损耗约 0.7%

---

### 方式三: 中银香港港币入金

| 维度 | 内容 |
|------|------|
| **费用** | 0 元（中银香港实时转账） |
| **到账** | 4-5 小时 |
| **汇率损耗** | 极小（实测几乎无损） |
| **收款行** | 花旗银行香港分行 |

**操作步骤**:
1. 嘉信获取港币账户信息（花旗香港分行）
2. 中银 App → 转账 → 选择收款人 → 账户号码
3. 填入嘉信花旗香港分行收款信息
4. 转账日期选「实时」
5. **备注附言**: 姓名拼音 + 嘉信 8 位数账号（必须填写）
6. 确认转账，等待到账

> 💡 实测 10 港币到账 1.28 美元，对照实时汇率基本无损

### 方式四: 第三方机构入金（公司/政府/熊猫速汇）

| 维度 | 内容 |
|------|------|
| **方式** | 嘉信提供个人专属 JP 摩根账户 |
| **用途** | 公司薪水、社保等资金直接汇入 |
| **操作** | 嘉信 App → 左下角「提供给您的雇主打印信息」 |
| **状态** | 熊猫速汇暂未恢复跨境转账 |

## 交易所入金（Kraken 等）

| 要点 | 说明 |
|------|------|
| **是否支持** | ❌ 嘉信不支持交易所直接 Direct Deposit |
| **正确做法** | 交易所 → 提现到个人银行账户 → 电汇到嘉信 |
| **关键要求** | ① 汇款人姓名必须与嘉信账户一致 ② 准备资金来源证明（交易记录/出金证明） |
| **违规风险** | 他人账户或交易所账户名直接汇款 → 资金退回/延迟/合规审核 |

## 资金合规流转总结

```
国内银行 ──电汇──→ Wise ──网上转账──→ 嘉信 ✅（有时不稳定）
国内银行 ──电汇──→ iFAST ──境内付款──→ 嘉信 ✅（有汇损风险）
国内银行 ──电汇──→ 中银香港 ──实时转账──→ 嘉信 ✅（推荐，几乎无损）
交易所 ──提现──→ 个人银行 ──电汇──→ 嘉信 ✅（必须中转）
交易所 ──直接──→ 嘉信 ❌（不支持）
```
