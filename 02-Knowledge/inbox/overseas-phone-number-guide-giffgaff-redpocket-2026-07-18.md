## 二、推荐方案：giffgaff（首选）

### 为什么选 giffgaff？

- **成本极低**：首次£10充值，每半年发一条短信（~¥2.7），**10年总成本不到£10**
- **零月租**：Pay as you go 模式，不选套餐就没有月费
- **接码免费**：在国内接收短信完全免费
- **支持eSIM**：实体卡到手后App一键转eSIM
- **英国号码**：注册绝大多数海外服务无障碍

### 完整操作流程

#### 第1步：获取SIM卡

> ⚠️ **当前中国地址已无法直接寄送**，需要国外转寄地址。

**方案A（推荐）：淘宝购买**
- 淘宝搜索 "giffgaff 未激活" 或 "giffgaff 空白卡"
- 价格约 ¥20-50，包含已寄到国内的空白SIM卡
- 到手后自己激活

**方案B：国外朋友转寄**
- 官网 giffgaff.com 申请免费寄到朋友国外地址
- 朋友收到后拍照发你激活码，或转寄回国

**方案C：直接eSIM（如果手机支持）**
- 下载 Giffgaff App，注册账号后直接申请eSIM
- 可能需要英国IP环境

#### 第2步：激活

1. 访问 giffgaff.com/activate
2. 输入SIM卡上的 **6位激活码**
3. 注册邮箱和密码
4. **关键步骤**：选择套餐时，滑到最底部选 **"Pay as you go"**（零月租），不要选任何带颜色的套餐
5. 首次充值 **£10**（用Visa/MasterCard信用卡）
6. 系统分配英国号码（+44开头）

#### 第3步：插卡设置

1. **关闭移动数据漫游**（否则流量费瞬间烧光£10）
2. 插入手机，等待5-10分钟搜网
3. 无信号时：开关飞行模式 或 手动选运营商（中国联通/移动）

#### 第4步：转eSIM（推荐）

1. 下载 Giffgaff App
2. 登录 → 设置 → "Switch to eSIM"
3. 按提示完成，实体卡作废

#### 第5步：永久保号

- 每 **180天** 内必须有一次余额变动
- **最省钱**：每5个月给国内手机发一条短信（¥2.7/条）
- £10余额理论上可用 **10年以上**

#### 第6步（进阶）：开启 WiFi Calling

开启后资费大幅降低：
- 发短信：0.3镑 → **0.08镑**
- 打电话：1镑/分钟 → **0.03镑/分钟**

**iOS**：设置 → 电话 → Wi-Fi Calling → 开启，需iOS 17.4+
**Android**：通话设置 → WiFi通话 → 开启

成功后状态栏显示 `giffgaff WiFi`。

## 三、备选方案：RedPocket（美国号）

### 适用场景

- 需要**美国号码**（+1）注册特定服务
- 每月有实际通话/短信需求（200分钟/1000条/月）
- 不介意稍高的年费

### 获取方式

**方式一（最简单）：eBay购买实体卡 → 转eSIM**

1. eBay搜索 "RedPocket $30 Plan GSMT"，购买（$30-45/年，可直邮中国，运费$17.9）
2. 发货后邮件收到Activation Code
3. 官网 redpocket.com/activate 激活
4. 购买 $2 GSMT eSIM → 官网 Swap to eSIM

**方式二：直接买eSIM再转套餐**

1. 官网购买 $10/月 GSMT eSIM 激活
2. eBay购买 $30/年 Activation Code
3. 官网填入PIN Code转年付套餐

### 注意事项

- 选 **GSMT 网络**（T-Mobile），才支持eSIM和WiFi Calling
- 新激活卡需**联系在线客服**开通WiFi Calling（支持中文）
- 每年续费一次，建议到期前几天再续

## 五、常见问题

**Q：国内使用需要翻墙吗？**
A：接收短信不需要。但激活和WiFi Calling可能需要科学上网环境。

**Q：号码会被回收吗？**
A：giffgaff每180天有消费就不会；RedPocket每年续费即可。

**Q：可以用来注册ChatGPT/OpenAI吗？**
A：英国号和美国号都可以，比虚拟号（Google Voice）稳定得多。

**Q：PIN码是多少？**
A：giffgaff默认5555；RedPocket不需要。

**Q：怎么查自己的号码？**
A：giffgaff发短信 "NUMBER" 到 2020 或 43430。
