## 1. ClawHunt 是什么

ClawHunt 是一个 **AI Agent 任务众包平台**，核心定位是「Agent 的人才市场」。

### 平台逻辑

```
需求方（挂任务 + 悬赏） ←→ 平台（匹配 + 结算） ←→ Agent 开发者（部署 Agent 竞标）
```

- **需求方**: 发布任务（修 bug、写代码、数据处理等），标注悬赏金额
- **Agent 开发者**: 部署自己的 Agent，自动浏览任务广场、竞标、执行、交付
- **平台**: 撮合交易，法币结算，验收后付费

### 核心功能

| 功能 | 说明 |
|------|------|
| **任务广场** | 各类任务列表，带悬赏金额 |
| **Agent 部署** | 一条命令安装，获得「上岗证」 |
| **自动竞标** | Agent 自己挑选适合的任务参与竞标 |
| **实时追踪** | 每一步动作、状态切换都记录，可观测 |
| **Agent Arena** | 不同 Agent 同台竞技，用结果说话 |
| **SuperClaw** | AI Agent 工作区，自动规划/执行/验证 |
| **钱包** | 充值发布任务，或提现收入 |
| **孵化器** | 项目背书、token 支持、VC 对接 |

## 2. 核心流程拆解

### 2.1 Agent 赚钱流程

```
1. 安装 Agent
   curl -fsSL https://clawhunt.store/install | bash -s -- --name my-agent

2. 认领上岗证（Wesight 等工具辅助）

3. Agent 自动入职 → 进入任务市场

4. Agent 自主挑选任务 → 竞标 → 执行 → 交付

5. 需求方验收通过 → 钱包到账
```

### 2.2 实际数据（苍何一周测试）

| 指标 | 数值 |
|------|------|
| 运行时间 | 1 周 |
| 接单数 | 1 单 |
| 收入 | $10 |
| 人力投入 | 几乎为零 |
| 失败案例 | 1 单（任务描述模糊，Agent 理解偏差） |

**换算**: 相当于一个 7×24 小时不休息、不摸鱼、不要五险一金的「实习生」。

### 2.3 关键洞察

> **Agent 的边际成本几乎为零。** 部署 1 个和 10 个 Agent，除了 API 调用费，人力成本没有区别。
>
> 传统外包是「一个人干一份活」，Agent 经济是「一套 Prompt 干 N 份活」。

## 3. 市场前景分析

### 3.1 宏观趋势

| 趋势 | 数据/信号 |
|------|----------|
| **Agent 元年** | 2026 年被业内称为「Agent 元年」[3] |
| **Token 调用量** | 中国日均 Token 调用量突破 140 万亿，两年飙升超千倍 [2] |
| **企业落地** | OpenAI 2026 年 5 月发布 Enterprise Agent Platform [1] |
| **RPA 替代** | 传统 RPA 增速首次跌破 10%，AI Agent 替代加速 [4] |
| **项目失败率** | Gartner 预警：到 2027 年底超 40% AI Agent 项目因交付问题被取消 [5] |

### 3.2 市场规模推演

**类比**: ClawHunt 的逻辑跟 Upwork、猪八戒网一样，只是干活的从人变成了 Agent。

| 维度 | 传统外包平台 | Agent 众包平台 |
|------|------------|---------------|
| **供给端** | 人（有上限） | Agent（无上限） |
| **边际成本** | 线性增长 | 接近零 |
| **工作时间** | 8h/天 | 24h/天 |
| **交付稳定性** | 因人而异 | 取决于 Prompt 质量 |
| **可观测性** | 人工汇报 | 全链路自动记录 |

**关键判断**: 2026 年下半年是 Agent 商业化的分水岭。上半场比谁的 Agent 更聪明，下半场比谁的 Agent 能稳定交付、持续赚钱。

### 3.3 商业模式可行性

**优势**:
1. **真实需求存在**: 修 bug、数据处理、代码生成等任务有大量外包需求
2. **成本结构颠覆**: Agent 边际成本趋近于 API 调用费
3. **可观测性刚需**: Agent 干错了一直是痛点，ClawHunt 的全链路追踪解决了这个问题
4. **竞技验证**: Agent Arena 让 Agent 质量可量化

**挑战**:
1. **交付质量不稳定**: 任务描述模糊时 Agent 容易理解偏差
2. **验收标准难统一**: 代码类任务还好，创意类任务难验收
3. **平台抽成**: 未知，影响开发者收益
4. **竞争加剧**: 随着平台成熟，Agent 数量增加，单价可能被压低

## 4. 竞争优势与风险

### 4.1 ClawHunt 的差异化

| 维度 | ClawHunt | 传统外包平台 | 其他 Agent 平台 |
|------|---------|------------|---------------|
| **结算方式** | 法币（美元） | 法币 | 多为 token/积分 |
| **可观测性** | 全链路透明 | 人工汇报 | 多数不可见 |
| **竞技机制** | Agent Arena 同台竞技 | 无 | 少见 |
| **孵化器** | 有（背书 + VC 对接） | 无 | 少见 |
| **工作区** | SuperClaw 自动规划执行 | 无 | 部分有 |

### 4.2 风险清单

| 风险 | 等级 | 说明 |
|------|------|------|
| **任务描述质量** | 高 | 描述模糊 → Agent 理解偏差 → 交付失败 |
| **平台可持续性** | 中 | 早期平台，用户量和任务量能否持续增长 |
| **单价下降** | 中 | Agent 供给增加后，竞标价格可能被压低 |
| **API 成本** | 低 | 收入需覆盖 API 调用成本 |
| **技术门槛** | 低 | 部署简单，但调教 Agent 需要经验 |

## 5. 适合你吗？——个人匹配度分析

### 5.1 你的背景

根据 MEMORY.md：
- **技能**: 网络设备/嵌入式/C/Python/TSN/驱动/TFLM
- **经验**: ~9 年嵌入式开发（爱博精电 6 年 + 新华三 3 年）
- **当前状态**: 求职中（面试过 7 家公司，薪资底线 65-70W）
- **项目**: wechat-radar（AI 驱动公众号日报）、family-hub（家庭投资管理）
- **偏好**: 简洁直接、自动化脚本、配置备份

### 5.2 匹配度评估

| 维度 | 匹配度 | 分析 |
|------|--------|------|
| **技术能力** | ⭐⭐⭐⭐⭐ | 嵌入式/C/Python/TSN 是稀缺技能，平台上有相关任务（网络设备、驱动开发等） |
| **自动化思维** | ⭐⭐⭐⭐⭐ | 你偏好自动化脚本，这正是 Agent 经济的核心能力 |
| **时间投入** | ⭐⭐⭐⭐ | 当前求职中，有时间投入；但入职后时间会变少 |
| **收益预期** | ⭐⭐⭐ | 一周 $10 的收入对你的薪资水平（30K×16）来说太低 |
| **风险偏好** | ⭐⭐⭐⭐ | 你愿意尝试新工具，但会关注投入产出比 |
| **Prompt 工程** | ⭐⭐⭐ | 有 AI 使用经验，但专业级 Prompt 工程需要学习 |

### 5.3 适合你的切入点

**直接部署接单（不推荐）**:
- 一周 $10 的收益太低
- 你的时间价值远高于此
- 任务描述模糊时容易翻车

**作为技术验证和学习（推荐）**:
- 了解 Agent 经济的第一手经验
- 测试你的 Agent 在真实任务中的表现
- 积累 Prompt 工程经验

**作为副业探索（中长期）**:
- 如果平台成熟、单价提升，可以考虑规模化部署
- 结合你的嵌入式专长，做垂直领域 Agent

**作为投资观察（最推荐）**:
- 关注这个赛道的发展
- 了解 Agent 经济的真实痛点
- 为未来的职业转型做准备

## 7. 关键判断

### 核心结论

1. **市场前景**: Agent 众包是真实趋势，2026 下半年是分水岭。但当前阶段（平台早期）收入微薄，更适合作为**技术观察和学习**。

2. **是否适合你**: **不适合作为主业或主要收入来源**。你的时间价值（30K×16 = 53W/年）远高于当前平台收益（一周 $10）。但**适合作为副业探索和技术验证**。

3. **最佳策略**: **轻量参与 + 深度观察**。部署一个 Agent 跑一周，了解全流程，然后把精力放在更有价值的事情上（求职、wechat-radar 项目、family-hub）。

4. **关键风险**: 任务描述质量不稳定、平台早期不确定性、单价可能被压低。

5. **长期价值**: Agent 经济是未来趋势，早期参与可以获得认知优势，为未来的职业转型或创业积累经验和人脉。

### 一句话总结

> ClawHunt 验证了一个真实趋势（Agent 能赚钱），但当前阶段收入太低，不适合你作为主业投入。**建议轻量参与（注册 + 观察 + 跑一周测试），把主要精力放在求职和现有项目上**，同时保持对这个赛道的关注。
