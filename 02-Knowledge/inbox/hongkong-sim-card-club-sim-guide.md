## 产品概述

**Club Sim** 是香港 CSL 旗下的虚拟运营商品牌，以**极低保号成本**著称，是目前最经济的香港手机号解决方案。

| 属性 | 内容 |
|------|------|
| **运营商** | 香港 CSL（香港最大移动网络运营商之一） |
| **月租** | 0 元（免月租） |
| **保号成本** | 每年 6 港币 |
| **收验证码** | 免费 |
| **信号覆盖** | 香港稳定，内地漫游可用 |
| **形式** | 实体卡 / eSIM 两种 |

---

## 核心优势

| 优势 | 说明 |
|------|------|
| **成本极低** | 6 港币/年 ≈ 人民币 5-6 元，比内地副号还便宜 |
| **免月租** | 无固定月租费用，按需付费 |
| **收码免费** | 内地漫游接收短信验证码免费 |
| **信号稳定** | 依托 CSL 网络，香港信号覆盖好 |
| **eSIM 支持** | 无需实体卡，在线申请即可使用 |
| **携号转入** | 支持从其他运营商携号转入 Club Sim |

---

## 申请条件与费用

| 项目 | 要求 |
|------|------|
| **开卡最低消费** | 50 港币 |
| **保号规则** | 每 365 天内至少购买一次服务组合 |
| **最便宜保号套餐** | 6 港币短讯组合（30 天有效期） |
| **实名认证** | 需要（香港身份证或护照） |

---

## 两种形式对比

| 形式 | 优点 | 缺点 | 适合人群 |
|------|------|------|----------|
| **实体卡** | 可插入任何手机，兼容性好 | 需要邮寄或线下取卡 | 没有 eSIM 功能的手机用户 |
| **eSIM** | 在线申请即时可用，无需等待 | 需要手机支持 eSIM 功能 | iPhone XS 及以上、主流安卓旗舰 |

## 使用场景

| 场景 | 用途 |
|------|------|
| **港美股开户** | 接收券商验证码（嘉信、IBKR、第一证券等） |
| **境外服务注册** | PayPal、Wise、ChatGPT 等需要境外手机号 |
| **多平台店铺** | 跨境电商、多账号运营 |
| **隐私保护** | 隔离内地手机号，保护隐私 |
| **旅行备用** | 香港旅游、出差时本地号码 |

---

## 功能限制

| 限制 | 说明 |
|------|------|
| **内地通话** | ❌ 中国内地无通话功能（仅收短信） |
| **内地流量** | ❌ 内地漫游无流量（或需额外购买） |
| **香港本地** | ✅ 香港境内可通话、可上网 |

---

## 申请流程（eSIM 版）

1. **下载 Club Sim App**（iOS / Android）
2. **选择 eSIM 开卡**
3. **完成实名认证**（护照或香港身份证）
4. **支付最低 50 港币**（可购买流量包或通话包）
5. **下载 eSIM 配置文件**到手机
6. **激活使用**

---

## 保号操作

| 时间 | 操作 |
|------|------|
| **每年一次** | 购买任意服务组合（最便宜 6 港币短讯组合） |
| **提醒** | Club Sim App 会提前提醒续期 |
| **失效风险** | 超过 365 天未消费，号码会被回收 |

## 注意事项

1. **实名认证**: 需要护照或香港身份证，内地身份证可能无法通过
2. **eSIM 手机要求**: 确认手机支持 eSIM（iPhone XS 及以上、Pixel、部分三星/小米旗舰）
3. **内地使用限制**: 仅可收短信，不能打电话/上网（除非额外购买漫游包）
4. **保号提醒**: 设置日历提醒，每年至少消费一次 6 港币
