## 2. 行业整体趋势

### 关键数据

| 指标 | 数据 |
|------|------|
| **招聘增长** | 2026 年 1-4 月具身智能招聘指数较 2025 年暴增 **15 倍** |
| **平均月薪** | **6.2 万元**（具身智能领域） |
| **薪资集中区间** | 47.6% 岗位集中在 **20-50K/月** |
| **应届起薪** | 约 15.4K/月 |
| **3-5 年经验** | 可达 22.6K/月 |
| **融资热度** | 2026 开年第一周多家公司获融资，银河通用获 **25 亿** 开年最大融资 |
| **IPO 趋势** | 超 20 家 IPO 倒计时，银河通用、星海图等已完成股改，最新轮被视为 Pre-IPO 轮 |
| **百亿估值公司** | 宇树科技、智元机器人、银河通用（2025 年已突破） |

### 核心判断

> 2026 年是具身智能「上市大年」，也是「招聘大年」。国家大基金首次重仓押注具身智能赛道，资本和人才都在快速涌入。
