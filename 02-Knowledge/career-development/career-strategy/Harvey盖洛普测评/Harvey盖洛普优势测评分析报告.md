## 二、测试前注意事项（重点）

> 以下为用户提供的官方测评须知，测前务必通读。

1. **时长与环境**：本次测评共 200 道题，注册账号 + 完成测试约需 30–60 分钟，请找安静的地方进行。
2. **选本能而非理想**：尽量避免选中立选项，优先选那些你"本能、不自觉就会这样想或做"的答案——而非后天训练、别人教导、刻意压抑，或你"希望成为的样子"。相信真实的你依然很出色。
3. **节奏限制**：每道题 20 秒时间限制，超时自动进入下一题，**不能返回重答**；不答也是一种结果，会被系统记录。
4. **设备与浏览器**：手机电脑都能做，推荐使用**谷歌浏览器（电脑版）**以提升流畅度。
5. **中途退出**：有事退出后重新进入，会按原进度继续测评。
6. **状态影响**：测评者本人状态可能对结果有影响，尽量选**心情平静**时测，忌大悲大喜。
7. **不被定义**：盖洛普很多题并不是对立的，不必担心被测试定义——你的独特无法被定义，把它当工具参考就好。
8. **语言选择**：支持多语言，网页右上角可选国家/语言；题目为英文直译，英语好建议**用英文测评**以便更精准理解题意。
9. **测评码有效期**：官方目前未设过期，但建议尽早测（半年内）。

## 三、测评说明（分析基准）

盖洛普 CliftonStrengths 将人的才干分为 **34 个主题**，按 4 大领域归类。分析时以 **前 5 / 前 10 才干** 为核心优势，并关注**弱势领域**（排序靠后的领域）带来的盲区。

| 领域（中文） | 领域（英文） | 典型含义 |

| 执行力       | Executing   | 把事做成、落地、推动 |
| 影响力       | Influencing | 表达、说服、掌控局面 |
| 关系建立     | Relationship Building | 联结人、建立信任、凝聚团队 |
| 战略思维     | Strategic Thinking | 分析、前瞻、收集与判断 |

## 六、分项分析（已填充）

> 分析定位：不堆砌测评原话，结合用户画像（~9 年嵌入式 / 端侧 AI / PL 管理 / 北京海淀）给**可落地、且带批判**的建议。

### 6.1 优劣势分析

**组合效应（优势如何互相放大）**
- 纪律 + 成就 + 专注 + 责任 + 统筹（前 10 几乎全是执行力）→ 一台**极端可靠的"交付机器"**：定计划、拆解、死磕、按时交付、还能调度资源。
- 叠加审慎 → 交付**可控、低风险**；叠加和谐 + 公平 → 团队协作顺滑、制度公平，别人愿意跟你干。
- 在嵌入式 / 端侧 AI 部署这类"执行密集 + 不容出错"的活上，这套组合**如鱼得水**。

**真实盲区与风险场景（不讨好，照敲）**
- **影响力缺失 → "做得多、说得少"**：面试容易闷头讲技术细节、讲不出"我带来了什么影响"；谈薪偏软、不敢要价；做技术负责人时靠"把事做好"服人，但缺"靠愿景号召人"的气场。
- **战略思维末端 → 容易陷在执行里**：对市场 / 技术大方向判断弱，依赖"学习#9"补课，但"学"不等于"想明白"。典型场景：埋头把产品做完美（完美#19 + 成就），却没先验证"这事值不值得做"。
- **审慎 + 和谐 + 公平 三重叠加 → 过度求稳**：该拍板时求共识、流程重于结果、回避必要冲突，可能**错失时间窗**。
- **成就 + 纪律 盲点 → 工作狂**：用"忙"定义自我价值，挤压家庭 / 健康 / 战略思考时间。
- **与职业画像的冲突点**：嵌入式底层 + 端侧 AI 部署高度契合（执行力主场）；但 PL / 架构师进阶需要**影响力 + 战略思维**，正好是你的短板 → **进阶瓶颈在此，不在技术能力**。

### 6.2 职业发展建议

**优先争取的岗位（吃你的优势）**
- 高级嵌入式 / 端侧 AI **部署工程师**、系统 / 可靠性工程师、技术 **PL（项目牵头人）**、质量 / 流程负责人。
- 与「端侧 AI 攻略」目标（海淀 / 昌平 资深 / TL）高度匹配：本质是"把模型 / 系统可靠落地"，正是执行力主场。

**简历 / 面试话术落点**
- 强调"可靠交付 + 风险管控（审慎）+ 流程公平（公平 / 统筹）"，用**结果和影响**包装，而不只是"我做了什么"。

**需补位 / 避免的场景**
- 避免纯售前 / BD / 战略岗。
- 若想走到**架构师 / 技术管理者**，必须刻意补两项：①影响力（向上管理、跨部门推动、谈薪底气）；②战略思维（技术选型判断、行业前瞻）。否则会卡在高级 IC，上不去。

**具体动作**
1. 用**学习#9**系统学"技术战略 / 架构前瞻"，补战略短板（学 ≠ 想，要刻意练"定方向"）。
2. 每次复盘 / 述职，刻意练"把成果讲成影响力"。
3. 找一位**影响力强**的搭档 / 导师互补，别一个人硬扛。

### 6.3 创业建议

**适合的角色**
- **技术合伙人 / COO 型**（管交付、管流程、管风险），**不是对外 CEO**（融资 / 销售 / 站台）。

**最可能翻车的短板与对冲**
- 翻车点①市场验证弱（取悦 / 沟通 / 战略低 → 客户洞察与 pitching 弱）→ 容易"埋头把产品做完美但没人要"。**对冲**：先小步验证需求，再扩投入；把"卖"交给互补合伙人。
- 翻车点②审慎过度 → 犹豫错过窗口。**对冲**：给自己设"决策截止线"，信息够 70% 就动。
- 翻车点③和谐 → 不愿对合伙人 / 投资人亮底牌冲突，埋雷。**对冲**：把关键分歧白纸黑字写进协议。
- 翻车点④谈条件软（自信 / 统率 / 追求低）→ 估值 / 条款吃亏。**对冲**：谈前做功课、定底线，必要时让互补方出面。

**你的真实创业优势**
- 纪律 + 成就 → 最快把 MVP 跑通的护城河；审慎 → 控现金流风险（这是你比很多"画饼型"创始人强的地方）；学习 → 快速补行业 / 商业认知。

**结论**：能成"靠谱的执行型联合创始人"，**难成独狼创始人**。若单干，先把"卖"和"想"外包 / 合伙。

### 6.4 家庭建议

**优势用法**
- 和谐 + 公平 → 家庭气氛平和、规则分明、待人公正，孩子在"可预测环境"里长大；责任 + 纪律 → 对家庭可靠守信。

**需刻意规避的沟通雷区**
- **和谐盲点**：回避必要冲突 → 钱、分工、育儿分歧被压着不谈，长期发酵。→ 主动约定"定期把矛盾摆上桌面"。
- **审慎盲点**：情感内敛、慢热 → 伴侣可能觉得"你不说爱 / 不肯定我"。→ 你沟通#29 低，不能指望对方"懂你"，要**练说**、增加言语肯定。
- **成就 + 纪律盲点**：工作狂 → 家庭时间被挤压。→ 用"责任"的检查日程习惯，把家庭时间也排进待办并守住。
- **公平盲点**：对家人"一视同仁"机械化 → 忽略个体需求差异（孩子 / 伴侣各不同）。

**协作建议（待爱人测评后填第七节）**
- 你主"执行 + 风控 + 公平"；若爱人偏影响力 / 战略思维则完美互补；若也偏执行，则可能"两人都闷头干、没人抬头看路"，需外部补战略（见 6.3）。
