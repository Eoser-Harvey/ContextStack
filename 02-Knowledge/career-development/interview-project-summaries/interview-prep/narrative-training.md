## 一、历史反思整合

### 九号公司教训（2026-06）
**核心问题**：回答停留在"知识复述"层面，8年经验被按3年标准评估。

> "每道题都知道，但没达到面试官预期"

**根因**：没展现资深工程师的思考深度和工程判断力。

### 思朗科技反思（更早）
**核心发现**：面试官想看的顺序错了——我最先讲的不是他们最想听的。

> 你应该展示的顺序（最重要→次重要）：
> 1. 算法/模型工程化落地、性能优化（最值钱）
> 2. 产品全流程、量产经验、控项目
> 3. 带团队、PL、任务拆解、质量把控
> 4. 大公司流程体系、建规范

**当时定下的行动**（部分已搁置）：
- 端到端推理流程：模型训练→量化→转换→部署
- 性能优化目标：推理延迟≤10ms，内存≤100KB
- GitHub 开源代码 + README 说明
- 3篇技术博客 → 建立技术标签

## 三、核心方法论：四层叙事框架

每个技术问题、项目介绍都按这个结构回答：

```
问题本质（一句话点出核心）
    ↓
我的实践（真实项目 + 具体数据）
    ↓
踩过的坑（区别于普通工程师的关键）
    ↓
我的思考（展现学习能力和技术判断力）
```

### 示例：自研RTOS

**问："你做过RTOS开发？"**

| 普通回答 | 工程叙事 |
|---------|---------|
| "做过，自己写过一个RTOS，有任务调度、信号量、中断管理" | 「RTOS本质是资源受限场景下的确定性调度。我在爱博精电时从头写过一个：内核10KB、零任务40KB、创建32任务只增0.4KB——比μC/OS和FreeRTOS都轻。踩过的坑：优先级反转的链式问题，两个任务分别持有不同资源互相等，后来在编码规范里禁止锁内调等待函数才解决。学到的是：RTOS不是代码量问题，是确定性保障问题——你能不能让一个中断响应永远在5μs内完成。」 |

## 四、7天集中训练计划

每天两段式：
- **晨学（30分钟）**：基础知识系统补强（ARM架构/C语言/RTOS/CPU底层轮转）
- **晚练（30分钟）**：项目叙事训练（本质→实践→坑→思考）

### 📚 基础知识主题轮转（7天覆盖 4 大模块）

| 模块 | 覆盖天数 | 重点子主题 |
|------|:--:|------|
| **ARM 架构** | Day 1, 5 | 流水线/工作模式/寄存器/中断向量表/Cache/MPU/MMU |
| **C 语言底层** | Day 2, 6 | volatile/static/const/字节对齐/指针函数/sizeof陷阱 |
| **RTOS / OS** | Day 3, 7 | 调度算法/上下文切换/死锁/内存管理/进程线程 |
| **CPU 底层** | Day 4 | Cache一致性/DMA协同/内存屏障/原子操作 |

### Day 1：自研RTOS系统
**🌅 晨学（ARM架构-上）**
- ARM Cortex-M 三级流水线（取指→译码→执行）及五级流水线扩展
- 7种工作模式（User/FIQ/IRQ/Supervisor/Abort/Undefined/System）
- 37个寄存器组成（R0-R15 + CPSR + SPSR），不同模式下寄存器banking
- ARM vs Thumb 指令集区别
- 练习：手绘 ARM 寄存器组图 + 解释模式切换场景
- 📖 参考：[ARM体系与架构面试题](https://jishuzhan.net/article/2012686761693593602)

**🌙 晚练（项目叙事）**
- **关键数据**：10KB/40KB/0.4KB
- **核心叙事**：从零搭建 → 性能指标 → 踩坑 → 方法论沉淀

### Day 2：DSP双核AMP架构（SC573）
**🌅 晨学（C语言底层-上）** — 九号暴露的薄弱点！
- `volatile` 三场景三误解（寄存器/ISR变量/内存映射IO ≠ 原子性/线程安全/内存屏障）
- `const volatile` 共存场景（只读硬件状态寄存器）
- `static` 三种语义（函数内持久/文件内隐藏/全局不可外链）
- 练习：用「本质→实践→坑→思考」口头回答每个概念
- 📖 参考：[嵌入式C语言30个高频考点](https://yunpan.plus/t/4039-1-1)

**🌙 晚练（项目叙事）**
- **关键数据**：跨核通信≤10ms，DSP跑RTOS+A5跑Linux
- **核心叙事**：为什么选这架构 → 双核通信方案 → 中断驱动+共享内存 → 踩坑

### Day 3：TSN时间敏感网络交换机
**🌅 晨学（RTOS-上）**
- 任务调度算法对比：优先级抢占 vs 时间片轮转 vs 合作式
- 上下文切换流程（保存→选择→恢复，PendSV的作用）
- 优先级反转三种解决方案（继承/天花板/编码规避）+ 火星探路者案例
- 死锁四必要条件 + 银行家算法概念
- 练习：画上下文切换流程图，讲清楚 PendSV 为什么是最低优先级
- 📖 参考：[FreeRTOS调度与优先级反转详解](https://www.nowcoder.com/discuss/808356304229003264)

**🌙 晚练（项目叙事）**
- **关键数据**：802.1Qbv/AS/Qci/Qbu/CB/Qcc 六个协议、环网≤20ms
- **核心叙事**：TSN要解决什么 → 怎么协同6个协议 → 踩坑 → 行业价值

### Day 4：DSP算法优化
**🌅 晨学（CPU底层）**
- Cache 一致性问题（写透/写回、Cache Flush/Invalidate 时机）
- DMA 与 CPU 协同（DMA 前后必须操作 Cache）
- 内存屏障（DMB/DSB/ISB 三条指令的区别与使用场景）
- 原子操作原理（LDREX/STREX 独占访问）
- 练习：解释「DMA传输后CPU读到旧数据」的根因和解决步骤
- 📖 参考：[ARM硬件笔试面试题型](https://zhuanlan.zhihu.com/p/1916057165761840418)

**🌙 晚练（项目叙事）**
- **关键数据**：FFT/均方根/滤波/插值 汇编优化 + FIR/IIR/FFT硬件加速器
- **核心叙事**：算法瓶颈在哪 → 汇编+硬加器方案 → 效果数据 → 可复用方法论

### Day 5：电力监控仪表 + DMA优化（爱博精电）
**🌅 晨学（ARM架构-下）**
- Cortex-M 中断向量表结构（前16个系统异常 + 外设中断）
- NVIC 中断优先级分组（抢占优先级 vs 子优先级）
- MPU（内存保护单元）vs MMU（内存管理单元）— 区别和应用场景
- HardFault 常见原因：非对齐访问/非法内存/未定义指令/除零
- 练习：手绘中断向量表 + 解释 HardFault 定位四步法
- 📖 参考：[Cortex-M面试核心考点](https://www.nowcoder.com/discuss/725288479193624576)

**🌙 晚练（项目叙事）**
- **关键数据**：DMA链式传输替代CPU轮询，CPU负载率 90%→47%，高实时性 20ms 周期
- **核心叙事**：CPU瓶颈在哪 → DMA链式方案设计 → 踩坑（DMA与Cache一致性）→ 实时性保障思维

### Day 6：低成本L2交换机（新华三）
**🌅 晨学（C语言底层-下）**
- 字节对齐原理 + `#pragma pack` 副作用 + 0x69a9→HardFault 九号真题
- 指针函数 vs 函数指针（声明区别 + 使用场景：回调/解耦/状态机）
- `sizeof` 数组在函数参数中的陷阱（退化为指针）
- 结构体内存布局（对齐规则、填充字节、`__attribute__((packed))`）
- 练习：写一个包含 char/int/short 的结构体，手工计算 sizeof
- 📖 参考：[嵌入式C语言面试常考题](https://www.nowcoder.com/discuss/841222926857666560)

**🌙 晚练（项目叙事）**
- **关键数据**：降本30%、RTL MAC+C51方案、WEB管理+云端纳管
- **核心叙事**：为什么选廉价方案 → 驱动→BOOT→量产全流程 → 降本30%怎么做到的 → 产品价值

### Day 7：PL管理经验（跨项目综合）
**🌅 晨学（RTOS-下）**
- 内存管理：静态内存池 vs 动态堆分配（确定性 vs 灵活性）
- FreeRTOS 五种堆方案 (Heap_1~5) 区别与选型
- 任务间通信全景：队列/信号量/互斥锁/事件组/任务通知（各自动用场景）
- 中断下半部机制（Tasklet/工作队列，嵌入式中的 Deferred Interrupt 处理）
- 练习：画任务通信全景图，标注每种机制的典型使用场景
- 📖 参考：[技术面试知识点总汇](../技术面试知识点总汇.md) 第一节

**🌙 晚练（项目叙事）**
- **关键数据**：5人团队、培养3骨干、IPD流程
- **核心叙事**：带团队的核心 → 建规范+拆任务+控风险 → 培养人的方法论

## 五、面试展示顺序（固化思朗反思）

无论面什么岗位，自我介绍和项目介绍的顺序固定为：

```
1. 核心能力（最对口的那一项，打面试官的第一印象）
   例：面MCU驱动岗 → 先讲 RTOS/底层驱动
   例：面TSN相关岗 → 先讲 TSN协议栈
   
2. 项目成果（数据说话，证明你能落地）
   
3. PL管理（加分项，证明你不是一个人干活的）
   
4. 工程体系（证明你在流程规范上的积累）
```
