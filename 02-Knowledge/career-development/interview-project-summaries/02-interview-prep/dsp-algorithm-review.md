## 〇、FIR vs IIR（滤波器第一问，必考）

### 0.1 分别是什么

| | FIR | IIR |
|:--|:----|:----|
| 全称 | 有限冲激响应 Finite Impulse Response | 无限冲激响应 Infinite Impulse Response |
| 结构 | 只有**前馈**，无反馈 | 有**反馈**，输出回送 |
| 差分方程 | `y[n] = Σ b_k·x[n-k]`（只依赖输入） | `y[n] = Σ b_k·x[n-k] + Σ a_j·y[n-j]`（还依赖过去输出） |
| 冲激响应 | **有限长**（N 拍后归零） | **无限长**（理论上衰减不完，永远有尾巴） |
| 本质 | 卷积 | 带递归的差分方程 |

### 0.2 四大区别（背）

| 维度 | FIR | IIR |
|:-----|:----|:----|
| 反馈 | 无 | 有 |
| 相位 | **可严格线性相位**（系数对称） | 非线性相位（需补偿） |
| 稳定性 | **永远稳定**（无极点） | 可能不稳定（极点出单位圆） |
| 同指标阶数 | 高（系数多） | **低（效率高）** |

### 0.3 应用层面怎么选（⭐ 面试官就爱问这个）

**核心一句话：FIR 保波形，IIR 省算力。**

**FIR 用在「要保波形形状」的场景**——线性相位 = 不同频率延迟相同 = 波形不畸变：
- 工频提取（要基波波形）
- 通信脉冲整形（码间串扰敏感）
- 音频 / 图像（相位失真敏感）

**IIR 用在「要省算力 / 匹配标准规定模拟滤波器」的场景**——阶数低、乘加少：
- 闪变仪滤波器组（IEC 标准规定 Butterworth 特性，用 IIR 精确逼近）
- 控制环路的简单补偿滤波
- MCU 上资源受限的简单低通（一阶 IIR 只需一个系数）

**工程例子（结合我的项目）**：
- 电能质量：工频提取用 **FIR**（线性相位保波形）、闪变仪用 **IIR**（标准规定 Butterworth）
- 激光：功率/温度采样简单去噪 → 一阶 IIR `y[n] = α·x[n] + (1-α)·y[n-1]`（一个系数极省）；要保波形/严格线性相位 → FIR

**选型口诀（脱口）**：
> 要波形 → FIR（线性相位、稳定、阶数高）；要省算力 / 匹配模拟原型 → IIR（阶数低、效率高、相位非线）。

## 一、FFT 谐波分析

### 1.1 从 DFT 到 FFT（原理）

**DFT 定义**：把 N 点时域信号变换到频域

```
X[k] = Σ_{n=0}^{N-1} x[n] · e^(-j2πkn/N)，k = 0..N-1
```

- 直接算 DFT 是 **O(N²)** 次复数乘加
- **FFT 是 DFT 的快速算法**（基 2 蝶形运算，利用 e^(-j2πkn/N) 的周期性和对称性），复杂度降到 **O(N·log₂N)**
- 基 2 FFT 要求 **N = 2 的幂**（1024、2048…）

**频率分辨率**：`Δf = fs / N`（采样率 ÷ 点数）。这是理解后面所有「泄漏/栅栏」的钥匙。

### 1.2 谐波分析怎么用

- 电力基波 50Hz，**n 次谐波 = n × 50Hz**（2 次 100Hz、3 次 150Hz…）
- FFT 得到各频率谱线 → 取各次谐波的**幅值 + 相位**
- **THD（总谐波畸变率）**：`THD = √(V₂²+V₃²+…)/V₁ × 100%`，衡量波形畸变程度
- 电能质量国标要求测到 **50 次谐波**（2.5kHz），所以采样率至少 5kHz 以上（留奈奎斯特余量）

### 1.3 三大频域问题（MS 必问，讲不清 = 没做过）

| 问题 | 成因 | 现象 | 解法 |
|:-----|:-----|:-----|:-----|
| **频谱泄漏** | 非整周期截断（信号频率不是 Δf 的整数倍） | 单根谱线能量「漏」到周围多根谱线 | **加窗**（Hanning 等）压低旁瓣 |
| **栅栏效应** | FFT 只在离散点 Δf 整数倍处取值 | 像隔栅栏看频谱，可能漏掉栅栏间的峰值 | **插值** / 补零加密谱线 |
| **混叠** | 采样率 < 2×最高频率（奈奎斯特） | 高频成分折叠回低频，无法区分 | **抗混叠低通滤波**（ADC 前模拟滤波）+ 足够采样率 |

### 1.4 加窗（为什么 + 怎么选）

- **为什么加窗**：FFT 假设信号是周期重复的，实际截断的一段若首尾不连续，就相当于乘了个矩形窗 → 旁瓣泄漏
- **窗函数权衡**：矩形窗主瓣窄（分辨率高）但旁瓣高（泄漏大）；**Hanning 窗主瓣宽（分辨率降）但旁瓣低（泄漏小）**
- **我的选择**：谐波分析要的是「各次谐波幅值准」，不是「频率分辨率极高」，所以用 **Hanning**——牺牲一点分辨率换泄漏抑制

### 1.5 我的项目（MS 话术）

> 「电能质量分析仪测谐波，我用的 FFT + Hanning 窗。核心挑战是电网频率不是精确 50Hz（在 49.5~50.5 波动），固定采样率就会非整周期采样 → 频谱泄漏。所以我配合了插值重采样（见第四节）先把信号重采样到整周期，再 FFT，保证各次谐波幅值相位测得准，最后算 THD。」

## 二、闪变测量（IEC 61000-4-15，IIR 滤波器组）

### 2.1 闪变是什么（先理解物理意义）

- **闪变（flicker）**：电压波动引起灯光亮度变化，**人眼-大脑-灯泡系统**对这种低频电压波动（0.5~35Hz 调制）的感知
- 它不是单纯的「电压波动」，而是「人眼感知到的亮度闪烁」——所以测量模型要模拟人眼响应

### 2.2 IEC 61000-4-15 闪变仪 = 一组标准规定的 IIR 滤波器（核心）

闪变仪是标准规定传递函数的信号处理链，分 5 个模块：

```
输入电压 u(t)
  │
  ├─ ① 平方解调：u²(t) → 提取出电压波动的包络（调制信号）
  │
  ├─ ② 滤波器组（模拟人眼响应，全是标准规定的传递函数）：
  │       · 高通滤波器（一阶，截止 0.05Hz）去直流漂移
  │       · 低通滤波器（6 阶 Butterworth，截止 35Hz）去高频
  │       · 加权滤波器（人眼-灯泡加权，8.8Hz 附近灵敏度最高）
  │
  ├─ ③ 平方 + 一阶低通平滑：模拟人脑的记忆/积分效应
  │
  └─ ④ 统计分析（累计概率 CPF）→ Pst（短时 10min）/ Plt（长时 2h）
```

**关键点（MS 必答）**：闪变仪的「IIR 滤波器组」不是随便选的低通，是 **IEC 61000-4-15 标准明确规定了每个滤波器的传递函数**（0.05Hz 高通、6 阶 Butterworth 35Hz 低通、人眼加权滤波器），要实现合规的闪变测量就必须精确复现这组滤波器。

### 2.3 为什么闪变用 IIR 不用 FIR（高频追问）

- 标准规定的是**模拟滤波器原型**（Butterworth 等），要精确匹配它的幅频/相频特性
- **IIR 阶数低、效率高**，能用几阶就精确逼近标准规定的模拟滤波器特性（双线性变换从模拟原型设计数字 IIR）
- FIR 要达到同样的陡峭截止需要几十上百阶，算力浪费

### 2.4 Pst / Plt

- **Pst（short-term flicker severity）**：10 分钟短时闪变严重度，从累计概率统计（CPF）算
- **Plt（long-term）**：2 小时长时闪变，由 12 个连续 Pst 计算：`Plt = ³√(Σ Pstᵢ³ / 12)`

### 2.5 我的项目（MS 话术）

> 「闪变测量我按 IEC 61000-4-15 标准实现——核心是一组标准规定的 IIR 滤波器（0.05Hz 高通、6 阶 Butterworth 35Hz 低通、人眼加权滤波器），加平方解调和平滑，最后统计出 Pst/Plt。这让我对『用 IIR 精确复现标准规定的滤波器特性』有实操经验，和激光器温控里设计数字补偿滤波器是同一套设计方法。」

## 三、工频提取与频率测量

### 3.1 工频（50Hz 基波）提取的几种方法

| 方法 | 原理 | 特点 |
|:-----|:-----|:-----|
| **带通滤波器** | 50Hz 带通（FIR）滤出基波 | 要线性相位保波形 → 用 FIR |
| **陷波滤波器** | 陷掉其他频率，保留 50Hz | 相反思路 |
| **过零检测** | 检测过零点 → 算周期 → f=1/T | 简单，但受噪声/过零抖动影响 |
| **Goertzel 算法** | 只算 50Hz 一个频点的 DFT | 比 FFT 高效（单频点） |

### 3.2 频率精确测量（电网频率会漂）

- 电网频率不是精确 50Hz，在 **49.5~50.5Hz 漂移**
- **过零检测**：简单直接，但过零点受噪声和波形畸变影响，抖动大
- **DFT 插值**：FFT 后在 50Hz 附近谱线间插值，精确估计真实频率——精度远高于过零检测

### 3.3 我的项目（MS 话术）

> 「工频提取我用 FIR 带通（要线性相位保波形形状），频率精确测量用 DFT 插值而不是过零检测——过零检测受噪声和过零抖动影响精度不够，插值能精确估出 49.98Hz 这种漂移值，这对后续谐波分析的整周期采样很重要。」

## 四、插值重采样

### 4.1 为什么需要（和第一节呼应）

- 电网频率漂移 → 固定采样率下，**每个基波周期不是整数个采样点** → FFT 非整周期截断 → **频谱泄漏**
- 两条解法：
  1. **同步采样**：锁相环（PLL）跟踪电网频率，动态调整采样率（硬件复杂）
  2. **插值重采样**：软件在原始采样点间插值，重采样到「每周期整数点」（软件灵活，我的选择）

### 4.2 插值原理

- 在原始采样点之间用**插值**（线性 / 多项式 / sinc）估计中间值，得到新的等间隔采样序列，使每个基波周期有整数个采样点
- 效果：消除非整周期采样导致的泄漏，谐波幅值相位测得准

### 4.3 我的项目（MS 话术）

> 「电网频率漂移导致固定采样率非整周期采样，FFT 会泄漏。我用软件插值重采样把信号重采样到整周期，再 FFT——比硬件锁相环同步采样灵活，成本低，精度够用。这个『采样率对齐』的思路，激光器多传感器数据融合（不同采样率对齐）也用得上。」

## 五、SHARC 硬件 FIR/IIR/FFT 加速器

### 5.1 SHARC DSP 为什么快（三件套）

| 硬件能力 | 作用 | 对应算法 |
|:---------|:-----|:---------|
| **单周期 MAC（乘累加）** | `acc += x[n]·b[k]` 一条指令完成 | FIR 卷积、IIR 差分方程 |
| **DAG 数据地址生成器** | 自动生成采样点地址 + **循环缓冲** | FIR 的延迟线（滑动窗口） |
| **bit-reverse 寻址** | FFT 蝶形运算的数据重排硬件直接支持 | FFT |

- 核心：**单周期完成一次 FIR tap 乘加**，比普通 CPU 的「load → 乘 → 加 → store」多指令流程快数倍
- 循环缓冲（DAG）让 FIR 的滑动窗口不用搬数据，指针自动绕回——这是 FIR 实时性的关键

### 5.2 硬件加速器 vs 纯软件

- 纯 CPU 循环：每个 tap 要 load 系数、load 样本、乘、加、store，好几条指令
- SHARC 加速器：MAC 指令单周期完成一次乘加，DAG 自动寻址，零开销循环 → 效率翻倍

### 5.3 我的项目（MS 话术）

> 「我在 SHARC DSP 上做 FFT 谐波分析、FIR/IIR 滤波，关键是把算法落到硬件加速器上——用单周期 MAC 做 FIR/IIR 的乘加、用 DAG 循环缓冲做 FIR 延迟线、用 bit-reverse 寻址加速 FFT 蝶形运算，再配合汇编优化，把整个 DSP 流水线效率拉满。这让我对『算法怎么映射到硬件加速』有实操理解——和现在端侧 AI 里 CPU/NPU 加速思路是相通的。」

## 六、汇编优化 + Cache 优化

### 6.1 汇编优化（DSP 的极致性能）

- 关键 DSP 循环用**汇编**写，利用 SHARC 专用指令（单周期 MAC、循环寻址、并行数据搬运）
- 手动软件流水（software pipelining）：重叠指令的取指/执行，隐藏延迟

### 6.2 Cache 优化（双核伪共享的坑）

- **ICache/DCache** 驱动产品化：DSP 的指令/数据缓存配置优化
- **双核伪共享（false sharing）**：两个核的数据落在同一个 Cache 行，一个核写导致另一个核的 Cache 行失效 → **性能降 40%**
- **解法**：关键数据 **64 字节对齐**（独立 Cache 行），避免伪共享

### 6.3 我的项目（MS 话术）

> 「DSP 性能优化我分两层：算法层用硬件加速器（FIR/IIR/FFT），代码层用汇编 + Cache 优化。踩过最典型的坑是双核伪共享——两个核的数据在同一 Cache 行，互相失效导致性能降 40%，用 64 字节对齐解决。这种『性能问题定位到 Cache 层』的能力，在实时性要求高的激光控制里同样关键。」

## 八、定点 vs 浮点（Q 格式 / 溢出 / 饱和）

> 2026-09-21 新增：主战场切到军工/航天后，定点/浮点是 DSP 理论面必考（简历有「汇编优化」必被深挖）

### 8.1 网上高频通用题（背熟）

#### 题 1：Q15 / Q31 格式是什么？范围多大？0x4000 表示多少？

**Q 格式 = 用整数模拟小数的定标法**，Qn 表示「小数点在第 n 位右侧」，即 n 位小数。

| 格式 | 结构 | 范围 | 真实值换算 |
|:--|:--|:--|:--|
| Q0 | 16 位纯整数 | -32768 ~ 32767 | 原值 |
| Q15 (Frac16) | 1 符号 + 15 小数 | **-1 ~ 0.9999695**（≈-1 ~ 1） | 存储整数 ÷ 2^15 |
| Q31 (Frac32) | 1 符号 + 31 小数 | -1 ~ 0.9999999995 | 存储整数 ÷ 2^31 |

- `0x4000`(16384) 在 Q15 里 = `16384 / 32768 = 0.5`
- `0x7FFF`(32767) = 0.99997；`0x8000`(-32768) = **-1**（注意：Q15 没有「+1」，这是补码特性）

**换算公式**：浮点→定点 `Xq = (int)(Xf × 2^Q)`；定点→浮点 `Xf = Xq / 2^Q`

---

#### 题 2：定点乘法的 Q 值怎么变化？Q15 × Q15 怎么办？

**口诀：加减同 Q，乘加 Q，除减 Q。**

- **加减**：必须同 Q 格式（Qx == Qz 才能直接加）
- **乘**：Q 值**相加** → `Qa × Qb = Q(a+b)`，例 `Q15 × Q15 = Q30`
- **除**：Q 值**相减** → `Qa ÷ Qb = Q(a-b)`
- **移位**：左移 1 位 = Q+1，右移 1 位 = Q-1

**Q15 × Q15 的经典坑**：
```
0.5 × 0.5 = 0.25
0x4000 × 0x4000 = 0x1000_0000   ← Q30，占 32 位
要存回 Q15，必须右移 15 位 → 0x2000 = 0.25 ✅
```
**关键**：两个 16 位相乘结果是 32 位，**中间必须用 32 位（或累加器）暂存**，再右移定标存回 16 位。如果直接截断 16 位，小数全丢。

---

#### 题 3：溢出分哪两类？「回绕」和「饱和」有什么区别？

**两类溢出**：
- **上溢（overflow）**：结果 > 能表示的最大值
- **下溢（underflow）**：结果 < 能表示的最小值（或小到被舍入成 0）

**两种处理（必背区别）**：

| | 回绕（wrap-around） | 饱和（saturation） |
|:--|:--|:--|
| 行为 | 直接截断，超出部分「绕圈」 | 钳位到边界值 |
| 例：32767+1 | **-32768**（正数变负数！） | **32767**（保持最大） |
| 例：255+1（uchar） | 0 | 255 |
| 危害 | 正变负、信号完全错误 | 只削顶，方向不反 |

**为什么饱和重要**：音频回绕 → 刺耳爆音；控制信号回绕 → 执行器反向、发散。所以 DSP 硬件都有「饱和模式」（saturation mode），溢出自动钳位。

---

#### 题 4：定点 DSP 和浮点 DSP 到底差在哪？怎么选？

| 维度 | 定点 | 浮点 |
|:--|:--|:--|
| 动态范围 | 小（Q15 只有 [-1,1)） | 大（指数表示，跨几十个数量级） |
| 精度 | 相对精度随幅度变（小信号量化误差大） | 相对精度恒定 |
| 溢出 | 极易（中间变量就要防） | 几乎不溢出 |
| 速度 | **快**（整数 ALU，单周期） | 慢（浮点 ALU 多周期） |
| 硬件 | **简单、便宜、功耗低** | 复杂、贵、功耗高 |

**选型一句话**：**要便宜/快/低功耗 → 定点（但要精心定标防溢出）；要动态范围/精度/开发快 → 浮点。**

---

#### 题 5：FFT 定点实现为什么溢出？1024 点需要几个保护位？怎么解？

**为什么会溢出**：FFT 每级蝶形运算最大放大 2 倍，**N 点 FFT 输出最大放大 N 倍**。1024 点 = 1000 倍增长。

**保护位**：要保证 1024 点 FFT 全程不溢出，需要 `log₂(1024) = 10` 个保护位 → 定点处理器字宽要跟着涨，不现实。

**三种解法（必背）**：

| 方案 | 做法 | 优劣 |
|:--|:--|:--|
| ① 每级定标 | 每级蝶形后右移 1 位（除 2） | 简单，但精度损失大（信号被量化噪声淹没） |
| ② **块浮点** | 整帧共享一个指数（绝对值最大数的指数），逐级判断移位 | **兼顾动态范围和精度，最常用** |
| ③ 浮点 | 直接浮点算 | 精度最高，硬件贵慢 |

**块浮点（block floating point）核心**：一组数据共用一个指数，只对尾数运算（和定点一样快），逐级做溢出判断决定是否统一移位——「定点的速度 + 浮点的动态范围」。

---

#### 题 6：滤波器中间变量溢出的「隐形坑」是什么？

经典案例（音频效果器）：输入 16 位 PCM，算法内部增益放大，你在**输出级加了限幅器**——但没用，因为**滤波器中间累积变量（Q15）在内部就已经溢出回绕了**，数据从算法内部就错乱了。

**结论**：溢出要防在**中间节点**（滤波器累加器、增益级、FFT 每级），不是只在输入/输出端加保护。

### 8.2 结合你项目的题（讲得出「项目里的定点细节」）

#### 项目题 1：你电能质量分析仪为什么用 SHARC 浮点 DSP，不用更便宜的定点 DSP？

**答题要点（结合项目事实）**：

- 电能质量分析要测到 **50 次谐波**（2.5kHz），且要测**小谐波分量**（可能只有基波的百分之零点几）
- 精度等级 **0.1 级**（电压电流测量误差 ≤0.1%）——这个精度用定点 Q15 很难做到：Q15 动态范围只有 [-1,1)，**小谐波会被量化噪声淹没**，大信号又容易溢出
- 浮点 SHARC 动态范围大、相对精度恒定，小信号不丢精度、大信号不溢出 → 满足 0.1 级精度
- **代价**是浮点硬件贵/慢 → 所以我用**汇编优化 + 硬件加速器（FIR/IIR/FFT）+ Cache 优化**把性能补回来
- 一句话：**0.1 级精度决定选浮点，性能用硬件加速器和汇编补**

---

#### 项目题 2：如果老板要降成本，把 SHARC 换成定点 DSP（如 TI C2000），你会怎么处理？

**答题要点（这是最能体现你懂定点的题）**：

1. **用 Q31 不用 Q15**：32 位小数，动态范围和精度比 Q15 大得多，满足谐波测量精度
2. **FFT 用块浮点**：每级做溢出判断 + 统一移位，而不是傻傻每级除 2（精度损失大）
3. **关键路径用宽累加器**：FIR/IIR 累加用 40/64 位，最后才舍入到输出位宽
4. **系数定标（scaling）**：FIR/IIR 系数提前定标，保证中间节点不溢出
5. **验证**：定点结果和浮点参考对比，量化误差控制在精度等级允许范围内
- 结论：**定点能实现，但要重新做「定标 + 块浮点 + 溢出控制」整套设计，工作量和风险比浮点大得多**

---

#### 项目题 3：SHARC 的累加器是多少位？为什么 FIR/IIR 要用「宽累加器」而不是和输入输出同宽？

**答题要点**：

- SHARC 累加器是 **40-bit**（32 位数据 + **8 位保护位**）
- **为什么宽**：FIR 是 N 个「样本×系数」累加，N 个乘积的中间和可能远超单个数据的位宽；IIR 有反馈，误差/溢出会**累积**
- 如果累加器和输入输出同宽（16 位），**中间和就会溢出**（呼应题 6 的「隐形坑」）
- 40-bit 累加器让中间累加不溢出，**最后一步才舍入到 32/16 位输出** → 精度只在最后丢一次，不在每步都丢
- 这和你「Cache 伪共享」一样，都是「性能/精度问题定位到硬件层」的能力

---

#### 项目题 4：闪变仪（IEC 61000-4-15）那组 IIR 滤波器，定点实现时反馈环的溢出怎么防？系数怎么定标？

**答题要点**：

- IIR 有**反馈**（输出回送），一旦某个节点溢出回绕，错误会**在环路里累积放大** → 必须用**饱和算术**（不是回绕）
- **系数定标（scaling）**：把滤波器系数按比例缩小，保证所有中间节点（每级输出）不超过 ±1（定点）或安全范围；定标因子由滤波器的增益分析（L1/L2 范数）算出
- 闪变仪那组是 **IEC 标准规定传递函数**（0.05Hz 高通 + 6 阶 Butterworth 35Hz 低通 + 8.8Hz 人眼加权），定点化要**精确复现幅频/相频** → 系数必须用足够位宽的 Q 格式（如 Q31）量化，量化误差会直接反映成测量误差
- 你项目里用的是浮点 SHARC，所以这个问题你是「从浮点反推定点该怎么设计」，回答时先讲「我在浮点上没这个困扰，但我知道定点该怎么处理」——显得你既做过、又懂底层

---

#### 项目题 5：你做过汇编优化，SHARC 上哪些运算「浮点改定点」收益最大？哪些绝对不能定点化？

**答题要点（分两类讲）**：

**能定点化（收益大）**：
- 固定的乘加循环（FIR 卷积、IIR 差分方程）—— SHARC 单周期 MAC 对整数/定点更高效
- 系数固定的查表/内插计算
- 结果范围已知、可预先定标的模块

**不能定点化（会丢精度）**：
- FFT 大点数变换（动态范围跨 N 倍，浮点才稳，除非上块浮点）
- 小信号谐波提取（小分量会被量化噪声淹没）
- 需要大动态范围的中间计算

**折中答案（加分）**：**块浮点**——关键大动态范围路径用块浮点（定点速度 + 浮点范围），边缘小计算直接用定点。这体现你不是「只会写浮点代码」，而是「理解数据流里每段的动态范围，按需选格式」。
