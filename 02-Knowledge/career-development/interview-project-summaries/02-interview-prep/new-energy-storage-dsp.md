# 新能源/储能 DSP 岗位：4 概念补课 + 面试答题卡

> 触发：2026-09-10 方向定在「新能源/储能/充电桩」后，补 4 个核心概念（MPPT / PLL / 电压电流环 / 电力电子拓扑）
> 定位：这 4 个概念**都和你做过的 DSP 信号处理相通**（采样→计算→闭环），是「延伸」不是「跨界」，2-4 周能到面试水平
> 每个概念 = 通俗原理 → 和你的 DSP 背景怎么连 → 面试答题卡

## 〇、先建立全局认知（一句话打通）

**新能源/储能 DSP 岗位的本质，和你做电能质量分析仪是同一件事：**

```
你做过的：ADC 采样 → 数字滤波 → FFT/计算 → 输出结果（电能质量分析仪）
新能源做的：ADC 采样 → 数字滤波 → 控制算法 → PWM 输出（逆变器功率控制）

区别只有：把「FFT 分析」换成「MPPT/PLL/双环控制」，把「输出结果」换成「输出 PWM」
```

**平台也同类**：你的 SHARC DSP → 他们的 TI C2000 DSP，都是专用 DSP。所以这 4 个概念，是往你已有功底的「旁边挪一步」，不是翻山。

## 一、MPPT（最大功率点跟踪）—— 光伏的核心

### 1.1 通俗原理

- 光伏板有个特性：输出电压和电流不是随便配的，只有工作在**特定电压**下，功率才最大（P = V × I 的峰值点）
- **MPPT 就是不断调整工作电压，让光伏板始终工作在最大功率点**（这个点随光照/温度变化，所以要动态跟踪）
- 本质：一个「寻优」算法，在 P-V 曲线上找峰值

### 1.2 两种常用算法（面试要能讲）

| 算法 | 做法 | 特点 |
|:-----|:-----|:-----|
| **扰动观察法（P&O）** | 微调电压，看功率增还是减：增 → 继续同方向，减 → 反向 | 简单、常用，但会在 MPP 附近振荡 |
| **电导增量法（INC）** | 比较 dP/dV 的符号，精确判断 MPP 位置 | 更精确，稳态不振荡，计算稍复杂 |

### 1.3 和你的 DSP 背景怎么连

> MPPT 的链路是「**ADC 采样电压电流 → 算功率 → 调整 PWM 占空比**」——这正是你电能质量分析仪的「ADC 高精度采样 → 计算 → 输出」链路。你的 ADC + DMA + 滤波功底直接对口，只是把「算谐波」换成「算功率、调占空比」。

### 1.4 面试答题卡

| 问 | 答 |
|:---|:---|
| MPPT 是什么？ | 光伏板 P-V 曲线有唯一最大功率点，MPPT 算法动态跟踪这个点，让光伏板始终输出最大功率（光照温度变化时这个点会漂移） |
| 常用算法？ | 扰动观察法（扰动电压看功率变化方向）和电导增量法（比较 dP/dV，更精确） |
| 为什么需要 MPPT？ | 光伏板不工作在 MPP 会浪费大量功率（可能只输出一半），MPPT 是光伏发电效率的核心 |

## 二、PLL 锁相环（并网）—— 并网的核心

### 2.1 通俗原理

- 并网逆变器要把直流电变成交流电，**接入电网**，所以输出必须和电网**同频率、同相位**
- **PLL 锁相环就是「锁住电网的相位」**，让逆变器输出和电网精确同步
- 不锁相的后果：输出和电网不同步 → 环流、冲击电流，甚至损坏设备

### 2.2 实现方式（面试要能讲）

- 常用 **dq 坐标系下的 PLL（SRF-PLL）**：
  1. 三相电压 → **Park 变换**，变到 dq 旋转坐标系
  2. 调节使 q 轴分量为 0，此时 d 轴就是电网电压幅值，相位角就是电网相位
- 本质：一个相位跟踪闭环

### 2.3 和你的 DSP 背景怎么连

> PLL 本质是「**从信号里提取相位/频率**」——这正是你做过的事！你的「工频提取、DFT 插值测频率、过零检测」就是从电网信号里提取频率信息。PLL 是同一件事的「动态跟踪」版，而且 Park 变换和你的 FFT 同属「坐标/域变换」的数学体系，你完全熟。

### 2.4 面试答题卡

| 问 | 答 |
|:---|:---|
| PLL 干什么？ | 并网逆变器要锁住电网相位，让输出和电网同频同相；dq 坐标系下 Park 变换后锁 q 轴为 0，得到电网相位 |
| 为什么并网要锁相？ | 不锁相，输出和电网不同步，产生环流/冲击电流，可能损坏设备 |
| PLL 和你的经验怎么连？ | 我做过工频提取和频率精确测量（DFT 插值），PLL 是同一类「从信号提相位」的闭环，迁移很快 |

## 三、电压环 / 电流环（逆变器双环控制）—— 控制的核心

### 3.1 通俗原理

- 逆变器控制是**双闭环（级联 PID）**：
  - **外环（电压环）**：给目标电压/功率，输出「电流指令」——负责稳压、稳功率
  - **内环（电流环）**：跟踪电流指令，快速响应——负责限流、保护器件
- 关系：外环慢、内环快，内环带宽远高于外环（通常 10 倍）

### 3.2 为什么双环（面试重点）

| 环 | 作用 | 特点 |
|:---|:-----|:-----|
| 外环电压环 | 稳压/稳功率，给电流指令 | 慢 |
| 内环电流环 | 快速跟踪电流、限流保护 | 快 |

> **双环的意义**：外环保证「输出对」，内环保证「响应快 + 不过流」。只做单环（只有电压环）的话，负载突变时电流会失控、器件会烧。

### 3.3 和你的 DSP 背景怎么连

> 双环本质是「**级联 PID**」，而你做过「TEC 温控闭环（ADC 采样 → 滤波 → PID → 输出）」。你的闭环控制经验 + PID 基础，直接就是内环电流环的结构。唯一的区别是：你做过单环（温控），这里是双环级联——往旁边扩一环而已。

### 3.4 面试答题卡

| 问 | 答 |
|:---|:---|
| 为什么用双环？ | 外环电压环稳压/稳功率，内环电流环快速响应 + 限流保护；内环比外环快（带宽高 10 倍），保证动态响应和器件安全 |
| 内外环带宽怎么定？ | 内环带宽远高于外环（约 10 倍），内环快保证电流跟踪，外环慢保证稳定不振荡 |
| 你的闭环经验？ | 我做过 TEC 温控闭环（ADC 采样→滤波→PID→输出），双环是单环的级联扩展，PID 和闭环结构我都熟 |

## 四、电力电子拓扑（BUCK/BOOST/LLC、DC-AC/DC-DC）—— 硬件概念

### 4.1 通俗原理（软件工程师只需懂「拓扑决定控制策略」）

| 拓扑 | 作用 | 软件侧关注 |
|:-----|:-----|:-----------|
| **BUCK** | 降压（DC-DC） | 控 PWM 占空比 |
| **BOOST** | 升压（DC-DC） | 控 PWM 占空比 |
| **LLC** | 谐振变换（高效率，储能/充电桩常用） | 控开关频率（不是占空比） |
| **DC-AC** | 逆变（直流变交流，储能 PCS 核心） | 控 SPWM/调制 |
| **DC-DC** | 直流变换（光伏 MPPT 前） | 控占空比/频率 |

### 4.2 关键认知（面试要能讲）

- **拓扑决定控制策略**：BUCK/BOOST 控占空比，LLC 控频率——不懂拓扑就不知道该怎么控
- 软件工程师**不需要画板、选器件**，但必须懂「这个拓扑该怎么控制」
- 储能 PCS 典型：**DC-DC（BOOST 升压）+ DC-AC（逆变）** 双向变换

### 4.3 和你的 DSP 背景怎么连

> 拓扑是硬件电路，但你是软件工程师，**只需补「拓扑决定控制策略」这一层概念**，不碰硬件设计。你懂「电路基础」（career-profile 有硬件基础），补拓扑概念很快。

### 4.4 面试答题卡

| 问 | 答 |
|:---|:---|
| 储能 PCS 用什么拓扑？ | DC-DC（BOOST 升压）+ DC-AC（逆变），双向变换；软件侧关注拓扑决定的控制方式 |
| 软件工程师为什么懂拓扑？ | 拓扑决定控制策略——BUCK/BOOST 控占空比、LLC 控频率，不懂拓扑写不了控制算法 |
| 你的硬件基础？ | 我有电路基础（原理图/PCB），拓扑概念能快速补上，我的强项在控制软件层 |
