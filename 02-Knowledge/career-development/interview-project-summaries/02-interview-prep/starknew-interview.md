## 三、核心考点（都是强项，讲深 + 结合真实数据）

### 3.1 MCU 外设驱动（主场，CAN 是王牌）

**被问「你驱动能力怎么样」——用数据说话，别只说「熟练」**：

| 外设 | 我的实战 |
|:-----|:---------|
| **CAN / CAN FD** | 双波特率位时序校准，**总线负载 72%→21%**；多节点优先级调度；总线关闭自动恢复 |
| **ADC + DMA** | 三级优先级 + DMA 双缓冲 + 环形缓冲，采样抖动 **±15us→±2us** |
| **DMA** | 链式传输替代 CPU 轮询，**CPU 负载 90%→47%** |
| **SPI / I2C / UART** | 寄存器级开发，半双工方向切换时序精确控制 |
| **中断** | ISR 快进快出 + 底半部设计，关中断时长严格控制在微秒级 |

**MS 话术**：
> 「驱动我做了 9 年，最拿手的是 CAN 和 DMA。CAN FD 用双波特率精细化位时序校准，把多节点总线负载从 72% 降到 21%；ADC 采样用三级优先级 + DMA 双缓冲 + 环形缓冲，采样抖动从 ±15us 压到 ±2us。这些都是在量产产品上踩过坑、调过优的真实数据。」

### 3.2 OTA 升级（差异化杀招，别人讲不清你能讲全）

> JD 明确点名 OTA，这是你能拉开差距的地方。完整链路要能脱口：

| 环节 | 关键点 |
|:-----|:-------|
| **分片传输** | 升级包拆固定长度分片，逐帧传输 |
| **断点续传** | 中断后从断点继续，不重头传 |
| **双分区 A/B** | 升级写备用分区，校验成功才切换，失败自动回滚，**绝不量产变砖** |
| **校验 + 签名** | CRC 校验 + 固件签名防篡改/防错包 |
| **断电回滚** | 升级标志放 **no-init RAM**（软复位不清零），断电重启能识别「升级到一半」并回滚 |
| **批量升级** | 产线一拖多节点同时升级，进度监控 + 失败重试 |

**MS 话术**：
> 「OTA 我做过 CAN 总线多节点升级，核心是 A/B 双分区 + 升级标志放 no-init RAM——升级写备用分区，校验签名成功才切换；升级到一半断电，重启时靠 no-init RAM 里的标志识别『半成品』自动回滚到旧分区，保证量产设备永不砖。批量升级一拖多，失败自动重试。」

### 3.3 电源时序控制

| 考点 | 我的实战 |
|:-----|:---------|
| 上电时序 | 多模块上电顺序控制（电力仪表多电源域） |
| 复位电路 | 复位原因寄存器（RCC_CSR）区分看门狗/掉电/软件复位 |
| 电源监控 | 电压监控 + 掉电保护（掉电前写关键状态） |
| 低功耗 | Tickless 低功耗（LPTIM 唤醒，待机个位数 uA） |

**MS 话术（结合机器人）**：
> 「机器人多模块上电时序，本质是『主控先起来，外设按依赖顺序逐个上电，异常立即下电保护』。我做过电力仪表的多电源域时序管理 + 掉电保护（掉电瞬间把关键状态写进备份区），还有低功耗的 Tickless 机制——这套思路直接迁移到机器人的电源管理。」

### 3.4 传感器接入

| 传感器 | 接入方式 + 处理 |
|:-------|:---------------|
| IMU | SPI/I2C + DMA + 时间戳 + 数字滤波（FIR 去噪） |
| 编码器 | SPI/ABZ/SSI，配合定时器测速 |
| 电流/电压 | ADC 采样 + 校准 + 滤波 + 异常检测 |

**MS 话术**：
> 「传感器接入我熟——IMU 走 SPI/DMA 采集加时间戳，编码器配合定时器测速，模拟量走 ADC + DMA 双缓冲。关键在数据链路：采样要稳（抖动 ±2us 级）、滤波要去噪、异常要能检测出来。这和我做电能质量的高精度采样是同一条链。」

### 3.5 电机调试（加分项，基础即可，别硬撑）

> ⚠️ 诚实定位：电机精细调参不是你的日常方向，但有机器人比赛早期经验（2015 机器人大赛冠军）+ 闭环控制框架熟。答「驱动层和闭环框架熟，精细调参少」，别装专家。

| 电机 | 要能讲的基础 |
|:-----|:-------------|
| **直流电机** | PWM 调速 + 方向控制（H 桥）+ 编码器反馈 + 速度闭环 PID |
| **步进电机** | 细分驱动 + 加减速曲线（梯形/S 形）+ 失步检测 |

**MS 话术（诚实 + 迁移）**：
> 「直流电机的 PWM 调速、方向控制、编码器反馈闭环，这些驱动层和控制框架我很熟；步进电机的细分和加减速曲线原理清楚。精细的电机调参不是我日常主攻方向，但『PWM + 编码器 + 闭环』这套底层和我的 DSP/控制功底是相通的，上手会很快。」

### 3.6 RTOS（JD 没写，但必用，你的降维打击）

> JD 没列 RTOS，但机器人 MCU 一定跑 RTOS。主动把自研 RTOS 摆出来，是超出 JD 预期的加分项。

**MS 话术**：
> 「JD 没提 RTOS，但机器人 MCU 肯定是跑 RTOS 的。我从零自研过轻量级 RTOS（内核 5~10KB），调度/内存/信号量/中断/低功耗全做过源码级，也用 FreeRTOS 带过团队搭平台。所以 RTOS 这块我不只是『会用』，是『能改内核』，这对机器人的实时任务调度是直接优势。」

## 七、豆包线程增量考点（09-07 整理，补本文盲区）

### 7.1 技术文档编写（JD 明确要求，本文原遗漏，易被问）

> 口述框架：写软件设计文档/接口文档/测试文档；模块接口、时序、异常场景写清楚；**文档跟随代码迭代同步维护，保证与实现对齐**。

### 7.2 OTA 真实 bug（提前想好一个，问题-定位-解决-结果）

> 例：升级后校验失败 / 分片丢包。别只背链路，要有一个自己踩过的实例，讲四段式。

### 7.3 C + RTOS 八股速查（必考，直接复用存量）

- **C**：volatile / static / 内存对齐 / ISR 限制（禁止 printf/malloc，快进快出）/ 栈溢出现象与排查
- **RTOS**：任务划分与优先级分配 / 信号量-队列-互斥锁区别 / 优先级反转 / 死锁四条件 / HardFault 完整排查流程 / 中断上下文 vs 任务上下文

### 7.4 高频场景题（记思路，别背答案）

1. **OTA 中途断电如何防变砖** → A/B 双分区 + 校验标记 + 自动回滚
2. **设备偶发死机完整排查流程** → HardFault 定位（看 fault 寄存器/栈回溯）
3. **传感器偶发断线，软件层如何做可靠性** → 通信重试 + 超时保护 + 断线识别 + 故障上报
4. **多个传感器上电偶发通信失败怎么排查**（电源时序配套场景题）→ 硬件上电/复位时序 + 软件错开初始化时机 + 增加重试与超时

### 7.5 外设驱动重点讲"踩坑与异常处理"（别只说配寄存器）

> 1) I2C/SPI 总线挂死：怎么定位、软件如何恢复；2) ADC 采样噪声：硬件滤波 + 软件滤波（中值/滑动平均）；3) CAN 驱动总线负载与异常处理；4) PWM 输出使用场景。

### 7.6 禁止花时间做

> ❌ 不研究复杂机器人控制算法、不深挖公司背景八卦、不学全新知识——明天中午就面，全部复用存量。
