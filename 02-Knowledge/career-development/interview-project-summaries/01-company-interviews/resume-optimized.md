## 8 类问题怎么改的

| 问题 | 改法 |
|:--|:--|
| 口语啰嗦 | 删「打下坚实基础/提供保障/不可或缺」等套话，每句只留「动作 + 数据」 |
| 逻辑矛盾 | RAM 统一为「ROM 5KB / RAM 1.5KB」（⚠️ 你之前 career-profile 写 40KB，需确认哪个对，建议按简历 1.5KB 或源码核实值统一） |
| 时间线 bug | DSP 平台（3 个月）标注为「平台化与性能优化」，避免单薄感；时间格式统一「YYYY.MM - YYYY.MM」 |
| 量化强弱不均 | 工作经历也补数据（降本 30%、5 人 / 3 骨干、2019 优秀员工），不再全定性 |
| 重点埋没 | DSP 王牌（FFT/谐波/闪变/SHARC）写进电能质量分析仪 + 核心能力第 1 条 |
| 内容堆砌 | 删「界面/网页/报表/导出」等功能堆砌，只留 DSP 难点 + 工业协议 |
| 定位摇摆 | 核心能力收敛为 4 条（DSP/RTOS/工业协议/工程化），删端侧 AI、AI 工具、硬件 |
| 标点混乱 | 统一中文标点、统一「-」编号、统一时间 / 数字格式 |

## 面试经验怎么融入的

- **根因 1（岗位错位）→** 定位聚焦「DSP + 自研 RTOS + 工业协议」，项目围绕这三条线组织
- **根因 2（知识复述挂）→** 每个项目写「难点 + 数据」（90%→47%、降 90%、40%、≤10ms、降本 30%）
- **根因 3（先讲不值钱的）→** 核心能力第 1 条就是 DSP 王牌，删套话
- **致命（DSP 隐形 + TSN 虚标签）→** 电能质量分析仪标「核心项目」+ DSP 内容补全；TSN 写明「协议栈核心由驱动/平台团队负责」
- **端侧 AI 被戳穿 →** 删除，不主动暴露短板
