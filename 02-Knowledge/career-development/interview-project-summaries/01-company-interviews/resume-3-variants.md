# 版本 1：MCU / DSP 底层 + RTOS（王牌版）

> 投：电力电子、芯片固件（C 语言）、工业底层、仪器仪表——吃你最强的「自研 RTOS + DSP 信号处理」

**求职意向**：高级嵌入式软件工程师（MCU / DSP 底层 + RTOS 内核方向）

**核心能力**：
- **自研 RTOS**：从零自研轻量级 RTOS 内核（调度/内存/中断/信号量源码级），内核 ROM 5KB、零任务 RAM 1.5KB，优于 µC/OS 与 FreeRTOS，百万台量产。
- **DSP 信号处理**：FFT 谐波分析、闪变测量（IEC 61000-4-15 标准 IIR 滤波器组）、工频提取、插值重采样；SHARC 硬件 FIR/IIR/FFT 加速器 + 汇编优化 + Cache 优化。
- **底层驱动与工业协议**：CAN/CAN FD、Modbus、IEC 61850、工业环网（≤20ms）；DMA 链式传输 CPU 负载 90%→47%，多通道 ADC 采样抖动 ±15us→±2us。
- **工程化与 PL**：百万级量产经验，直管 5 人团队，IPD 流程。

**项目排序 + 侧重**：
1. **DSP 产品平台开发**（自研 RTOS 内核 + DSP 优化，置顶打 RTOS 王牌）
2. **高端电能质量分析仪**（DSP 信号处理全展开：FFT/闪变/插值/SHARC 加速器）
3. **电力监控仪表**（DMA 优化 90%→47%，RTOS 实时性）
4. **新一代 TSN 交换机**（写「驱动+集成」角色，突出底层驱动，弱化 Linux）
5. **低成本 L2 交换机**（底层驱动/BOOT/量产，突出 MCU 底层）

# 版本 2：Linux + ARM 体系（驱动版）

> 投：Linux 驱动工程师 / 固件工程师（C 语言）——芯片、汽车电子、工业。这是你 Linux 内核驱动能力成长后新开的方向

**求职意向**：高级嵌入式软件工程师（Linux 设备驱动 / 固件方向）

**核心能力**：
- **Linux 设备驱动**：Linux 内核驱动实操——DTS 设备树配置、GPIO 中断、字符设备驱动开发与调试（Marvell 平台 TSN 交换机，C 语言）。
- **ARM / DSP 体系结构**：ARM Cortex-M/A、SHARC DSP、AMP 异构架构；ICache/DCache、中断、DMA 底层开发。
- **自研 RTOS**：从零自研 RTOS 内核，深入理解 OS 内核原理（调度/内存/中断，与 Linux 内核设计相通）。
- **底层驱动与工业协议**：CAN/SPI/I2C/RS485/PHY；DMA、中断驱动、共享内存跨核通信。

**项目排序 + 侧重**：
1. **新一代 TSN 时间敏感网络交换机**（置顶，重点扩写 Linux 驱动实操：DTS/GPIO 中断/字符设备/SyncE/PHY 驱动；仍写明「协议栈核心由驱动/平台团队负责」）
2. **低成本 L2 弱管交换机**（Bootloader/驱动/量产，底层全流程）
3. **高端电能质量分析仪**（强调 A5 跑 Linux + DSP 异构，跨核通信 ≤10ms）
4. **DSP 产品平台开发**（ARM/DSP 体系 + Cache/中断底层）
5. **电力监控仪表**（ARM Cortex-M4 底层）

> ⚠️ V2 关键：把 TSN 项目里「Linux 驱动实操」写实写细（DTS/GPIO 中断/字符设备），这是这份简历的灵魂——但**只写你真调过的，不编造**。
