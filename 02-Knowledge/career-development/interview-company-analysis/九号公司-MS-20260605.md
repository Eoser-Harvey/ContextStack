## 四、技术问题优先级 & 你的回答

### 第一优先级：RTOS（100% 会问）

**1. 详细讲你自研 RTOS 的过程（5分钟）**

思路：为什么自研 → 核心架构 → 技术难点 → 量产验证 → 对比 FreeRTOS

关键数字：任务切换 <1μs、中断响应 <5μs、ROM <8KB、RAM <2KB

**2. FreeRTOS 调度原理 → 对比自研优化**

就绪列表用位图加速，O(n)→O(1)，体现深度

**3. 实时性保证**

抢占式调度 + 中断上下半部 + 静态内存 + 优先级继承

**4. 低功耗实现（九号最关心）**

Tickless 机制 + 动态功耗管理，唤醒延迟 <10μs

> 💡 **技巧**：每个 FreeRTOS 问题都带上"我在自研 RTOS 时做了 XX 优化"——把对话拉回你的优势区

### 第二优先级：MCU/驱动（80%）

- STM32 启动流程（栈指针 → 复位向量 → 初始化 → main）
- CAN 总线（终端电阻/负载率 <30%/屏蔽线抗干扰）— 九号产品大量使用
- 驱动分层设计（HAL → 核心层 → 接口层）

### 第三优先级：架构与工程化（70%）

- 可复用架构：HAL → OSAL → 中间件 → 应用层
- 百万级质量：编码规范 + 四级测试 + 静态分析 + 灰度发布
- AI 编程提效：CodeBuddy 四大场景（驱动/评审/排障/文档），效率提升 40%+

### 第四优先级：行为面（60%）

- "为什么选九号？" → 赛道 + 技术底蕴 + 能力匹配
- 薪资：底线 75W，谈 80W（开 70W 以上，具体协商）
