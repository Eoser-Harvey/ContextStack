# WeChat CLI Skill

通过 [wechat-cli](https://github.com/huohuoer/wechat-cli) 命令行工具查询本地微信数据（聊天记录、联系人、群成员、活跃度统计、收藏、导出等）。工具专为 AI Agent 设计，**默认输出结构化 JSON**，完全本地运行（SQLCipher 实时解密，数据不出本机）。
