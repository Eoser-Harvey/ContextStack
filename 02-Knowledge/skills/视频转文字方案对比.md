## 二、本地离线方案（推荐，隐私安全）

### 2.1 Vibe — 最推荐

| 项目 | 详情 |
|---|---|
| 官网 | [thewh1teagle.github.io/vibe](https://thewh1teagle.github.io/vibe/) |
| GitHub | [thewh1teagle/vibe](https://github.com/thewh1teagle/vibe) |
| 最新版本 | v3.0.19（2026-03-13） |
| 技术栈 | Rust + Tauri |
| 安装包大小 | ~44MB（Windows） |
| 许可 | MIT，完全免费 |

**为什么比 WhisperDesktop 好：**

- WhisperDesktop（Const-me/Whisper）已停更，最后版本 v1.12.0（2023年7月），只支持到 medium 模型
- Vibe 持续更新，支持最新 large-v3 和 large-v3-turbo 模型
- Vibe 安装包仅 44MB，无需 Python 环境，双击即用

**核心功能：**

- 支持所有常见音视频格式：MP3、MP4、WAV、M4A、MKV、MOV、AVI、FLAC、OGG
- 导出格式：TXT、SRT、VTT、HTML、MD
- 支持 GPU 加速（NVIDIA/AMD/Intel）
- 批量转录多个文件
- 支持麦克风实时转录
- 可直接下载 YouTube 视频音频并转写
- 内置 AI 总结功能（可接 Ollama/Claude/OpenAI）

**操作步骤：**

1. 下载安装 → 首次启动自动引导下载模型
2. 拖入视频/音频文件
3. 选择语言（中文）→ 点击转录
4. 导出 TXT/SRT/MD

### 2.2 Buzz — 功能最全的开源老将

| 项目 | 详情 |
|---|---|
| GitHub | [chidiwilliams/buzz](https://github.com/chidiwilliams/buzz) ⭐18.8k |
| 许可 | MIT，完全免费 |
| 最新更新 | 2026-04-19 |
| 平台 | Windows、macOS、Linux |

**核心功能：**

- 文件转录 + 实时麦克风转录 + YouTube URL 导入
- 支持 99 种语言
- 导出 TXT / SRT / VTT / CSV
- 支持 CUDA 和 Apple Silicon 加速
- 命令行支持（可脚本批量处理）

**安装方式：**

```
# Windows（winget）
winget install ChidiWilliams.Buzz

# macOS（Homebrew）
brew install --cask buzz

# 或从 SourceForge 下载 exe
```

**注意：** Windows 版 exe 未签名，安装时会弹出 SmartScreen 警告，点"更多信息 → 仍要运行"即可。

## 五、模型选择建议

| 模型 | 大小 | 内存需求 | 速度 | 准确率 | 推荐场景 |
|---|---|---|---|---|---|
| tiny | 75MB | ~1GB | 10x | 较低 | 快速预览 |
| base | 142MB | ~1GB | 7x | 一般 | 短音频 |
| small | 466MB | ~2GB | 4x | 较好 | 日常使用 |
| **medium** | 1.5GB | ~5GB | 2x | **高** | **推荐** |
| large-v3 | 2.9GB | ~10GB | 1x | 最高 | 专业需求 |
| large-v3-turbo | 1.5GB | ~6GB | 8x | 高 | **平衡推荐** |

**建议：** 日常使用选 `medium` 或 `large-v3-turbo`，平衡速度与准确率。

## 六、推荐策略

```
你的场景                          → 推荐方案

日常快速转写、无限时长              → 剪映（完全免费）
隐私敏感内容（涉密录音等）           → Vibe（离线本地）
需要批量处理 + 功能全面             → Buzz（离线本地）
会议场景、多人对话                  → 飞书妙记（准确率最高）
需要 AI 自动总结                    → 通义听悟
方言、专业术语、最高精度            → 讯飞听见（付费）
```

**对于你的视频号下载场景的完整工作流：**

1. 下载视频 → wx_channel（方案一）
2. 转文字 → 剪映（日常）或 Vibe（隐私敏感）
3. 整理排版 → Markdown 编辑器
