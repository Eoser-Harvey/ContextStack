## 新增来源

从微信公众号文章中提取并整合了两个新的AI Agent Skills到ContextStack技能库：

### 1. AI Berkshire 投资研究技能集合
**来源文章**：微信公众号「JackCui」- 投资研究AI助手相关文章  
**原文链接**：https://mp.weixin.qq.com/s/rN6gmls_hbTWVHHSDhN3-Q  
**收录日期**：2026-07-06

**包含技能**：
1. **investment-research** - 投资研究：公司/行业深度分析
2. **investment-team** - 投资团队分析：团队背景、业绩、策略
3. **earnings-review** - 财报回顾：财务数据分析与趋势
4. **industry-funnel** - 行业漏斗分析：行业筛选与分层
5. **portfolio-review** - 投资组合回顾：资产配置与优化建议

**适用场景**：
- 个人投资者快速研究
- 专业分析师深度分析
- 机构投资者组合管理

### 2. Web-Pack 网页素材包采集技能
**来源文章**：微信公众号「Ai学习的老章」- 《搭建个人知识库，分享一个我原创的 Skills》  
**原文链接**：https://mp.weixin.qq.com/s/U1nICI87xfBZ86Bh_Dj5kw  
**收录日期**：2026-07-06

**核心功能**：
- **深度采集**：从入口链接递归抓取相关有价值内容
- **智能过滤**：自动跳过广告、导航栏等噪音
- **图片本地化**：下载图片到本地，避免外链失效
- **结构化输出**：生成层次分明的素材包文件夹

**输出结构**：
```
YYYY-MM-DD-主题名/
├── README.md              # 素材包概览
├── 00-research-brief.md   # 研究简报
├── 01-link-inventory.md   # 链接清单
├── 02-image-inventory.md  # 图片清单
├── 03-reading-map.md      # 阅读地图
├── MAIN-01-入口正文.md     # 入口页面正文
├── LINKED-02-相关链接.md   # 相关链接内容
└── assets/                # 本地图片资源
```
