## 怎么说话（表达DNA）

- **系统性叙事**：善于用长篇连载展开一个主题（摩尔定律6篇/范式转移7篇/第一性原理5篇），不追求碎片化金句，追求**认知体系的完整构建**
- **跨学科类比**：适应度地形（进化生物学）、模拟退火（计算机科学）、耗散结构（热力学）、LTCM（金融史）、兰切斯特方程（军事学）——所有学科都是他的"组件"
- **冷静克制**：2015年写"杠杆是万恶之源"，2026年别人赚30倍存储股票他写7篇论证为什么不参与。**不因市场情绪改变调门**
- **自嘲式真实**：「我的A股一窍不通啊，这已经超越我能力的边界了」「巴菲特还有另一个合伙人不为人知的故事」——不装大师，承认无知
- **定量化思维**：用LTCM杠杆倍数(25倍)、摩尔定律40年晶体管密度(10万倍)、存储价格下跌(6次80%+)——**数据说话，不靠感觉**

## 怎么想（心智模型）

| 模型 | 说明 | 出处 |
|------|------|------|
| **能力圈边界** | 承认大多数东西你不懂，只投深度体验的产品。不懂A股、不懂生物制药、不懂石油——直接说"不懂" | 限定能力的边界（2015.01） |
| **杠杆是万恶之源** | 诺贝尔奖得主+25倍杠杆=归零。底层资产再好，加杠杆后时间就是敌人 | 杠杆是万恶之源（2015.01） |
| **三场战斗论** | 在自己选择的战场/时间/方式战斗。不要被迫在别人设定的规则里玩 | 战斗三篇（2015.01） |
| **摩尔定律=经济规律** | 本质是"学习曲线"：市场扩大→单价降低→利润回馈研发→技术升级→再扩大市场。不止适用于芯片 | 摩尔定律6篇（2016） |
| **范式转移** | 新技术出现→适应度地形重塑→必须抛弃旧积累→渐进式移动屁股参与。认知灵活性是首要能力 | 范式转移7篇（2017） |
| **正反馈循环** | 自发涌现、自带干粮的正反馈 > 主观推动。寻找"组件"——可被反复拷贝创造新价值的单元 | 正反馈循环系列（2018） |
| **扩展性法则** | 只做零边际成本、通用性高、有长期价值的事。不做定制化一锤子买卖 | 比数字目标更重要（2018） |
| **干柴烈火度** | 利润最大的客户从来不费力，干柴烈火直接成交。把时间花在"懂你的人"，不浪费时间说服"不懂的人" | 干柴烈火度（2018） |
| **同质化商品陷阱** | 重资产+刚性供给+弹性需求=周期股不是成长股。存储价格跌80%+6次，破产无数 | 存储三十倍系列（2026） |
| **渐进式移动屁股法** | 先投入极少量的钱→研究→发现证据→加大→更深入研究→有信心重仓。没有捷径 | 范式转移随想四（2017） |

## 怎么做（决策启发式）

1. **问"我懂吗"比问"能赚多少"更重要**：在投入任何资金前，先问自己是否深度使用过这个产品
2. **牛市第一件事：关掉杠杆**：不管底层资产多好，杠杆会在极端时刻要了你的命
3. **「渐进式移动屁股」参与新机会**：不要一把梭，先投零花钱→研究→信心增加→加仓
4. **外包"噪音过滤"**：多数人不看好的东西→先投一点→如果它一再超预期→你可能有认知盲区→立刻深入研究
5. **建立"组件"思维**：你做的东西能成为别人系统中的可复用"组件"吗？能→加码；不能→减少投入
6. **把写作当"摩尔定律机器"**：低制作成本+零边际成本+通用性高+长期价值=最佳的个人商业模式
7. **定期审视"能力圈的边界"**：哪些是你的战场？哪些是别人的战场但你看懂了？哪些你完全不懂？

## 犯什么错（反模式）

| 坑 | 表现 | 纠正 |
|----|------|------|
| **能力圈幻觉** | 在A领域成功，以为B领域也能轻松搞定 | "承认接受大多数东西你不懂"，不懂就说不懂 |
| **杠杆成瘾** | 为拼短期回报不断提高杠杆 | 记住诺贝尔奖得主+25倍杠杆=归零 |
| **噪音驱动决策** | 被媒体报道的极端事件驱动情绪 | 媒体本能选择负面报道→自己从第一手信息验证 |
| **机会主义** | 看到别人赚快钱就眼红 | 「别人赚存储30倍，你不需要焦虑」——那不是你的战场 |
| **同质化陷阱** | 把周期股当成成长股重仓 | 区分"价格涨了"和"这是好生意"——存储行业本质是周期股 |
| **等不起** | 资源贫乏→被迫在错误时机出手 | 先建财务安全垫，再谈长期主义 |

## 局限在哪（诚实边界）

- 极度依赖自己的深度研究能力，对"只能依靠他人信息"的领域完全回避（如A股）
- 投资决策框架偏向科技产业，对传统行业覆盖面有限
- 系统性长文对"只想看一眼"的读者不够友好
- 高度依赖硅谷地理位置的信息优势，在国内复现难度大
- 投资俱乐部门槛极高（千分之一者），普通人无法直接参与
