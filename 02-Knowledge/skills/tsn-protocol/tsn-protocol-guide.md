## TSN协议栈概览

### 核心标准
| 标准号 | 名称 | 功能 | 状态 |
|--------|------|------|------|
| IEEE 802.1AS-2020 | 时间同步 | gPTP（广义精确时间协议） | 已发布 |
| IEEE 802.1Qbv | 时间感知整形 | 基于时间门的流量调度 | 已发布 |
| IEEE 802.1Qci | 流量过滤和监控 | 每流过滤和监控 | 已发布 |
| IEEE 802.1CB | 帧复制与消除 | 可靠性保障 | 已发布 |
| IEEE 802.1Qbu | 帧抢占 | 低优先级帧可被抢占 | 已发布 |
| IEEE 802.1Qch | 循环排队和转发 | 确定性转发 | 已发布 |
| IEEE 802.1Qcr | 异步流量整形 | 无需全局时间同步 | 已发布 |

### 协议层次
```
应用层
    ↓
TSN配置管理（YANG模型、NETCONF）
    ↓
TSN控制面（CUC、CNC）
    ↓
TSN数据面（交换机、终端）
    ↓
物理层（以太网）
```

## TSN网络部署

### 1. 网络规划

#### 拓扑设计
- **环形拓扑**: 高可靠性，支持帧复制与消除
- **星形拓扑**: 简单易管理，中心交换机要求高
- **混合拓扑**: 结合环形和星形优势

#### 流量分类
- **A类流量** (最高优先级): 运动控制、安全信号
- **B类流量** (中等优先级): 过程数据、视频流
- **C类流量** (低优先级): 文件传输、配置数据

#### 时间同步规划
- **Grandmaster时钟**: 选择高稳定性时钟源
- **时钟层级**: 设计合理的时钟层级结构
- **同步精度**: 根据应用需求确定精度要求

### 2. 设备配置

#### 交换机配置
```bash
# 进入配置模式
configure terminal

# 启用TSN功能
tsn enable

# 配置时间同步
ptp profile 802.1as
ptp domain 0
ptp priority1 128
ptp priority2 128
ptp clock-source external

# 配置时间感知整形
interface GigabitEthernet1/0/1
tsn qbv enable
tsn qbv schedule 1
tsn qbv gate-states 1 1 1 1 1 1 1 1
tsn qbv gate-durations 1000000
```

#### 终端设备配置
```bash
# Linux PTP配置
ptp4l -i eth0 -m -s -2

# Windows PTP配置
w32tm /config /manualpeerlist:"192.168.1.1" /syncfromflags:manual /reliable:yes /update
```

### 3. 参数调优

#### 时间同步参数
- **Sync间隔**: 通常1秒，可根据需求调整
- **Announce间隔**: 通常1秒
- **Delay_Req间隔**: 通常1秒
- **路径延迟测量**: 使用对端延迟机制

#### 流量整形参数
- **门控列表周期**: 根据流量模式设计
- **门状态**: 为每个流量类分配门状态
- **时间偏移**: 确保流量在正确时间发送

#### 可靠性参数
- **复制路径数**: 通常2条路径
- **消除算法**: 序列号检测、时间戳检测
- **恢复机制**: 自动切换、手动切换

## TSN调试方法

### 1. 时间同步调试

#### 检查时钟状态
```bash
# Linux查看PTP状态
pmc -u -b 0 "GET CURRENT_DATA_SET"
pmc -u -b 0 "GET PARENT_DATA_SET"

# 查看系统时间同步状态
timedatectl status
ptp4l -m -i eth0
```

#### 常见问题
- **时钟不同步**: 检查网络连通性、PTP配置、时钟源
- **同步精度差**: 检查网络负载、交换机配置、时钟稳定性
- **主时钟切换**: 检查时钟优先级、Announce消息

### 2. 流量整形调试

#### 检查门控状态
```bash
# 交换机查看门控状态
show tsn qbv interface GigabitEthernet1/0/1
show tsn qbv schedule 1
```

#### 性能测试
- **延迟测试**: 使用Ping、iperf3测量端到端延迟
- **抖动测试**: 使用ptp4l测量时间抖动
- **带宽测试**: 使用iperf3测量可用带宽

### 3. 抓包分析

#### TSN特定过滤器
```
# gPTP协议
ptp

# 特定PTP消息类型
ptp.messageType == 0  # Sync
ptp.messageType == 1  # Delay_Req
ptp.messageType == 2  # Path_Delay_Req
ptp.messageType == 3  # Path_Delay_Resp

# VLAN标签（用于TSN流量）
vlan.id == 100
```

#### 关键字段分析
- **sequenceId**: 帧序列号（用于帧复制与消除）
- **timeSync**: 时间同步相关信息
- **gateState**: 门控状态（如果捕获到配置消息）

## TSN问题排查指南

### 问题1：时间同步失败

#### 症状
- 设备时钟偏差大（>1微秒）
- PTP状态显示未同步
- 应用报告时间错误

#### 排查步骤
1. **检查物理连接**
   - 网线是否正常？
   - 接口指示灯是否正常？
   - 是否有CRC错误？

2. **检查PTP配置**
   - 所有设备是否在同一域？
   - 时钟优先级设置是否正确？
   - 是否启用了正确的PTP配置？

3. **检查网络配置**
   - 是否有防火墙阻挡PTP消息？
   - 是否有组播转发问题？
   - 是否有VLAN配置错误？

4. **检查时钟源**
   - Grandmaster时钟是否正常？
   - 是否有多个Grandmaster竞争？
   - 时钟源稳定性如何？

### 问题2：流量延迟过大

#### 症状
- 端到端延迟超过要求
- 延迟波动大（抖动）
- 特定时间段延迟突增

#### 排查步骤
1. **检查门控配置**
   - 门控列表周期是否合理？
   - 门状态分配是否正确？
   - 时间偏移是否准确？

2. **检查网络负载**
   - 是否有非TSN流量干扰？
   - 链路利用率是否过高？
   - 是否有广播风暴？

3. **检查设备性能**
   - 交换机处理能力是否足够？
   - 终端设备是否及时处理？
   - 是否有缓冲区溢出？

### 问题3：帧丢失或重复

#### 症状
- 应用收到重复帧
- 应用丢失关键帧
- 网络中有冗余路径但未正确消除

#### 排查步骤
1. **检查帧复制配置**
   - 是否启用了帧复制？
   - 复制路径是否正确配置？
   - 消除算法是否启用？

2. **检查网络拓扑**
   - 环形拓扑是否完整？
   - 是否有链路故障？
   - 路径延迟是否对称？

3. **检查序列号**
   - 序列号生成是否正确？
   - 序列号检测算法是否正常？
   - 是否有序列号溢出？
