## 二、方案一：wx_channel（推荐）

### 基本信息

| 项目 | 详情 |
|---|---|
| 仓库 | [nobiyou/wx_channel](https://github.com/nobiyou/wx_channel) |
| Fork 自 | [ltaoo/wx_channels_download](https://github.com/ltaoo/wx_channels_download)（⭐5.4k） |
| 当前版本 | v5.6.9（2026-06-19 更新） |
| 技术栈 | Electron + MITM 代理 |
| 我的 Fork | [Eoser-Harvey/wx_channel](https://github.com/Eoser-Harvey/wx_channel) |

### 操作步骤

1. 从 [Releases](https://github.com/nobiyou/wx_channel/releases) 下载最新 exe
2. **右键 → 以管理员身份运行**（必须，否则无法安装证书）
3. 程序自动安装 CA 证书、配置系统代理
4. 打开微信 → 进入视频号 → 播放任意视频
5. 视频下方出现 **红色下载按钮**，点击选择清晰度即可下载
6. 使用完毕按 `Ctrl+C` 退出（自动清理证书和代理）

### 增强功能（v5.6.9）

- Web 控制台：`http://127.0.0.1:2025/console`
- 批量下载、断点续传
- 多清晰度选择（包括 1080P 原画）
- 下载历史管理

### 安全注意事项

| 风险 | 说明 |
|---|---|
| MITM 自签证书 | 理论上能解密所有 HTTPS 流量 |
| 管理员权限 | 可能修改系统配置 |
| 闭源 exe | 无法审查源码 |

**降低风险：**
- 用完立刻 `Ctrl+C` 退出（自动清理证书 + 恢复代理）
- 不定期检查证书：`Win+R → certmgr.msc → 受信任的根证书颁发机构`
- 不长期运行、不设开机启动

## 三、方案二：wechatVideoDownload

### 基本信息

| 项目 | 详情 |
|---|---|
| 仓库 | [qiye45/wechatVideoDownload](https://github.com/qiye45/wechatVideoDownload) |
| 作者 | B站 UP主 @长风998 |
| 技术栈 | Python + HTTPS 嗅探 |
| 我的 Fork | [Eoser-Harvey/wechatVideoDownload](https://github.com/Eoser-Harvey/wechatVideoDownload) |

### 操作步骤

1. 下载便携版，解压即用（无需安装）
2. 运行 `wechatVideoDownload.exe`
3. 点击 **"开始监听"**
4. 打开微信 → 视频号 → 播放视频
5. 软件自动捕获视频 URL，选择清晰度下载

### 特点

- 支持 1080P / 4K 原画
- 支持直播录制
- 支持断点续传
- 支持 IDM / Aria2 配合加速
- 暗黑模式
- 便携版无需安装，不装证书，纯流量嗅探（风险更低）

## 四、方案三：res-downloader

### 基本信息

| 项目 | 详情 |
|---|---|
| 仓库 | [putyy/res-downloader](https://github.com/putyy/res-downloader) |
| 技术栈 | Go + Wails (GUI) |
| 我的 Fork | [Eoser-Harvey/res-downloader](https://github.com/Eoser-Harvey/res-downloader) |

### 支持平台

微信视频号、抖音、快手、小红书、QQ音乐、B站、YouTube、m3u8 流媒体等

### 操作步骤

1. 下载安装 → 启动代理
2. 播放目标视频
3. 软件自动捕获资源列表
4. 选择下载

### 适用场景

需要同时下载多个平台内容（抖音/快手/小红书 + 视频号）的用户。

## 五、方案四：在线网站

| 工具 | 地址 | 特点 |
|---|---|---|
| greenvideo | greenvideo.cc | 40+ 国内平台 |
| datatool | datatool.vip | 支持 4K 高清 |
| cobalt | cobalt.tools | 全能型多平台 |

**优点**：无需安装任何软件

**缺点**：视频号支持不稳定，经常失效，有隐私风险（视频链接上传到第三方服务器）
