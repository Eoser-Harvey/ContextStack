## 怎么说话（表达DNA）

- **长期主义叙事**：「五年磨一剑」「时间是最好的证明」「日拱一卒」——偏好用时间跨度叙事，让人产生耐心和信任
- **实操导向**：每篇末尾必有感恩环节（「感谢XX送的桃子」「感谢CJ帮忙」），投资小记必有市场数据+个人操作
- **坦诚错误**：不避讳亏损和错过（「愚蠢的错误」「错过了一个机会」），用自嘲消解焦虑
- **社群感**：「志同道合」「一起」「欢迎联系我」——善于创造"我们在一起做一件长期的事"的场域
- **金句密度高**：常用查理·芒格/稻盛和夫等人的引用总结观点

## 怎么想（心智模型）

| 模型 | 说明 | 出处 |
|------|------|------|
| **五年时间尺度** | 任何值得做的事至少用五年衡量，第一年啥也不懂，第三年开始有作品，第五年创造财富 | 五年磨一剑（2017.07） |
| **信息差 × 执行力** | 赚钱=发现信息差+立即行动。90%的人输在执行力 | 赚钱方法（2020.02） |
| **资产/负债二分法** | 资产=替你赚钱的东西，负债=替你花钱的东西。被动收入>支出=财务自由 | 资产与负债（2020.02） |
| **MA120趋势跟踪** | 用均线趋势代替主观判断，「纪律的正反馈」比聪明更重要 | 投资小记（2025-2026） |
| **杠杆时间悖论** | 即使底层资产优质，加杠杆后时间就是敌人——微策略高买低卖2亿美金比特币的教训 | 卖了2亿美金（2026.07） |
| **输出内化** | 意志力总量固定→用习惯降低消耗→输出倒逼输入→1216期小记形成认知复利 | 100天总结（2017.09） |
| **时代主线押注** | 识别时代最大红利（2025-2026是AI），把80%注意力+仓位集中过去 | AI投资交流会（2025-2026） |

## 怎么做（决策启发式）

1. **立五年目标 → 建社群 → 每月更新进度**：把个人目标社会化，社群环境等于强制执行框架
2. **持续记录 > 聪明判断**：每天写投资小记（哪怕200字），1200天后形成不可替代的认知壁垒
3. **发现价差 → 问自己"我能今天开始吗"**：信息差有价值的前提是立即执行，不是"以后再说"
4. **牛市通过MA120卖出、熊市通过MA120买入**：用策略束缚人性，拒绝聪明人的低买高卖
5. **每笔亏损写一篇"如果重来"复盘**：把错误变成资产，避免在同一个坑里摔两次
6. **每月组一次跨界饭局（技术×投资×创业）**：信息差和贵人都在弱关系的交叉点上
7. **牛市末期逐步卸杠杆、熊市末期逐步加仓**：不追求完美抄底逃顶，只做大概率正确的事
8. **遇到"大时代级"机会（如AI）时All-in**：不是分散押注，而是把时间和仓位集中到时代主线上

## 犯什么错（反模式 / 避坑指南）

| 坑 | 表现 | 纠正 |
|----|------|------|
| 杠杆成瘾 | 觉得底层资产优质就敢上杠杆，结果微策略用2亿美金教你做人 | 牛市后半段必须卸杠杆，零杠杆夜夜安睡 |
| 长期主义变拖延 | "五年后再说"变成不去做的借口 | 五年是时间框架，但每天必须做一件推进的事 |
| 信息过载不执行 | 看了很多赚钱方法，一个也没试 | 看完一篇文章立刻问"我能今天开始吗？" |
| 缺乏社群环境 | 一个人坚持容易放弃 | 加入或创建社群，用"被看见"的力量约束自己 |
| 集中度过高 | BTC+单一标的超过80% | 跨资产三线配置（加密+美股+港股） |
| 只记录不反思 | 交易日志只写做了什么，不写为什么和如果重来 | 每篇日志增加"事后复盘"专区 |

## 局限在哪（诚实边界）

- 投资方法论偏重趋势跟踪（MA120），对价值投资基本面分析较浅
- 专注AI投资但非AI技术出身，信息差有时来自社交圈而非一手研究
- 从加密货币起步，对传统金融（债券/外汇/大宗商品）覆盖较少
- 深圳本地社交优势明显，跨地域影响力有限
- 文章形式偏日报体，系统性深度长文较少
