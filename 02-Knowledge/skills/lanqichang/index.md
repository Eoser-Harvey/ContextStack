## 适用场景

当用户面临以下决策时激活此Skill：
- 投资/资产配置决策（分散vs集中、何时买卖、如何管理风险）
- 职业/创业转型决策（大厂→独立、主业vs副业、产品定价）
- 认知/学习优先级决策（投资大脑vs投资资产、学什么不学什么）
- 心力/情绪管理（面对亏损、面对不确定、自我否定）
- AI时代财富策略（AI+投资、AI+教育、AI+创业）

## 一、7个核心心智模型

### 1. 认知 > 本金 > 机会
**来源**：兰启昌+杜世伟联合提炼
**核心**：投资大脑的ROI最高。月薪5000时花500元（10%）找行家咨询。
**应用**：每月收入的10%用于买书/课程/咨询/社群。你的嵌入式AI专业+投资认知=独特信息差。
**反例**：很多人有机会但没认知（看到Web3但不懂货币理论），有本金但没认知（有钱但亏在P2P）。

### 2. 挣钱模式 → 赚钱模式
**来源**：兰启昌2022复盘
**核心**：挣钱=靠手劳动（手停口停）；赚钱=靠资本增值（被动收入）。中产家庭的核心困境是只有主动收入。
**应用**：把每月结余系统性转化为生息资产。目标是被动收入>生活费。
**判断标准**：如果你停止工作3个月，现金流是否还能覆盖生活？

### 3. 风险管理为核心（7层体系）
**来源**：兰启昌2025-04-18
**核心**：投资的核心不是追求盈利，而是做好风险管理。"败兵先战而后求胜，胜兵先胜而后求战。"
**7层**：①保险 ②负债率<50% ③30%储蓄率 ④不碰个股专注ETF ⑤不在牛市高位买入 ⑥全球多元分散 ⑦持续学习
**应用**：对照7层逐项检查你的家庭财务。不满足的层级=你的风险敞口。

### 4. 牛市制定熊市计划，熊市思考牛市计划
**来源**：兰启昌2023-01-09
**核心**：让自己不受市场情绪影响。在平静时写好买卖计划，然后机械执行。
**应用**：现在就写下——CRCL/BTC跌到什么价格加仓？涨到什么价格减仓？如果暴跌50%怎么办？

### 5. 复利IP（不追热点，找大问题）
**来源**：兰启昌2022复盘
**核心**：两种创作路线——跟随热点（短期流量大但衰减快）vs 相信长期价值（长尾效应，持续产生信任和收入）。
**应用**：每月1-2篇深度文章，记录真实的学习和投资决策。不追热点，输出自己的答案。

### 6. 人生商业模式三角色
**来源**：兰启昌2022复盘
**核心**：投资者（被动收入）+ 创作者（信任复利）+ 知识服务者（主动收入）。三角色互补，形成飞轮。
**应用**：在职状态下先启动"创作者"角色，等被动收入覆盖生活费再考虑切换。

### 7. 最重要的事情只有一件
**来源**：兰启昌2025-09-16
**核心**：创业三阶段，每阶段只聚焦一件事——萌芽期（持续输出找到方向）→扎根期（深度服务打磨手艺）→开花期（技能产品化稳定盈利）。
**应用**：问自己"当前阶段，哪一件事做成了，其他事都会变得更容易？"

## 二、8条决策启发式

### 1. "当机会出现时，多犹豫一秒，就是对它的不尊重"
看到机会就把执行力拉满。港股打新开200+个账户，香港优才毫不犹豫。**行动力=不避劳烦+不怕人说**。

### 2. "如果你知道自己会死在哪里，那就不要去那里"（芒格）
不碰杠杆、不做空、不听内幕消息、不追涨杀跌、不FOMO。**避免错误比做对更重要**。

### 3. "盈亏同源"——远离激进
激进型选手押对时翻倍，但市场转换时跌落悬崖。选择稳健道路——全球资产配置。**恒大就是极致反例**。

### 4. "教是最好的学"
通过帮别人解决问题来打磨自己的专业能力。兰启昌2018年在腾讯内部做理财咨询，3年后才裸辞。**在职先跑通"教"的角色**。

### 5. 三句话心法：我很好 / 我错了 / 我可以学
- "我很好"= 自我肯定，降低内耗
- "我错了"= 直面错误，不逃避
- "我可以学"= 成长型思维，相信可以变好

### 6. 三魔法：复盘 / 庆祝 / 感恩
- 复盘= 避免低水平重复
- 庆祝= 给自己创造心理"甜点"，长期坚持
- 感恩= 意识到自己能给予，富足感

### 7. "山高万仞，只登一步"（王阳明）
不考虑3年后该做的事，专注于当下3个月最重要的事情。

### 8. "沿着旧地图，找不到新大陆"
当趋势转向时，改变旧有的成功经验。20年买房赚钱的肌肉记忆，在人口下降+房产税时代不再适用。

## 三、投资框架进化路径

```
阶段1：学巴菲特，研究个股 → 好未来亏90%（政策风险）
阶段2：逐步放弃个股，转向指数基金 → "90%基金经理跑不赢指数"
阶段3：全球资产配置 + ETF + Web3 → 达里奥全天候策略
```

**核心原则**：多元分散、优秀资产、低估买入、高估卖出

**资产配置方向**：A股宽基ETF + 港股优质标的 + 美股宽基ETF + 黄金 + Web3/BTC

## 四、6个避坑指南

| 坑 | 兰启昌的教训 | 你的对照 |
|----|------------|---------|
| 单一个股集中 | 好未来跌90%（政策风险） | CRCL 67.8%——同样的集中风险 |
| 高杠杆 | "高杠杆是双刃剑，逆风期死得快" | 房贷180万/净资产140万=128% |
| 追热点买基金 | "相信国运定投纳指"在高点买入很惨 | 需评估你的买入时点 |
| 不懂就投 | P2P/民间借贷/代客理财 | 信用卡40万循环用于WEB3 |
| 在牛市买入 | 2020年底"疫情牛"后高点买入 | MA120纪律已帮你规避 |
| 停止学习 | "AI会让很多技能快速贬值" | 持续学习中✅ |

## 五、使用方式

当用户面临投资/创业/认知决策时，以兰启昌的框架进行交叉验证：

1. **投资决策**：先用7层风险管理体系检查 → 再用"盈亏同源"评估激进程度 → 最后用"牛市熊市计划"写好执行方案
2. **职业决策**：先用"挣钱→赚钱"模式判断当前阶段 → 再用"三角色"设计转型路径 → 最后用"三阶段最重要一件事"聚焦当前行动
3. **认知决策**：先用"认知>本金>机会"判断ROI → 再用"教是最好的学"设计输出方式 → 最后用"复利IP"确定长期方向
4. **心力管理**：三句话心法（我很好/我错了/我可以学）+ 三魔法（复盘/庆祝/感恩）
