## 核心工具

### Wireshark
- **版本**: 3.6.x及以上
- **关键功能**: 实时抓包、离线分析、协议解析、统计图表
- **文件格式**: .pcap, .pcapng

### tcpdump
- **命令行抓包工具**: 适合无GUI环境
- **常用参数**: `-i`指定接口, `-w`保存文件, `-c`抓包数量
- **过滤表达式**: 支持BPF语法

### 其他工具
- **tshark**: Wireshark命令行版本
- **ngrep**: 网络层grep工具
- **netstat**: 网络状态查看

## 抓包流程

### 1. 准备工作
1. **确定抓包目标**
   - 问题现象描述
   - 涉及设备IP地址
   - 通信协议和端口

2. **选择抓包位置**
   - 客户端侧抓包
   - 服务器侧抓包
   - 中间网络设备抓包（镜像端口）

3. **配置抓包参数**
   - 抓包接口（eth0, wlan0等）
   - 抓包过滤器（host, port, net等）
   - 抓包时长和文件大小限制

### 2. 抓包执行

#### Wireshark图形界面
```bash
# 启动Wireshark
wireshark

# 选择接口开始抓包
# 设置显示过滤器
# 保存抓包文件
```

#### tcpdump命令行
```bash
# 基本抓包
tcpdump -i eth0 -w capture.pcap

# 抓特定主机
tcpdump -i eth0 host 192.168.1.100 -w capture.pcap

# 抓特定端口
tcpdump -i eth0 port 80 -w capture.pcap

# 抓特定网段
tcpdump -i eth0 net 192.168.1.0/24 -w capture.pcap

# 组合过滤
tcpdump -i eth0 "host 192.168.1.100 and port 80" -w capture.pcap
```

### 3. 分析流程

#### 第一步：整体概览
- **统计** → **Conversations**: 查看通信对端
- **统计** → **Protocol Hierarchy**: 查看协议分布
- **统计** → **Endpoints**: 查看端点统计

#### 第二步：过滤重点流量
- 使用显示过滤器精确定位问题
- 常见过滤器：
  ```
  ip.addr == 192.168.1.100
  tcp.port == 80
  http.request
  tcp.flags.syn == 1
  tcp.analysis.duplicate_ack
  tcp.analysis.retransmission
  ```

#### 第三步：深入分析
- **TCP流跟踪**: 右键 → **Follow** → **TCP Stream**
- **协议字段解析**: 展开协议树查看字段值
- **时间序列分析**: **统计** → **TCP Stream Graphs**

#### 第四步：问题定位
- **丢包**: 查看重传、重复ACK、零窗口
- **延迟**: 分析RTT、握手时间、响应时间
- **错误**: 查看RST、FIN、协议错误码

### 4. 常见问题分析模板

#### 连通性问题
```
1. 检查ARP/NDP是否正常
2. 检查ICMP ping是否通
3. 检查TCP三次握手是否成功
4. 检查防火墙规则
5. 检查路由表
```

#### 性能问题
```
1. 测量RTT（Round Trip Time）
2. 检查带宽利用率
3. 分析TCP窗口大小
4. 检查重传率
5. 查看应用层响应时间
```

#### 协议错误
```
1. 查看协议状态码（HTTP 404, 500等）
2. 检查TLS/SSL握手错误
3. 分析DNS解析问题
4. 检查DHCP过程
```
