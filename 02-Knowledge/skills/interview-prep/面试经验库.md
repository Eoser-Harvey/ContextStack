### 2. 北京加速进化科技

| 维度 | 内容 |
|------|------|
| **薪资** | 年包 65W，平均 15个月 × 4.3W |
| **结果** | ❌ 一轮淘汰，没给原因 |
| **自评原因** | C 问题回答不完美；启动汇编实现的功能、Boot 和 App 跳转都说的不太好 |

**教训**：
- **C 语言底层机制必须烂熟于心**：启动汇编、Boot/App 跳转是高频考点
- 嵌入式底层知识是核心竞争力，不能停留在"会用"层面

---

### 3. 昉擎科技 — AI芯片方向

| 维度 | 内容 |
|------|------|
| **面试过程** | 面试官没问基础知识，随便问了几点驱动相关内容，了解项目用到的芯片等能力范围 |
| **失误** | 主动问了裁员的事情 |
| **结果** | 未通过 |

**教训**：
- ⛔ **绝对不要主动问裁员/稳定性相关话题！** 这会给面试官传递"不自信/对公司没信心"的信号
- 对初创/中小公司尤其敏感

### 4. 西门子 — 智能建筑事业部

| 维度 | 内容 |
|------|------|
| **事业部** | 智能建筑事业部，楼宇产品 |
| **产品线** | 前端数据采集（智能仪表）+ IO控制器 + 网络通信（无管理交换机）+ 组态/网页展示控制 或 PLC控制 + 电机/变频器 |
| **面试流程** | 笔试 + 现场面试 |

#### 笔试
- 实际开发经验部分还行
- **编程题比较欠缺**

#### 现场面试
- **自我介绍要点**：要说明设计、项目管理、PL 等角色、带人等
- 简历项目细节要准备充分
- 单元测试、静态分析工具、如何集成到 CI → 需提前准备
- **英语自我介绍**：外企确实会问！虽然22年脉脉有人说没有，但实际问了
- 合同签主体：需确认是西门子中国还是西门子西伯乐斯

#### 技术准备缺失项
- profinet 协议 → 待了解

#### 待请教/关注事项
- 口语很关键吗？
- 每年涨工资比较慢？→ **一定要底薪高一点！**
- 培训/成长支持计划？
- 职业发展路径（工程师→专家→首席专家）？
- 不是专注某一模块（驱动/协议栈），整机系统设计机会？向专家或系统设计发展？

#### 标准话术

**离职初衷**：
> 23年加入新华三本着新的工业交换机产品线积极发展的方向，去年公司战略调整，部门合并，业务也缩减，目前组织对我来讲做的都是重复性比较强的工作，没有挑战性，上升空间有限。

**为什么选择西门子**（满分答案）：
> 我选择西门子中国、选择智能建筑事业部，核心是"个人职业规划与公司发展、岗位需求高度契合"，主要有三个原因：
> 
> 第一，从公司层面来说，西门子作为百年外企，在工业领域的技术积累、品牌影响力全球领先，尤其是智能基础设施和智能建筑领域，是行业标杆，其完善的培训体系、清晰的职业发展通道（工程师→专家→首席专家），能让我这个拥有8年嵌入式经验的工程师，在技术领域持续沉淀、稳步成长；同时，西门子重视工作生活平衡、抗周期能力强，没有"35岁危机"的隐忧，这也是我现阶段职业规划中非常看重的——我希望能深耕工业嵌入式领域，与公司共同成长，而非追求短期的快速迭代。
> 
> 第二，从事业部和岗位层面来说，智能建筑事业部专注于楼宇自动化、消防安防领域，其核心产品（Desigo系列、Cerberus PRO系列）的嵌入式开发，与我8年的工业嵌入式经验高度匹配——我之前长期从事楼宇、消防类产品的嵌入式开发，精通RTOS、CAN/Modbus/BACnet等协议，熟悉工业级产品的稳定性、可靠性设计要求，能够快速适配岗位需求；同时，事业部的产品聚焦于"智能化、数字化"，需要嵌入式技术与AI、物联网结合，这既能发挥我现有的嵌入式优势，也能让我接触到新的技术方向，实现个人技能的升级，避免长期做传统嵌入式的技术瓶颈。
> 
> 第三，从价值观和个人追求来说，西门子"卓越、责任、创新"的核心价值观，与我个人的职业理念高度契合——我在8年的嵌入式开发中，始终将"产品稳定性、可靠性"放在首位（如之前优化消防报警系统的实时响应速度、解决偶发性死机问题），这与西门子工业产品"追求卓越、重视责任"的理念一致；同时，我也希望能通过自己的嵌入式技术，参与到智能建筑、消防安防这类关乎民生安全的项目中，为楼宇智能化、消防安全贡献力量，而西门子智能建筑事业部的产品，正是聚焦于这类场景，能让我实现个人价值与社会价值的统一。
> 
> 综上，无论是公司平台、岗位适配度，还是价值观契合度，西门子中国智能建筑事业部的嵌入式岗位，都是我现阶段的最优选择，我也有信心，凭借8年的嵌入式经验，快速融入团队，为公司创造价值。

#### 失败原因
- 面试反馈"还不错"，但没通过
- **真正原因**：另一个候选人有安全方面的经验
- ⚠️ **教训**：岗位要求里的"优先招聘"项要格外关注！那往往就是决定性因素
- **英语口语没提前准备**是本次的失败之处

### 6. 宜休科技（ISHO）

#### 必须确认的硬性问题
- 公积金、社保每月具体金额
- 年包拆分：如 65W → 月薪多少 + 年终奖多少
- 公司能停车吗？
- 能办工作居住证吗？
- 合同第一次签几年？后续呢？试用期多久？
- 公积金社保是全额 12% 吗？有商业保险吗？

#### 业务/技术问题
- 工作可以切换到端侧 AI 的业务吗？
- 软硬件都是自己开发还是 ODM 的硬件？→ **自研软硬**
- 目前产品化到什么阶段了？和 Oura 对比呢？AI 和会员模式？

#### 二轮主管面试
- 端侧 AI 目前应用程度？
- 有没有后续轮岗可能性？

#### 对技术面试官的提问
- 团队技术栈
- 团队多少人？公司/团队文化
- 开发模式、流程？

#### 发展相关提问
- 您认为公司优点或您比较欣赏的地方？
- 工作节奏？
- 新人培训计划（体现职业规划）
- 事业部的业务增长点？
- 产品路线图？

## 三、通用提问策略

### 对 HR 面试官的提问（待遇福利详细谈）

| 类别 | 问题 |
|------|------|
| **薪资结构** | 薪资结构？（年终奖 + 绩效？）调薪机制？ |
| **岗位定级** | 岗位定级多少？多久调整一次？ |
| **合同** | 合同第一次几年？后续呢？试用期多久？【重要】 |
| **工居证** | 工作居住证是否可以承接？【非常重要】 |
| **五险一金** | 公积金、社保是全额 12% 吧？有商业保险吗？ |
| **股权** | 有股权激励机制吗？授予的条件是？ |

### 其他确认事项
- 需要 1 个月的公司交接时间？1个月 + 1周缓冲可以吗？
- 交通问题：可停车吗？

## 四、5条面试红线

1. ⛔ **不说"想转型"** → 说"能力迁移"
2. ⛔ **不先报薪资** → 等对方开价
3. ⛔ **不暴露急于跳槽**
4. ⛔ **不只讲技术细节** → 讲工程整体、讲价值
5. ⛔ **不问裁员/稳定性** — 来自昉擎科技教训！
