# Interview Prep Skill — 使用说明

## 基本信息
- **Skill名称**：interview-prep
- **来源**：ContextStack 自定义 Skill（基于豆包 AI 对话 + 7家公司实际面试经验）
- **规则类型**：manual（手动触发）
- **作用域**：项目级（ContextStack）
- **创建日期**：2026-06-10
- **更新日期**：2026-06-10

## 个人薪资基准
- **当前**：30K × 16（14月基础 + 2月绩效）= **53W/年**
- **福利**：节日福利、生日福利、饭补、商业保险
- **谈薪底线**：65-70W 总包

## 功能描述
输入公司名称，自动生成面试准备清单。动态读取框架中已有面试经验和技术知识库，结合网络搜索，输出8模块结构化清单。

## 触发方式
用户输入公司名称时触发：
- "准备{公司名}面试"
- "{公司名}面试准备"
- "帮我分析{公司名}"
- "生成{公司名}的面试清单"

## 执行流程

### 1. 框架资料映射（动态读取全部文件）
读取以下目录下**所有文件**（不指定具体文件名，运行时动态发现）：
```
02-Knowledge/skills/interview-prep/
├── interview-prep使用说明.md          # 本文档
└── 面试经验库.md                      # 7家公司完整面试记录+教训+话术（必读！）

02-Knowledge/career-development/
├── MEMORY.md                           # L4 行为约束+知识索引（含6条红线）
├── career-strategy/                    # 通用职业策略（读取所有文件）
├── interview-project-summaries/
│   ├── company-interviews/             # 各公司面试经验（读取所有文件）
│   ├── embedded-fundamentals/          # 技术知识库（读取所有文件）
│   └── interview-prep/                # 通用面试准备材料（读取所有文件）
└── index.md
```

### 2. 两条路径分流
- **快速路径**：`company-interviews/` 下存在该公司相关文件 → 读取全部，优先用框架资料
- **完整路径**：新公司 → 网络搜索公司信息 + 叠加框架通用经验（读取 career-strategy/ 和 interview-prep/ 下所有文件）

### 3. 赛道 → P0 考点映射
| 赛道 | P0 必考 |
|------|---------|
| 短交通/机器人 | RTOS实时性、FOC电机控制、CAN总线、低功耗、传感器融合 |
| 工业自动化 | 实时性/确定性、Modbus/EtherCAT、功能安全、冗余设计 |
| 消费电子 | BLE/WiFi低功耗、OTA升级、量产测试 |
| 汽车电子 | CAN/CAN FD/LIN、ISO26262、AUTOSAR |
| AIoT/智能家居 | WiFi/BLE Mesh、云连接、低功耗、端侧AI |
| 芯片原厂 | 驱动开发、芯片验证、异构计算、SDK设计 |

### 4. 输出8个必含模块
- **A. 公司画像** — 赛道/产品/技术栈/薪资水平
- **B. 能力匹配矩阵** — ✅优势 ⚠️需补课 ❌短板
- **C. 技术准备** — P0核心方向 / P1通用必考 / P2加分项
- **D. 自我介绍定制** — 30秒融入自研RTOS+百万量产+AI工具
- **E. 回答策略** — 本质→实践→坑→思考，数据说话
- **F. 薪资策略** — 底线70W，不先报价
- **G. 反问问题** — 3个深度定制问题
- **H. 行动清单** — 面试前必做，带checkbox

### 5. 6条红线（从 MEMORY.md + 面试经验库提取）
1. 不说"想转型" → 说"能力迁移"
2. 不先报薪资 → 等对方开价
3. 不暴露急于跳槽
4. 不只讲技术细节 → 讲工程整体、讲价值
5. 不带敏感文件
6. ⛔ **不问裁员/稳定性** — 昉擎科技教训！

### 6. 外企专项检查（面试经验库提取）
- 英语自我介绍必须提前准备！
- 口语不一定要流利，但基础自我介绍+项目介绍要能做到
- 岗位"优先招聘"项要格外重视（西门子因安全经验被刷）

### 7. 硬性确认清单（每次面试前必问）
- 公积金比例？（5% 或 12% 差距大）
- 社保是否全额缴纳？
- 工作居住证是否承接？
- 合同第一次几年？试用期多久？
- 年包拆分：月薪 + 年终奖 + 绩效
- 停车可用吗？
- 有商业保险/股权激励吗？

### 8. 输出路径
`02-Knowledge/career-development/interview-project-summaries/company-interviews/{公司名}-面试准备清单.md`

## 适用场景
- 面试前快速生成针对性的准备清单
- 已有面试复盘的公司走快速路径，新公司走完整搜索

## 与其他 Skill 的关系
- 上游：无特定依赖
- 互补：`brainstorming`（复杂面试策略分析可先激活头脑风暴）
- 下游：`writing-plans`（准备清单确认后可拆解为每日学习计划）

> **原则**：本 Skill 只定义流程和模板。具体公司数据从 `career-development/` 下各子目录全部文件动态读取，面试通用经验从同目录 `面试经验库.md` 读取，不在此硬编码文件名。
