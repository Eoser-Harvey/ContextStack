# 北京开公司/个体工商户为家人缴纳社保公积金研究

> 整理时间: 2026-06-11
> 核心目标: 为爱人、弟弟缴纳北京社保+公积金+个税 → 满足摇号资格

---

## 一、家庭现状

| 成员 | 户口 | 北京社保状态 | 居住证 | 需求 |
|------|------|:--:|:--:|------|
| **你（自己）** | 内蒙古 | ✅ 在职缴纳（8年连续） | 有 | 已有资格 |
| **爱人** | — | ❓ 待确认 | — | **需要连续5年社保+个税** |
| **弟弟** | — | ❓ 待确认 | — | **需要连续5年社保+个税** |

### 摇号硬性条件（非京籍）
- 持有有效的《北京市居住证》或《北京市工作居住证》
- 近**5年（60个月）连续**在北京缴纳社保
  - **断月**：可以补缴，补缴后视为连续有效
  - **断年**（整年无记录）：不能补缴，重新计算5年
  - **三年内断缴**：在60个月窗口内可以补（单位原因）。3个月内断缴线上批量办；超3个月需零星办理+提供劳动合同/工资流水等证明材料
  - **个人原因断缴**（如离职换工作）：**无法补缴**，只能从下次正常缴纳重新算连续年限
  - **三年前的断缴**：如果已超出近60个月窗口，无需补缴（不影响当前申请）
- 近**5年每年**都有个人所得税纳税记录（非零）

> **结论**: 社保+个税+居住证，缺一不可。必须马上开始缴纳，5年后才能摇号。

## 三、方案A: 注册有限责任公司（推荐）

### 3.1 为什么是有限责任公司而不是个体户

**核心区别：法人能不能给自己发工资薪金个税。**

| 维度 | 个体工商户 | 有限责任公司 |
|------|-----------|-------------|
| **法人给自己发工资** | ❌ 经营者只能报**经营所得**个税 | ✅ 法人可与公司签劳动合同，拿**工资薪金**个税 |
| **个税类型**（对摇号关键） | 经营所得（无收入则为零） | 工资薪金（正常发薪即有记录） |
| **注册难度** | 低 | 中（需法人/监事/章程） |
| **代理记账** | 1200-2000元/年 | 2400-4000元/年 |
| **年报** | 简单年检 | 工商年报+税务汇算清缴 |
| **能否雇工交社保** | ✅ | ✅ |

> **为什么个体户不行**：税务局明确规定，个体户业主的"工资"属于经营所得而非工资薪金所得，不能按工资薪金申报个税。摇号需要的是每年有非零的个税记录，经营所得如果没有实际收入就是零→资格不保。
>
> **有限责任公司可以**：法人是独立法律主体，同时也能是公司员工。签劳动合同→发工资→代扣工资薪金个税→满足摇号要求。

### 3.2 正确的人员架构

```
公司注册人：爱人（法人 + 股东）
     ↓
爱人同时作为公司员工 → 签劳动合同 → 每月发工资 → 工资薪金个税 ✅
弟弟作为公司员工 → 签劳动合同 → 每月发工资 → 工资薪金个税 ✅
你（自己）→ 不参与公司，H3C在职不受影响
```

| 成员 | 角色 | 社保来源 | 个税类型 | 摇号 |
|------|------|---------|------|:--:|
| **你** | 不参与 | H3C在职（主） | 工资薪金（H3C） | ✅ 已满足 |
| **爱人** | 法人+员工 | 公司代缴 | 工资薪金 | ✅ 发工资即有 |
| **弟弟** | 员工 | 公司代缴 | 工资薪金 | ✅ 发工资即有 |

### 3.4 注册地址解决方案

北京住宅/公寓不能用于公司注册，必须有商业/办公地址。三种方案：

| 方案 | 费用 | 续费 | 可开户 | 推荐 |
|------|------|:--:|:--:|:--:|
| 集群注册（政府备案） | 免费~几百元/年 | 每年 | ✅ | ✅ 首选 |
| 郊区园区终身地址 | 1500-3000元一次性 | 不用 | ✅ | ✅ |
| 商业挂靠地址 | 1000-3000元/年 | 每年 | ✅ | 备选 |

**方案一：集群注册地址（政府备案地址）** — 就是你查到的那种

北京各区政府、中关村园区、经济开发区提供的合法备案地址。2025年11月新规《北京市经营主体经营场所登记管理若干规定》正式落地，海淀已发出全市首份集群注册营业执照。

| 优势 | 注意事项 |
|------|---------|
| 政府备案，100%合法 | 部分园区有名额限制或行业要求 |
| 费用极低，甚至免费 | 需要托管机构作为"集群注册管理方" |
| 可开对公账户、办税控 | 托管机构通常也提供代理记账，打包价更优 |
| 海淀、昌平、朝阳等各区都有 | 郊区（平谷/房山）的集群地址更容易申请 |

> **费用对比**：集群注册**地址本身**更便宜（免费~几百/年 vs 终身地址1500-3000首年），但地址每年续费。2年以上算总账，终身地址略省（首年贵但后续不用续地址费）。两种方案费用差距不大，选哪个主要看托管机构的打包报价和服务质量。

**方案二：郊区园区终身地址**

郊区园区招商引资的注册地址，一次性收费，终身不用续费。比集群注册贵首年，但从第二年起持平或更省。

| 郊区 | 终身地址费（约） |
|------|------|
| 平谷 | 1500-2000元 |
| 房山 | 1500-2500元 |
| 大兴 | 2000-3000元 |
| 延庆/密云 | 1000-1500元 |

- 代办打包：注册+地址+刻章 **2000-4000元全包**
- 和你住海淀没关系，公司注册在郊区完全合法

### 3.5 操作流程

```
Step 1: 办理北京居住证（非京籍前置条件）
    ↓  → 已有的话跳过，约15个工作日
Step 2: 注册有限责任公司（选郊区终身地址）
    ↓  → 找代办或自己办，1-3个工作日拿营业执照
Step 3: 刻章 + 银行开户
    ↓  → 公章、财务章、法人章 + 对公账户
Step 4: 税务登记 + 社保开户
    ↓  → 到区税务局/社保中心办理
Step 5: 公积金开户（可选）
    ↓  → 到北京住房公积金管理中心
Step 6: 增员（爱人、弟弟）
    ↓  → 作为雇工添加，签订劳动合同
Step 7: 每月/每季度正常报税 + 缴纳社保
    ↓  → 代理记账公司处理
```

### 3.6 关键政策要点

| 要点 | 说明 |
|------|------|
| **法人=员工** | 有限责任公司法人可与公司签劳动合同，合法领取工资薪金 |
| **工资薪金个税** | 正常发工资即产生工资薪金个税记录，满足摇号要求 |
| **雇工定义** | 只要有劳动关系（签劳动合同、发工资），就必须交五险 |
| **非京籍可行** | 通过公司为雇工缴纳北京职工社保，非京籍可合法参保 |
| **公积金** | 非强制，但建议交（最低5%，对摇号有益） |
| **零申报可行** | 无实际业务时可以做零申报，不影响社保缴纳 |

### 3.8 ⚠️ 零收入公司发工资：合法，但要发"合理工资"

**核心：不冲突。** 公司没有业务收入，完全可以合法雇佣员工、发工资、代扣个税。

资金流转路径：
```
家庭资金 →（股东借款/增资）→ 公司对公账户 →（发工资）→ 爱人和弟弟个人卡 →（代扣个税）→ 税务局
```

**但有一个重要细节：工资不能太低。** 金税四期下，长期发5000元以下（免征额线）工资的公司是税务稽查重点。发6000-10000元反而更安全，因为：

- 初创公司创始人拿**低薪**（而非零薪或5000擦边）是正常的
- 零收入公司与低薪在逻辑上一致——"创业阶段，控制成本"
- 但是工资要与职位匹配：爱人≈总经理/执行董事 6000-10000元；弟弟≈技术主管 6000-8000元，都是北京同岗位的正常低值
- 如果公司零收入却发20000+高薪，反而不合理

**但！个税金额不能为零。** 摇号要求"每年有个人所得税缴纳记录"，如果工资太低（扣除5000免征额+社保公积金后应纳税所得额为0），就没有实际缴税记录。

| 月工资 | 应税所得（扣5000+社保532+公积金172后） | 月个税 | 年个税 | 摇号 |
|------|------|------|------|:--:|
| 5000元 | -704元（免） | 0 | 0 | ❌ |
| 6000元 | 296元 | ~8.9元 | ~107元 | ✅ 有记录但极少 |
| 8000元 | 2296元 | ~68.9元 | ~827元 | ✅ |
| 10000元 | 4296元 | ~128.9元 | ~1547元 | ✅ |

> **建议月工资6000-8000元**：刚好产生个税记录，成本可控。按最低工资发的话个税会是零，摇号不认。

**注意**：工资越高，公司承担的五险一金也越高（按实际工资基数），需要平衡总成本。

### 3.9 资产隔离：公司债务不波及家庭

有限责任公司的核心优势：股东仅以认缴出资额为限承担责任，公司亏损/破产不波及个人财产。

**但有一人公司陷阱**：如果爱人一个人持股（一人有限责任公司），根据《公司法》第63条，**举证责任在你身上**——必须自证公私财产分离，否则有限责任保护失效。

| 防护措施 | 说明 |
|------|------|
| 公私账户严格分开 | 公司对公账户≠家庭账户，绝不混用 |
| 规范发薪留痕 | 银行转账发工资，不拿公司钱付个人账单 |
| 每年审计报告 | 一人公司法定要求 |
| **最稳妥：加个小股东** | 爱人99% + 弟弟/父母1%，避开一人公司的举证陷阱 |

- [ ] 确定注册资本（建议3-10万认缴，无需实缴）
- [ ] ⭐⭐ 联系2-3家地址卖家/代办询价（集群注册 vs 郊区终身地址）

> ⚠️ **弟弟居住证解决方案**：单位入职交社保不需要居住证（只有灵活就业才需要）。弟弟可先办**居住登记卡**（租房合同或借住证明去派出所），6个月后换居住证。社保和居住证两条线并行，不互相阻塞。5年后摇号时居住证早已有效。

### 4.2 公司注册（1-2周）

| 步骤 | 操作 | 方式 | 耗时 |
|:--:|------|------|:--:|
| 1 | 核名：提交2-3个备选名称 | 📱 线上（e窗通） | 10分钟-1天 |

> ⚠️ **代办风险与防护**：代办需提交爱人身份证+居住证，存在信息被滥用的风险。防护措施：
> - 找有实体办公室的正规财税公司（美团/企查查可查工商信息），不找个人代办
> - 签正规合同，明确"仅限于本次公司注册使用"
> - 法人章、公章、财务章注册完成后**立即自己保管**，不留给代办
> - 营业执照下来后，法人（爱人）亲自去银行开户，不委托代办
> - 注册完成后在"国家企业信用信息公示系统"和"天眼查"核查公司信息是否正确
> - 定期（每季度）查一次公司名下是否有异常贷款/变更记录
| 2 | ⭐⭐ 提交材料：爱人(法人)身份证+居住证 + 弟弟(股东)身份证 | 📱 线上（e窗通+北京通APP电子签） | 1天 |
| 3 | 领取营业执照 | 📱 线上（电子执照）+ 邮寄纸质 | 1-3天 |
| 4 | 刻章：公章/财务章/法人章/发票章 | 📱 线上申请+邮寄 | 1天 |
| 5 | ⭐⭐ 税务登记 + 社保开户 + 公积金开户 | 📱 线上（e窗通可同步勾选） | 1天 |
| 6 | ⭐⭐ 签代理记账合同 | 找正规机构，含记账+报税+年报 | 1-2天 |
| 7 | ⭐⭐⭐ 银行开对公账户 | 🏢 **线下**（法人爱人亲自去），见开户要点 | 半天 |
| 8 | ⭐⭐⭐ 签劳动合同 + 社保增员 + 个税备案 | 爱人+弟弟签合同，社保系统添加，税务局备案 | 1天 |
| **合计** | **全流程1-2周** | | |

**开户要点与避坑**：虚拟地址开户是公司注册全流程里**最容易踩坑的一步**。

| 坑 | 具体是什么 | 怎么准备 |
|------|------|------|
| **银行拒开** | 四大行（工农中建）对虚拟地址审核严，直接拒 | 首选**招商银行、浦发银行**（对小微企业最友好），次选建行/北京银行 |
| **上门核查** | 客户经理要去注册地址实地拍照，挂靠地址没人办公→被拒 | 买地址时确认"支持银行开户+配合核查"，卖家安排人应答 |
| **法人远程不给办** | 法人不到场基本开不了，代办也替代不了 | 爱人本人去，带齐：**营业执照正副本+公章+法人章+身份证+公司章程** |
| **地址备案文件不匹配** | 银行系统里地址和工商备案不一致 | 买地址时索要：营业执照地址一致的**产权证明复印件+租赁合同+园区备案文件** |
| **被列为高风险客户** | 新公司+无社保记录+虚拟地址→银行风控直接拉黑 | 先完成税务登记和社保开户再去银行，显得"正常经营" |
| **选错支行** | 不是每家支行都接虚拟地址开户 | 提前电话问"你们支行接园区注册地址开户吗？"，确认了再去 |

**最佳路径**：
```
1. 买地址 → 确认卖家有合作银行（通常是招行某支行）
2. 拿执照 → 先完成税务登记+社保开户（让公司看起来"活跃"）
3. 预约银行 → 法人带全套材料去合作支行
4. 当场开好 → 拿到U盾/密码器，激活网银
```

> 💡 **买地址时必问卖家**："你们地址能开哪几家银行？有没有不核查直接开的？"如果卖家支支吾吾说不清→换一家。

> 📌 **唯一必须线下**：银行开对公账户（法人爱人亲自去）。其他（工商/税务/社保/公积金）e窗通七合一全程线上，新公司法后连监事都可免。

#### 省钱方案：只买地址，自己注册

完全可行。代办主要赚的是"省时间"的钱，不是必须的。

| 方式 | 地址费 | 代办注册费 | 总首年费用 | 耗时 |
|------|------|:--:|------|:--:|
| 代办全包 | 含在内 | 2000-4000元 | 2000-4000元 | 3天 |
| **只买地址+自己注册** | 1500-3000元 | 0 | 1500-3000元 | 3-7天 |

**自己注册的坑**：

| 坑 | 说明 | 如何避 |
|------|------|------|
| 经营范围不会选 | 选错经营范围后续开票/资质受限 | 抄同类型公司的经营范围（天眼查搜"北京XX文化创意有限公司"） |
| 注册地址信息填错 | 地址和备案信息不一致被驳回 | 买地址时让卖家提供精确到门牌号的注册地址文本 |
| 电子签名不会操作 | 北京通APP签名步骤多 | 按e窗通提示一步步来，有问题打11616611 |
| 税务报到漏做 | 拿到执照后忘记税务登记 | e窗通会自动同步税务，但首次登录电子税务局需手动激活 |
| 社保公积金没同步开户 | 只注册了公司没开社保户 | e窗通注册时勾选"五险一金同步开户" |

**建议**：自己注册完全可行，但第一次如果不想折腾，花几百找代办只做注册（不含地址和记账）也行，拿到执照后后面的社保公积金代理记账你自己来或者另找。询价时可以问"只买地址+只代办注册，分开报价"。

### 4.3 员工入职与社保增员

> 对应主流程步骤8。开户完成后立即执行。

| ⭐ | 操作 | 细节 |
|:--:|------|------|
| ⭐⭐⭐ | 爱人+弟弟签**劳动合同** | 爱人：总经理/设计师 7000元；弟弟：运营主管 6500元 |

### 4.7 关键注意事项清单

| 类别 | 注意事项 | 重要性 |
|------|------|:--:|
| **社保不中断** | 每月15日前确保对公账户余额充足，自动扣款失败=断缴→5年重算 | ⭐⭐⭐ |
| **银行转账发工资** | 必须走对公账户→个人卡，严禁现金发薪 | ⭐⭐⭐ |
| **劳动合同** | 必须有真实签字的合同，职位薪资与实际一致 | ⭐⭐⭐ |
| **对公账户余额** | 保持至少2-3个月社保费用的余额，防止扣款失败 | ⭐⭐⭐ |
| **股东架构** | 爱人99%+弟弟1%，避开一人公司举证陷阱 | ⭐⭐ |
| **居住证** | 必须每年续签，断签则社保连续性可能受影响 | ⭐⭐ |
| **代理记账** | 选有资质的机构，签正规合同，每月确认申报记录 | ⭐⭐ |
| **工商年报** | 每年3-6月必须报，漏报列异常名录 | ⭐⭐ |
| **税务零申报** | 无业务收入报零申报合法，但个税不能为零 | ⭐ |
| **地址年检** | 集群注册每年确认地址续费状态 | ⭐ |
| **年度审计** | 虽非一人公司但建议做 | ⭐ |
