# 权益变现与活动追踪

> 信用卡权益变现流水线 + 银行活动日历 + 收支盈亏追踪  
> 核心目标：通过权益变现收益覆盖刚性年费支出，实现净收益

---

## 一、权益变现流水线

### 1.1 闲鱼卖权益标准流程

```
1. 确认权益 → 打开银行App查看剩余次数
2. 发布闲鱼 → 使用下方模板，定价参考市场价
3. 买家下单 → 确认买家信息（姓名/手机/航班号/地址）
4. 预约权益 → 在银行App预约，填写买家信息
5. 发送凭证 → 截图/录屏发给买家
6. 确认收货 → 买家使用后确认，到账
```

### 1.2 闲鱼标题模板

```
【银行名+权益】接送机/代驾/休息室 长期有效 当天可约

示例：
- 邮储鼎致白 代驾40km 当天可约 长期有效
- 建行大山白 接送机100km 机场高铁站 当天可约
- 兴业行悠白 境内接送机 当天可约
```

### 1.3 溢价时间窗口

| 节假日 | 溢价幅度 | 预约时间 | 操作 |
|--------|----------|----------|------|
| 春节 | +50-100% | 提前2周 | 接送机、代驾需求暴增 |
| 五一 | +30-50% | 提前1-2周 | 贵宾厅、接送机 |
| 十一 | +30-50% | 提前1-2周 | 贵宾厅、接送机 |
| 暑假 | +20-30% | 提前1周 | 贵宾厅需求大 |
| 周末 | +10-20% | 当天 | 代驾需求 |
| 平日 | 基准价 | 随时 | 挂着慢慢出 |

## 六、操作注意事项

1. **实名权益变现**：截图时关闭WiFi和定位，避免暴露位置信息
2. **溢价时机**：节假日提前1-2周上架，价格可上浮30-100%
3. **买家沟通**：确认使用日期、人数、航班号后下单，避免纠纷
4. **到账确认**：买家使用完毕后再确认收货，保留截图证据
5. **积分成本**：部分权益消耗积点（如民生100积点/次），需计算在内
