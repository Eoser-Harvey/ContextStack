# 提案：月度资产趋势图

## 背景
家庭资产月度报告（`research/portfolio/reports/`）已积累多个月份数据，每份报告包含"一、资产总览"表格，列出加密货币、美股、港股、现金固收、TS时间代币、净资产等各类资产金额。目前缺乏跨月对比视图，无法直观看到资产变化趋势。

## 需求
新增月度资产趋势图，从已有报告的资产总览表格自动提取数据，生成折线图嵌入年度报告。

## 数据源
- 路径：`research/portfolio/reports/家庭资产报告-YYYY-MM.md`
- 表格：`## 一、资产总览` 下的资产类别和金额
- 资产类别：加密货币、美股(链上)、美股、港股、A股、TS时间代币、现金固收、总资产、净资产

## 技术方案
- 用 Python 解析现有报告的 Markdown 表格
- 使用 matplotlib 生成折线图
- 横轴：月份（2026-05, 2026-06...）
- 纵轴：资产值（CNY）
- 每条资产类别一条折线，净资产用加粗线
- 图表嵌入 `家庭资产年度报告-2026.md`

## 约束
- 只提取"一、资产总览"表格，不碰"二、投资资产明细"
- 当某月某资产类别不存在时（如 A股仅在 5月出现），该点留空不连线
- 图表保存为 PNG 到 `research/portfolio/reports/images/`
