- 数字部分: 端口数量和类型
- U: Uplink（上行端口）
- P: PoE（以太网供电）
- TP: Twisted Pair（双绞线端口）

## 调试规范

### 调试流程
1. **问题描述**: 明确现象、影响范围、复现条件
2. **信息收集**: 日志、配置、抓包、状态信息
3. **分析定位**: 模式识别、根因分析、假设验证
4. **解决方案**: 制定方案、验证效果、记录结果

### 常用工具
- **ping**: 网络连通性测试
- **Wireshark**: 抓包分析（pcap/pcapng文件）
- **串口工具**: SecureCRT、MobaXterm
- **对比工具**: Beyond Compare
- **网络分析**: 网络性能分析工具

### 调试记录要求
- 每个问题独立文件记录
- 包含问题描述、调试过程、解决方案
- 记录关键日志和抓包文件路径
- 标注问题状态（待分析/进行中/已解决）

## 领域知识

### 工业交换机特性
- 宽温工作范围（-40°C ~ 75°C）
- 抗振动、抗电磁干扰
- 冗余电源设计
- 环网协议支持（ERPS/MRP）

### TSN时间敏感网络
- IEEE 802.1Qbv: 时间感知整形器
- IEEE 802.1Qci: 每流过滤和监控
- IEEE 802.1AS: 精确时间同步
- IEEE 802.1Qav: 基于信用的整形器

### 本质安全（Intrinsic Safety）
- 防爆环境的安全设计要求
- 本质安全电路对信号质量的影响
- 发射功率限制对通信距离的影响

## 产品红线

- 不在生产设备上直接执行未验证的配置变更
- 调试操作前必须备份当前配置
- 涉及网络中断的操作必须提前评估影响范围
- 客户现场设备调试必须有回滚方案
