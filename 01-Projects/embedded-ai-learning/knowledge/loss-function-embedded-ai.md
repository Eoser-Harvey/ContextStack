## 一、核心定义与本质

损失函数（Loss Function）= 衡量「模型预测值」与「真实标签值」之间差距的数学公式，是神经网络训练的**核心指挥棒**。

本质：把"模型准不准"这个模糊的业务问题，转化成一个**可计算、可求导、可优化的数值目标**。

---

## 二、核心作用

### 1. 量化模型效果
- 损失值越小 → 差距越小 → 模型越好
- 损失值越大 → 预测偏差越大

### 2. 引导模型优化：驱动梯度下降
- 损失函数输出误差 → 反向传播算每个权重的梯度 → 优化器（Adam/SGD）调整权重
- 没有损失函数，网络没有优化目标，无法训练

### 3. 决定模型的优化偏向
- 对大误差惩罚重 → 优先修正极端错误
- 对离群点不敏感 → 鲁棒性强，适配工业强干扰场景

---

## 三、基本原理：训练的完整闭环

```
1. 前向传播：传感器数据 → 网络逐层计算 → 预测结果
2. 计算损失：损失函数(预测值, 真实标签) → 损失值
3. 反向传播：从损失值出发，反算出每个权重的梯度
4. 权重更新：优化器按学习率调整所有权重
5. 循环迭代：重复直到损失不再下降（收敛）
```

## 四、嵌入式AI最常用的损失函数

### 4.1 分类任务 → 交叉熵损失（Cross Entropy Loss）

#### 二元交叉熵（BCE）
| 维度 | 内容 |
|------|------|
| 场景 | 二分类，输出层 `sigmoid` |
| 工业 | 电机异常检测（正常/异常）、接地故障（有/无） |
| 嵌入式优势 | 计算简单，单输出节点，内存极小，INT8量化精度损失小 |

#### 稀疏分类交叉熵（Sparse Categorical Crossentropy）
| 维度 | 内容 |
|------|------|
| 场景 | 多分类，输出层 `softmax` |
| 工业 | 电力故障（短路/接地/正常）、轴承故障（外圈/内圈/滚动体） |
| 嵌入式优势 | 标签用整数（0/1/2），不用独热编码，大幅省内存，MCU端多分类首选 |

> ⚠️ **鞭策提醒**：分类任务**绝对不能用 MSE**！MSE假设误差服从正态分布，而分类任务是概率分布，用MSE会导致梯度消失、收敛极慢。

### 4.2 回归任务

| 损失 | 原理 | 特性 | 适用 |
|------|------|------|------|
| **MSE** | 误差平方求平均 | 收敛快，对大误差惩罚重；对离群点极度敏感 | 实验室干净数据 |
| **MAE** | 误差绝对值求平均 | 鲁棒性强，抗离群点；但0点不可导 | 工业现场传感器 |
| **Huber** | 小误差MSE，大误差MAE | **兼顾速度与鲁棒性，工业万金油** | 设备寿命预测 |

> 嵌入式训练推荐：工业数据优先用 **Huber**，量化后表现也更稳定。

### 4.3 嵌入式专属辅助损失
- **知识蒸馏损失**：教师模型的软标签指导小模型训练，INT8量化后掉点更少
- **量化感知损失**：QAT时模拟INT8舍入误差，让模型在训练阶段适应低精度

---

## 五、选型原则

| # | 原则 | 说明 |
|:---:|------|------|
| 1 | 任务匹配 | 分类用交叉熵，回归用MSE/MAE/Huber |
| 2 | 简单优先 | 复杂损失部署时算子不支持、量化暴跌 |
| 3 | 工业抗干扰 | 带干扰数据用MAE或Huber |
| 4 | 省内存 | 多分类用 `Sparse Categorical Crossentropy` |

---

## 六、代码示例

```python
# 二分类异常检测
model.compile(optimizer='adam',
              loss='binary_crossentropy',
              metrics=['accuracy'])

# 多分类故障识别（标签0/1/2，省内存）
model.compile(optimizer='adam',
              loss='sparse_categorical_crossentropy',
              metrics=['accuracy'])

# 回归（工业带干扰数据，Huber）
model.compile(optimizer='adam',
              loss='huber',
              metrics=['mae', 'mse'])
```
