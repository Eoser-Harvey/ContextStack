## 项目标准文件结构

每个项目至少包含以下文件：

| 文件 | 用途 |
|------|------|
| **WORKSPACE.md** | 工作台入口、项目信息、导航 |
| **STATE.md** | 最新状态与进展 (✅⚠️📌❓) |
| **ACTIONS.md** | 任务清单与进度追踪 |
| **CONTEXT.md** | 稳定背景、共识决策、前提约束 |
| **REFERENCES.md** | 内部文档与外部资源链接 |
| **PROJECT-RULES.md** | 项目规则与行为约束 |
