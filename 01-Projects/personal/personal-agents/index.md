## 技术方案

### 参考架构

- **ARS 的苏格拉底式引导**: 对话健康监测、意图检测层
- **OpenSquilla 的 MetaSkill**: 动态发现、自动编排
- **ClawHunt 的可观测性**: 全链路追踪、状态透明

### 实现方式

1. **Claude Code Skill**: 基于 `.claude/skills/` 的本地 Skill 开发
2. **Prompt 工程**: 核心认知框架通过 Prompt 注入
3. **知识库**: 结合 ContextStack 框架的知识库做 RAG
4. **记忆系统**: 利用 MEMORY.md 做持久化记忆
