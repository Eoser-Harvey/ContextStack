#### 法人签"设计师"合同的合规性说明

| 常见疑问 | 解答 |
|---------|------|
| **法人能当员工吗？** | ✅ 完全可以。法定代表人与公司是劳动关系，可以签劳动合同、缴社保。这是合法且常见的操作（尤其是小微企业的创始人兼员工）。 |
| **法人签"设计师"不签"总经理"合理吗？** | ✅ 合理。岗位名称应**匹配实际工作内容和公司业务**。公司主营"文艺创作与表演"，设计师完全对口。7000元设计师月薪是市场合理水平，不会引起社保基数质疑。 |
| **为什么不签"总经理"？** | 7000元月薪的总经理在北京明显偏低，可能触发社保审计疑问。总经理更适合公司规模扩大后设立。 |
| **没有其他员工怎么办？** | ✅ 完全合规。小微企业常见情况——法人一人兼多职（设计师+行政），正常签合同缴社保即可。不强制要求必须有多个员工。 |

> **合同关键字段**：乙方岗位填"**设计师**"（或"创意设计师"），部门"设计部"，月薪7000元（税前），合同期3年（2026-08-10至2029-08-09），试用期"0个月"。

| 2 | **个税零申报 vs 个税为零** | 筹备期无员工→个税零申报；有员工后工资<5000→仍需申报但应纳税额为0；**摇号要求每年有非零个税记录**（不是每月），公积金12%下你月个税约17.30元自然满足 |
| 3 | **社保断缴后果** | 个人原因断缴无法补缴→5年连续重新计算；单位原因断缴3个月内可线上补。**社保是当月缴当月**（如8月社保在8月缴纳），非次月缴上月 |
| 4 | **三方协议** | 税务、社保、公积金均需签订三方协议（对公账户代扣），开户时一并办理 |
| 5 | **自记账责任清单** | 月度个税+季度增值税/企税+年度汇算+工商年报+残保金，确认无漏项 |
| 6 | **公积金基数新开户当年规则** | **新开户当年按开户当月工资申报基数，当年内不调整**。如2026年8月开户缴12%，基数6326维持到2027年6月；**2027年7月**再按上年度月均工资调整 |
| 7 | **自动化提醒建议** | 手机日历设置每月10日/15日提醒；或用自动化任务工具定时推送（如飞书/钉钉日程） |
| 8 | **小规模纳税人转一般纳税人** | 年销售额超500万强制转一般纳税人；初创期保持小规模即可 |
| 9 | **税务UKey/数电票** | 税务登记时申领免费UKey，开通数电票开票权限；暂不开票可不申领 |

#### 钱从哪来？对公账户资金流转

公司无收入，所有资金来自家庭积蓄。合法路径：

```
家庭积蓄 → 股东借款注入公司 → 公司对公账户 → 发工资+交社保公积金
                                       ↑
                              工资回到个人卡（净回收）
```

| 操作 | 说明 |
|------|------|
| 初始注入 | 按2-3个月用量（约5-6万）以"股东借款"名义转入对公账户 |
| 每月循环 | 工资发出去→回到家庭账户→次月再转入对公账户（可循环使用） |
| 实际消耗 | 只有社保公司和个税是纯支出（约3600元/月），工资回到家庭可复用 |
| **推荐补充** | 爱人布艺市集/电商收入走公司账户，产生真实流水 |

> 公司账上体现为"其他应付款-股东借款"，不交税。家庭净支出只有社保+个税+运营费。

#### ⭐ 一举两得的优化：爱人布艺收入走公司账

长期纯零收入公司容易触发"长亏不倒"稽查风险。爱人做布艺手作本来就打算创业，**线下市集、朋友圈、闲鱼的收入走公司账户**，一举多得：

| 好处 | 说明 |
|------|------|
| **让公司"真经营"** | 有真实收入流水，摆脱纯壳公司嫌疑 |
| **收入不用多** | 每月几千块就足够证明公司活跃 |
| **公司可开发票** | 如果是正规客户可以开票（小规模纳税人，税率低） |
| **收入可抵成本** | 材料采购、摊位费计入公司成本，不浪费 |
| **社保基数更合理** | 有收入后，按最低基数交社保更有说服力 |
| **为创业铺路** | 平台建好了，后续直接放大经营 |

### 5.4 个税零申报操作教程（自然人电子税务局扣缴端）

> 来源：国家税务总局官网 + 深圳/山西税务局 + 法行宝教程整理
> 适用场景：公司无员工（或未发工资），法定代表人为唯一申报人员，每月个税零申报

#### 5.4.1 前置准备

| 准备项 | 说明 |
|--------|------|
| 软件下载 | [自然人电子税务局（扣缴端）](https://etax.chinatax.gov.cn) 下载安装 |
| 登录方式 | ① 实名登录（法人个税APP扫码） ② 申报密码登录（税务局大厅获取） |
| 首次使用 | 需要先完成"单位信息采集"（输入纳税人识别号） |
| 电脑要求 | 数据存在本地，换电脑需重新下载历史数据或去大厅开通【扣缴端数据下载】权限 |

#### 5.4.2 完整操作步骤（四步法）

**第一步：人员信息采集**

```
扣缴端 → 左侧菜单【人员信息采集】→ 点击【添加】
  ├ 填写法人信息：姓名、身份证号、任职受雇从业类型选"雇员"
  ├ 任职受雇从业日期：填公司成立日或法人入职日
  ├ 手机号码：必填
  └ 点击【保存】→ 勾选该人员 → 点击【报送】→ 获取反馈显示"报送成功"
```

> ⚠️ **必须报送成功**才能进行下一步申报。如果没有员工，只需添加法定代表人一人即可。

**第二步：综合所得申报**

```
扣缴端 → 左侧菜单【综合所得申报】
  → 进入"综合所得预扣预缴表"页面
  → 点击【1 收入及减除填写】
  → 在"正常工资薪金所得"栏点击【填写】
  → 弹出人员列表，法人信息已在列表中
  → 所有收入项填入 0（本期收入、基本养老保险、医疗保险、失业保险、住房公积金等全填 0）
  → 点击【保存】
```

**第三步：税款计算**

```
综合所得申报页面 → 点击【2 税款计算】
  → 系统自动计算，应缴税款显示为 0
  → 确认无误
```

> 如有免税收入、减免税额等特殊项，需在【3 附表填写】中补充。零申报一般不需要。

**第四步：申报表报送**

```
综合所得申报页面 → 点击【4 申报表报送】
  → 确认所有数据为 0、无税款
  → 点击【发送申报】
  → 申报完成后点击【获取反馈】
  → 反馈状态显示"申报成功"即完成
```

> ✅ **零申报成功后无需缴款**（应缴税款为 0）。整个流程约 5 分钟。

### 摇号硬性条件（非京籍）
- 持有有效的《北京市居住证》或《北京市工作居住证》
- 近**5年（60个月）连续**在北京缴纳社保
  - **断月**：可以补缴，补缴后视为连续有效
  - **断年**（整年无记录）：不能补缴，重新计算5年
  - **三年内断缴**：在60个月窗口内可以补（单位原因）。3个月内断缴线上批量办；超3个月需零星办理+提供劳动合同/工资流水等证明材料
  - **个人原因断缴**（如离职换工作）：**无法补缴**，只能从下次正常缴纳重新算连续年限
  - **三年前的断缴**：如果已超出近60个月窗口，无需补缴（不影响当前申请）
- 近**5年每年**都有个人所得税纳税记录（非零）

> **结论**: 社保+个税+居住证，缺一不可。必须马上开始缴纳，5年后才能摇号。

## 三、方案A: 注册有限责任公司（推荐）

### 3.1 为什么是有限责任公司而不是个体户

**核心区别：法人能不能给自己发工资薪金个税。**

| 维度 | 个体工商户 | 有限责任公司 |
|------|-----------|-------------|
| **法人给自己发工资** | ❌ 经营者只能报**经营所得**个税 | ✅ 法人可与公司签劳动合同，拿**工资薪金**个税 |
| **个税类型**（对摇号关键） | 经营所得（无收入则为零） | 工资薪金（正常发薪即有记录） |
| **注册难度** | 低 | 中（需法人/监事/章程） |
| **自记账** | 0元/年（免费工具） | 0元/年（免费工具） |
| **年报** | 简单年检 | 工商年报+税务汇算清缴 |
| **能否雇工交社保** | ✅ | ✅ |

> **为什么个体户不行**：税务局明确规定，个体户业主的"工资"属于经营所得而非工资薪金所得，不能按工资薪金申报个税。摇号需要的是每年有非零的个税记录，经营所得如果没有实际收入就是零→资格不保。
>
> **有限责任公司可以**：法人是独立法律主体，同时也能是公司员工。签劳动合同→发工资→代扣工资薪金个税→满足摇号要求。

### 3.8 ⚠️ 零收入公司发工资：合法，但要发"合理工资"

**核心：不冲突。** 公司没有业务收入，完全可以合法雇佣员工、发工资、代扣个税。

资金流转路径：
```
家庭资金 →（股东借款/增资）→ 公司对公账户 →（发工资）→ 爱人和弟弟个人卡 →（代扣个税）→ 税务局
```

**但有一个重要细节：工资不能太低。** 金税四期下，长期发5000元以下（免征额线）工资的公司是税务稽查重点。发6000-10000元反而更安全，因为：

- 初创公司创始人拿**低薪**（而非零薪或5000擦边）是正常的
- 零收入公司与低薪在逻辑上一致——"创业阶段，控制成本"
- 但是工资要与职位匹配：爱人≈总经理/执行董事 6000-10000元；弟弟≈技术主管 6000-8000元，都是北京同岗位的正常低值
- 如果公司零收入却发20000+高薪，反而不合理

**但！个税金额不能为零。** 摇号要求"每年有个人所得税缴纳记录"，如果工资太低（扣除5000免征额+社保公积金后应纳税所得额为0），就没有实际缴税记录。

| 月工资 | 应税所得（扣5000+社保532+公积金172后） | 月个税 | 年个税 | 摇号 |
|------|------|------|------|:--:|
| 5000元 | -704元（免） | 0 | 0 | ❌ |
| 6000元 | 296元 | ~8.9元 | ~107元 | ✅ 有记录但极少 |
| 8000元 | 2296元 | ~68.9元 | ~827元 | ✅ |
| 10000元 | 4296元 | ~128.9元 | ~1547元 | ✅ |

> **建议月工资6000-8000元**：刚好产生个税记录，成本可控。按最低工资发的话个税会是零，摇号不认。

**注意**：工资越高，公司承担的五险一金也越高（按实际工资基数），需要平衡总成本。

### 3.9 资产隔离：公司债务不波及家庭

有限责任公司的核心优势：股东仅以认缴出资额为限承担责任，公司亏损/破产不波及个人财产。

**但有一人公司陷阱**：如果爱人一个人持股（一人有限责任公司），根据《公司法》第63条，**举证责任在你身上**——必须自证公私财产分离，否则有限责任保护失效。

| 防护措施 | 说明 |
|------|------|
| 公私账户严格分开 | 公司对公账户≠家庭账户，绝不混用 |
| 规范发薪留痕 | 银行转账发工资，不拿公司钱付个人账单 |
| 每年审计报告 | 一人公司法定要求 |
| **最稳妥：加个小股东** | 爱人99% + 弟弟/父母1%，避开一人公司的举证陷阱 |

| **法人远程不给办** | 法人不到场基本开不了，代办也替代不了 | 爱人本人去，带齐：**营业执照正副本+公章+法人章+身份证+公司章程** |
| **地址备案文件不匹配** | 银行系统里地址和工商备案不一致 | 买地址时索要：营业执照地址一致的**产权证明复印件+租赁合同+园区备案文件** |
| **被列为高风险客户** | 新公司+无社保记录+虚拟地址→银行风控直接拉黑 | 先完成税务登记和社保开户再去银行，显得"正常经营" |
| **选错支行** | 不是每家支行都接虚拟地址开户 | 提前电话问"你们支行接园区注册地址开户吗？"，确认了再去 |

**最佳路径**：
```
1. 买地址 → 确认卖家有合作银行（通常是招行某支行）
2. 拿执照 → 先完成税务登记+社保开户（让公司看起来"活跃"）
3. 预约银行 → 法人带全套材料去合作支行
4. 当场开好 → 拿到U盾/密码器，激活网银
```

> 💡 **买地址时必问卖家**："你们地址能开哪几家银行？有没有不核查直接开的？"如果卖家支支吾吾说不清→换一家。

> 📌 **唯一必须线下**：银行开对公账户（法人爱人亲自去）。其他（工商/税务/社保/公积金）e窗通七合一全程线上，新公司法后连监事都可免。

#### 省钱方案：只买地址，自己注册

完全可行。代办主要赚的是"省时间"的钱，不是必须的。

| 方式 | 地址费 | 代办注册费 | 总首年费用 | 耗时 |
|------|------|:--:|------|:--:|
| 代办全包 | 含在内 | 2000-4000元 | 2000-4000元 | 3天 |
| **只买地址+自己注册** | 1500-3000元 | 0 | 1500-3000元 | 3-7天 |

**自己注册的坑**：

| 坑 | 说明 | 如何避 |
|------|------|------|
| 经营范围不会选 | 选错经营范围后续开票/资质受限 | 抄同类型公司的经营范围（天眼查搜"北京XX文化创意有限公司"） |
| 注册地址信息填错 | 地址和备案信息不一致被驳回 | 买地址时让卖家提供精确到门牌号的注册地址文本 |
| 电子签名不会操作 | 北京通APP签名步骤多 | 按e窗通提示一步步来，有问题打11616611 |
| 税务报到漏做 | 拿到执照后忘记税务登记 | e窗通会自动同步税务，但首次登录电子税务局需手动激活 |
| 社保公积金没同步开户 | 只注册了公司没开社保户 | e窗通注册时勾选"五险一金同步开户" |

**建议**：自己注册完全可行，但第一次如果不想折腾，花几百找代办只做注册（不含地址和记账）也行，拿到执照后后面的社保公积金记账报税你自己来。询价时可以问"只买地址+只代办注册，分开报价"。

### 4.3 员工入职与社保增员

> 对应主流程步骤8。开户完成后立即执行。

| ⭐ | 操作 | 细节 |
|:--:|------|------|
| ⭐⭐⭐ | 爱人+弟弟签**劳动合同** | 爱人：总经理/设计师 7000元；弟弟：运营主管 6500元 |
| ⭐⭐⭐ | 社保系统增员 | 添加爱人和弟弟，填报工资基数 |
| ⭐⭐ | 公积金系统增员 | 同上，比例5% |
| ⭐⭐ | 税务局个税备案 | 全员全额扣缴申报备案 |

> ⚠️ **合同、工资表、银行流水三者必须一致**，这是社保审计的核心凭证。
