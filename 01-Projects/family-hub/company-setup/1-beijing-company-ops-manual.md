## 一、日常运营（每月 / 每季度 / 每年）
### 1.1 事项梳理（按时间线）

> **核心原则**：公司可以暂时没有正式员工、暂不发放工资、暂不缴纳社保公积金，初创筹备期属于正常合规状态；但**税务登记、按期报税、工商年报等主体法定义务，和有无员工无关，必须按时完成**。

### 1.2 公司基本信息与税种认定

> 📌 公司基本档案与税种认定清单已归档至 `archive/company-done-log.md` 第二节。本节仅保留申报时间线与日常维护事项。

**首次申报时间线（2026年下半年）**

> ⭐ **每月操作顺序（铁律：先缴后发 —— 前面的数决定后面的数，顺序不可颠倒）**
>
> ```
> ① 公积金      ← 每月最后一天自动托收（当月缴当月）
>       ↓   网厅确认【实际扣款额】→ 个人 840.00（锁定）
> ② 社保        ← 次月 10-25 日申报缴纳（次月缴上月）
>       ↓   电子税务局带出【个人应缴额】→ 个人 766.35（锁定）
> ③ 个税试算    ← 扣缴端试算本月应扣税额（发放前，仅为算实发）
>       ↓   锁定 → 个税 0.00
> ④ 发工资      ← 对公账户 → 个人卡转账
>      实发 5,393.65 = 应发 7,000 − 社保 766.35 − 公积金 840.00 − 个税 0.00
> ⑤ 个税申报    ← 发放【次月 1-15 日】正式申报缴款（属期 = 实际发放月）
> ```
>
> 📌 **每走完一步 → 立刻登记一行到 [账本 §0.5「每月实缴登记表」](2-beijing-company-accounting-ledger.md)**（约 20 秒）。表里写明了**每一步"从哪个网站抄哪个数"**，以及空白行模板。**不要等月末再回忆** —— 2026 年 8 月那次整批返工，源头就是"实际数"没有登记点、只能靠推算。
>
> 🔴 **为什么不能颠倒**：`实发 = 应发 − 个人社保 − 个人公积金 − 个税`，**四个扣项全部锁定后才能转账**。任一项未确认就先发钱 = 金额发错 = 工资表 / 记账凭证 / 日记账 / 报表**全部返工**。
>
> 🔴 **反面教材（2026 年 8 月实际踩的坑）**：公积金个人部分**未等实际托收**，先按网厅查询页默认基数 6,326×12% = **759.12** 推算 → 实际托收 **840.00** → 连锁错误：个人扣项 1,525.47→1,606.35、应实发 5,474.53→5,393.65、账本余额 25,142.32→24,980.56，**整批返工**。
> ✅ **杜绝办法**：一律以**网厅 / 电子税务局 / 银行的实际数**为准 —— **不自算、不推算、不提前估数入账**。
>
> ⚠️ **两个体系别混**：**公积金＝当月托收当月**（8/31 扣 8 月）；**社保＝次月申报上月**（9/10-25 缴 8 月）。
> ⚠️ **个税拆两步别混**：**发放前「试算」**（扣缴端测算扣多少，为算实发）、**发放后「申报」**（次月 1-15 日正式申报缴款）。**个税属期 = 实际发放月，不是工资所属月** —— 8 月工资 9 月发，属期是 **9 月**（10/1-15 申报），不是 8 月。
>
> ⚠️ **一个尚未解决的时序冲突**：现行"**每月 10 日发上月工资**"与"**10-25 日申报上月社保**"同日启动 —— 若社保拖到 10 日之后才缴，则发薪时个人社保额**尚未确认**（顺序里 ② 没走完就跳 ④）。**建议把发薪日改到每月 15-20 日**（社保缴完后），使数据链完整、零返工。
>
> 📌 **季度提醒**：季报（增值税+企税+附加税）在**次季首月 15 日前**，与月度链路并行，勿遗漏。

#### 法人签"设计师"合同的合规性说明

| 常见疑问 | 解答 |
|---------|------|
| **法人能当员工吗？** | ✅ 完全可以。法定代表人与公司是劳动关系，可以签劳动合同、缴社保。这是合法且常见的操作（尤其是小微企业的创始人兼员工）。 |
| **法人签"设计师"不签"总经理"合理吗？** | ✅ 合理。岗位名称应**匹配实际工作内容和公司业务**。公司主营"文艺创作与表演"，设计师完全对口。7000元设计师月薪是市场合理水平，不会引起社保基数质疑。 |
| **为什么不签"总经理"？** | 7000元月薪的总经理在北京明显偏低，可能触发社保审计疑问。总经理更适合公司规模扩大后设立。 |
| **没有其他员工怎么办？** | ✅ 完全合规。小微企业常见情况——法人一人兼多职（设计师+行政），正常签合同缴社保即可。不强制要求必须有多个员工。 |

> **合同关键字段**：乙方岗位填"**设计师**"（或"创意设计师"），部门"设计部"，月薪7000元（税前），合同期3年（2026-08-01至2029-07-31），试用期"0个月"。

#### 纸质合同 vs 电子合同（结论：用纸质即可）

| 维度 | 纸质合同 | 电子合同 |
|------|---------|---------|
| 法律效力 | ✅ 完全有效 | ✅ 完全有效（《电子签名法》认可） |
| 适用场景 | 夫妻店当面签 | 大公司远程签约 |
| 成本 | 打印签字即可 | 需第三方电子签平台（e签宝/法大大），要认证+可能收费 |
| 麻烦程度 | 低 | 高（实名认证+电子签章） |

> **结论：直接用纸质合同，无需电子合同。** 薛燕是爱人，当面签字几秒钟的事，不需要远程签约场景；纸质和电子法律效力完全相同，社保/公积金/个税只认"真实劳动关系"，不认合同形式。
> ⚠️ **关于之前误选**：社保增员时误选了"是否已签订电子劳动合同=是"，此字段仅系统信息登记，**不影响社保/公积金/个税任何权益**。若系统后续要求上传电子合同文件，可直接上传纸质合同扫描件/照片应付，或忽略。

##### 个税"累计预扣法"说明（重要）

> ⚠️ 工资薪金个税不是每月单独算，而是**按当年累计预扣**。原理如下：

```
累计应纳税所得额 = 累计收入 − 累计免征额(5000×已工作月数) − 累计社保公积金
累计个税 = 累计应纳税所得额 × 税率 − 速算扣除数
本月应扣个税 = 累计个税 − 已累计预扣个税
```

**税率表（综合所得，按累计应纳税所得额）：**

| 累计应纳税所得额 | 税率 | 速算扣除数 |
|:---:|:---:|:---:|
| ≤36,000 | 3% | 0 |
| 36,000~144,000 | 10% | 2,520 |
| 144,000~300,000 | 20% | 16,920 |
| ... | ... | ... |

> **薛燕的具体情况（正常年份口径，2027 年起）**：月薪7000，每月累计应税所得增加约 **393.65 元**（5000免征+社保766.35+公积金840.00后），全年累计仅 393.65×12 ≈ **4,723.80 元**，**远低于 36,000，全年停留 3% 档**，所以个税每月固定 **11.81 元**（全年 **141.71 元**）。
> 🔴 **2026 年不适用**：全年只发 5 个月工资（8–12 月），且 7 月入职登记多占一次 5,000 减除额 → **8–9 月属期累计应纳税所得额为负、10 月起转正** → 全年个税 **29.05 元**（全靠 10 月属期那笔奖金起头；见下方 2026 年专属口径表）。
> ⚠️ **但这是"低工资的巧合"，不是规律**。若未来薛燕工资涨到 2 万+、或有年终奖，累计应税所得可能跨入 10% 档，个税会在跨档当月**跳变**，届时不能照抄上月数字，必须用累计预扣法重新算。

##### 发工资操作方式（手动转账）

> 工行对公账户无便捷的"定期代发"自动化功能，且只有 1 名员工，**手动转账发工资最合适**，每月 2 分钟。

**每月 10 日手动发工资操作：**

```
1. 登录工行企业网银
2. 转账：对公账户 → 薛燕个人卡
3. 金额：**按当月工资表实发数**（8 月 **5,393.65**，⏳ 尚未发放；**10/10 = 9,388.22**），精确到分
4. 备注：X月工资（务必写清"工资"用途）
5. 确认转账
```

**手动发工资的好处（对 1 人场景）：**

| 优势 | 说明 |
|------|------|
| 简单 | 每月 2 分钟，不用研究银行功能 |
| 可控 | 转账时能看到余额，防止余额不足 |
| 灵活 | 金额随时可改（社保基数7月调整后直接改数字） |
| 留痕清晰 | 备注"X月工资"，银行流水明确 |

**⚠️ 三项硬性要求：**

| 事项 | 说明 |
|------|:---:|
| 走对公账户→个人卡 | ⭐⭐⭐ 严禁现金或私人账户转 |
| 备注写"工资" | 银行流水要清晰体现工资用途 |

> 结论：**手动转账发工资即可，无需自动化**。报税和记账本来就手动，发工资手动也不增加多少负担。

## 二、社保增员前置条件：上家公司必须已减员

**规则**：同一人在北京（同一社保统筹区），**必须"先减后增"**——上一家公司减员成功后，新公司才能增员。

| 状态 | 说明 |
|------|------|
| 上家**已减员**（显示"暂停参保"或"终止"） | ✅ 可以直接增员 |
| 上家**未减员**（显示"正常参保"） | ❌ 系统提示"该人员已在其他单位参保"，无法提交 |

**快速自查**：爱人登录**"北京人社"APP** → 查社保状态：
- "正常参保" → 还没减员 → 催上家 HR 尽快操作（减员只需几分钟，当天或次日生效）
- "暂停参保"或"终止" → 已减员 → 你可以增员了

> ⚠️ **这是社保增员的前提条件，必须在操作前确认。** 跨省/跨统筹区则不需要减员，直接在新参保地增员即可。

## 三、经营收入与收款码（布艺市集）

长期纯零收入公司容易触发"长亏不倒"稽查风险。爱人做布艺手作本来就打算创业，**线下市集、朋友圈、闲鱼的收入走公司账户**，一举多得：

| 好处 | 说明 |
|------|------|
| **让公司"真经营"** | 有真实收入流水，摆脱纯壳公司嫌疑 |
| **收入不用多** | 每月几千块就足够证明公司活跃 |
| **公司可开发票** | 如果是正规客户可以开票（小规模纳税人，税率低） |
| **收入可抵成本** | 材料采购、摊位费计入公司成本，不浪费 |
| **社保基数更合理** | 有收入后，按最低基数交社保更有说服力 |
| **为创业铺路** | 平台建好了，后续直接放大经营 |

**线下收款方案：必须用商家码，别用个人码**。

| 方式 | 费率 | 风险 |
|------|:--:|------|
| **公司商家收款码** | 0.38%（月收5000仅19元） | ✅ 合规，直接入对公账户 |
| 个人码→转公司账户 | 0 | ❌ **2026年严查**，公私混同+隐匿收入嫌疑 |

> ⚠️ 金税四期下，个人码收经营款已是稽查重点，有企业因此被罚几十万。**每月几块钱手续费，买的是合规和安全，绝对不能省。** 营业执照下来后去微信支付商户平台申请即可。

##### 信用卡/花呗收款关闭方法（深度研究）

> 信用卡/花呗费率更高（微信0.5%、支付宝花呗0.8%），能否关闭？结论是**分产品、有技巧**：

| 收款产品 | 能否关闭信用卡 | 方法 |
|---------|:---:|------|
| 支付宝「个人收钱码」 | ✅ 能 | 设置里直接关"信用卡收钱" |
| 支付宝「商家经营版」 | ⚠️ 间接可关 | **关闭"花呗收款"→ 信用卡收款自动停止**（可逆） |
| 微信「个人收款码」 | ✅ 天然不支持 | 2022年后个人码已停止信用卡收款 |
| 微信「商家经营码」 | ⚠️ 需客服/技术接口 | 商户平台无直接开关 |
| 工行 e 支付聚合码 | ❓ 需单独咨询 | 能否关闭信用卡通道需问银行 |

**支付宝关闭花呗/信用卡的隐藏技巧（可逆）：**

```
支付宝 → 搜索框输入"花呗收款" → 进入"花呗收钱服务"
→ 把右侧蓝色开关滑到灰色 → 提示"关闭成功"
→ 信用卡收款功能随之自动停止 ✅
→ 以后想恢复，重新打开花呗收款即可
```

**⚠️ 但要权衡（批判性）：**

| 关闭信用卡的利 | 关闭信用卡的弊 |
|--------------|--------------|
| 省下 0.5%~0.8% 手续费 | 部分客户习惯刷信用卡，可能不买 |
| 收款全是零钱/借记卡，费率低 | 客单价高时，客户可能想刷信用卡分期 |
| 账目简单 | 丢失"能用信用卡"的成交机会 |

> 💡 **关键判断依据——客单价**：
> - 客单价**几十元**（小布偶、挂件）→ 客户基本不用信用卡，**建议关闭**，省手续费
> - 客单价**几百上千**（大件手工品）→ 客户可能想刷信用卡，**保留更利于成交**
> 
> 建议：先申请收款码，观察实际客单价和信用卡占比，再决定是否关闭花呗收款。这个开关可逆，随时可调。

### 4.2 每月 / 每季度报税节奏

| 时间 | 操作 | 责任方 |
|:-----|:-----|:------:|
| **每月10日前** | 个人记账公司完成上月个税申报（工资薪金代扣代缴） | 个人记账 |
| **每月15日前** | 个税扣缴（自动从对公账户） | 公司 |
| **每季度15日前**（4月/7月/10月/1月） | 增值税零申报 + 城建税 + 教育费附加 + 地方教育附加 + 企业所得税 | 个人记账 |
| **次年1月1日-3月31日** | 上年度企业所得税汇算清缴 | 个人记账 |
| **次年3月1日-6月30日** | 工商年报 | 个人记账 |
| **次年3月1日-5月31日** | 上年度个人所得税年度汇算（个税APP办理） | 法人/员工本人 |
| **次年9月30日前** | 残疾人就业保障金申报 | 个人记账 |

### 4.3 关键解读

| 税种 | 关键点 |
|:-----|:-------|
| **个税** | **唯一月报**，每月扣缴工资薪金。**个税金额不能为零**（否则摇号资格不认） |
| **增值税** | 小规模纳税人按3%简易征收（如无业务做零申报）。季度销售额≤30万免征 |
| **企业所得税** | 季度预缴，年度汇算。小微企业（年利润≤300万）可享5%/10%优惠税率 |
| **城建税+教育费附加+地方教育附加** | 自动随增值税申报，**增值税为0时这三项也为0** |
| **残保金** | 即使公司无残疾人也要申报（按应安置人数计算，0人也可能需申报） |
| **文化服务税率** | 日常业务为"组织文化艺术交流活动"等→走文化服务 3% 征收率 |
