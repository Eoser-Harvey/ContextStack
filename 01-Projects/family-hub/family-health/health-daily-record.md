## 三、基于基因+体检的双方日常食谱与补充剂方案

> 本节从"备孕专属"扩展为**日常长期健康管理**：所有建议均锚定双方 WeGene 基因位点 + 薛燕 2025-10 体检异常项（甲状腺结节、宫颈炎症、BMI 24.6、AST/ALT 升高、窦性心动过缓等）。每日打卡见第一/二节；此处是"为什么这么吃、这么补"的依据与可执行食谱。备孕只是这套方案的**子集**，不是起点。

### 3.1 双方营养基因画像（吃的根基）

| 共同特征 | 基因型 / 依据 | 饮食含义 |
|---|---|---|
| 乳糖代谢弱 | 双方 MCM6 CC/GG | 纯牛奶→腹胀腹泻，用舒化奶/酸奶/奶酪 |
| 叶酸通路受损 | 韩 MTHFR C677T AG + MTHFD1 AG + TCN2 CG；薛 MTRR GG + MTHFD1×2 + TCN2 CG | 同型半胱氨酸管理，每日活性叶酸 + 甲钴胺 |
| 锌需求高 | 双方评分"高" | 每周 2-3 次牡蛎/牛肉/南瓜子 |
| 维 A 需求高 | 双方评分"高" | 猪肝/胡萝卜/南瓜/蛋黄 |
| 维 K 需求高 | 双方；韩 VKORC1 TT | 绿叶菜/西兰花；韩避免 K2 补充剂过量 |
| 维 D 需求稍高 | 双方；薛 VDR FokI 杂合 | 日晒 + D3 2000 IU |
| PAI-1 4G/4G | 双方 SERPINE1 AA | 血液偏稠：多饮水、控脂、避免久坐 |
| 解毒酶弱 | 双方 GSTP1 弱（韩 AA / 薛 AG） | 避二手烟/甲醛/化学暴露 |
| 口腔/鼻咽癌风险 | 薛口腔癌 10.16x；韩鼻咽癌 4.69x | 避过烫(>60°C)、腌制/咸鱼/加工肉 |

### 3.2 每日食谱框架（地中海抗炎基底 + 个性化修正）

**结构原则**：三餐定时（韩克罗恩 7.58x、薛胆结石 1.35x 均需按时进餐）→ 低血糖负荷（薛 PCOS 1.55x / 肥胖 2.24x）→ 高蔬果深海鱼（双方抗炎）→ 乳糖友好 + 锌/维A/叶酸强化。

| 餐次 | 模板（双方通用） | 关键依据 |
|---|---|---|
| 早餐 7-8 点 | 舒化奶/无糖酸奶 + 燕麦/全麦 + 鸡蛋 1 个 + 牛油果/坚果 1 把 + 焯水菠菜/西兰花 | 乳糖弱→舒化奶；PEMT→鸡蛋胆碱；叶酸/维A→深绿菜+牛油果；维E/镁→坚果 |
| 午餐（带便当） | 杂粮饭 + 深海鱼(三文鱼/沙丁鱼)或鸡胸/瘦牛肉 + 双份蔬菜(绿叶+彩椒番茄) + 橄榄油凉拌 | 低 GI(薛 PCOS)；Omega-3 抗炎(双方)；控盐(韩高血压)；补钾(香蕉/土豆/菠菜) |
| 晚餐（18 点前吃完） | 豆腐/豆制品 + 蔬菜 + 少量杂粮；韩加牡蛎/牛肉补锌，薛控量低脂 | GERD(韩/薛反流)：睡前 3h 不进食；韩控嘌呤 |
| 加餐 | 南瓜子/腰果(锌)、蓝莓/草莓(抗氧化)、猕猴桃/柑橘(维C)、大蒜洋葱凉拌 | 黏膜免疫(韩上火)；口腔癌抗氧化；锌需求 |

**每周必吃轮换**：牡蛎/牛肉/南瓜子(锌，2-3 次)、猪肝/胡萝卜/南瓜(维A，2-3 次；薛燕不过量)、深海鱼(Omega-3，2-3 次)、酸奶/奶酪(钙+乳糖友好，每日)、豆制品(胆碱/植物蛋白)、深绿叶菜(维K/叶酸，每日)、大蒜洋葱(抗菌抗炎，韩刻意加)。

**每日必避**：过烫 >60°C(双方口腔/鼻咽)、啤酒(韩痛风双重打击)、加工肉/咸鱼腌制(鼻咽癌/食管癌/口腔癌)、含糖饮料(韩尿酸/薛 PCOS)、外卖高油盐(韩血压/薛反流胆结石)。
