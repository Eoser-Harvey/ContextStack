**症状分析（2026-07-02）：**

两项症状高度关联，综合判断 → **胃食管反流病（GERD）可能性大**，但需排除其他原因。

**分析逻辑：**

| 症状 | 可能原因 | 与基因关联 | 可能性 |
|---|---|---|---|
| 口气重（半年） | ① **胃食管反流**：夜间胃酸反流至口腔，产生硫化物异味 | 克罗恩病 7.58x 提示消化道整体易感 | 高 |
| | ② 牙周炎/口腔问题 | 牙周炎 1.05x | 中 |
| | ③ 幽门螺杆菌感染 | 无直接基因提示 | 中 |
| | ④ 鼻咽/鼻窦问题 | 鼻咽癌 4.69x（但口臭非典型症状） | 低 |
| 晨起食道堵塞感（一周） | ① **胃食管反流**：卧位时胃酸反流刺激食管，产生异物感/烧心感 | 经典 GERD 症状 | **最高** |
| | ② 克罗恩病上消化道累及 | 克罗恩病 7.58x | 需警惕 |
| | ③ 食管炎 | 胃酸反复刺激导致 | 中 |

**关键线索**：消化药有效 → 指向酸相关疾病（GERD），而非结构性病变。

**建议处理：**

| 优先级 | 行动 | 说明 |
|---|---|---|
| **立即** | 睡前 3 小时不进食，枕头垫高 15-20cm | 减少夜间反流 |
| **立即** | 避免辛辣、油腻、咖啡、巧克力、薄荷 | 放松食管下括约肌的食物 |
| **立即** | 戒酒（尤其睡前） | 酒精加重反流 |
| **1 周内** | 消化内科就诊，考虑胃镜 | 排除克罗恩病上消化道累及 + 食管炎 + 幽门螺杆菌 |
| **1 周内** | 口腔检查 | 排除牙周炎导致的口臭 |
| **持续** | 如确诊 GERD，PPI 类药物（奥美拉唑等） | 注意：CYP2C19 *1/*2 中间代谢，可能需要调整剂量 |

> ⚠️ 特别提醒：克罗恩病 7.58x，食道症状也可能是克罗恩病的上消化道表现。消化内科就诊时务必告知医生克罗恩病遗传高风险，建议胃镜+活检。
