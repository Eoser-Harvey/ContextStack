## 一、体检方法论（王立铭 — 基于特朗普体检报告）

### 体检的四个核心原则

> 特朗普享受地球上最优越的医疗支持，他的体检套餐由专家基于科学证据制定。从他的报告出发，可以帮普通人理解体检的真正价值。

#### 原则一：检查并非越先进越好

| 检查 | 更先进方案 | 为什么不用更先进的 |
|------|-----------|-------------------|
| 低剂量胸部CT | X光胸片 | CT分辨率高，能识别早期肺癌（可微创治愈）；X光发现时往往是中晚期 |
| 腹部超声 | CT/核磁 | 超声已能判断内脏形态异常和肿瘤，且无辐射、更便宜 |
| 肠镜 | — | 侵入式+麻醉，息肉癌化需5-15年，几年一次即可 |

> **结论**: 一国总统都没有盲目使用最先进技术，普通人更没必要。

#### 原则二：检查并非越频繁越好

| 检查 | 科学频率 | 依据 |
|------|---------|------|
| 肠镜 | 正常→10年/次；1-2个息肉→5-7年/次 | 息肉癌化需5-15年，频繁做收益风险不平衡 |
| 颈动脉超声 | 正常→几年一次即可 | 风险主要来自血脂指标，已服药控制则无需每年查 |

> 特朗普2024年7月肠镜正常，医生建议3年后（2027年）再做。颈动脉超声去年正常，今年就免了。

#### 原则三：检查项目并非越多越好

**肿瘤标志物的真相（重要！）**

| 标志物 | 假阳性率 | 假阴性率 | 实际价值 |
|--------|---------|---------|---------|
| **PSA抗原**（前列腺） | 若4-10ng/ml，仅25%确诊为癌 | — | **唯一相对靠谱的**，但仍有争议 |
| **CEA**（癌胚抗原） | ~15% | ~30% | **基本无参考价值**，异常时患癌概率<1% |
| 其他常见标志物 | 大多类似CEA | 大多类似CEA | 不推荐常规体检查 |

> **医学界主流看法**: 不建议在无特殊原因时查大量肿瘤标志物。浪费钱不说，异常了你会担惊受怕、吃不下睡不着，然后做更多检查来排除——这些检查本身可能带来额外风险。

#### 原则四：体检需要定制化

根据不同人群增加针对性项目：

| 人群 | 加查项目 | 原因 |
|------|---------|------|
| 60岁以上 | 散瞳眼底检查 | 年龄相关黄斑变性、视网膜脱离风险 |
| 高度近视 | 散瞳眼底检查 | 比普通人更易患眼科疾病 |
| 年长者 | MoCA认知评估、PHQ-9/GAD7情绪量表 | 阿尔茨海默病早期筛查 |

### 体重骤降的警示（重要）

**如果体重在未刻意减肥的情况下突然下降，需警惕：**
- 肿瘤生长消耗营养
- 消化系统疾病（营养吸收障碍）
- 精神疾病（焦虑/抑郁影响体重）

> 同理，视力和视野的快速下降也可能是黄斑变性、白内障、青光眼的先兆。

## 二、血脂指标详解（新增）

特朗普服用他汀类药物+依折麦布控制血脂，因为他知道血脂与心脑血管的因果关系。

| 指标 | 含义 | 目标 |
|------|------|------|
| **总胆固醇** | 血液中胆固醇总量 | 低一些好 |
| **甘油三酯** | 血液中脂肪分子 | 低一些好 |
| **低密度脂蛋白(LDL)** | "坏胆固醇"，运输胆固醇到全身 | 越低越好 |
| **高密度脂蛋白(HDL)** | "好胆固醇"，从血管回收胆固醇 | 越高越好 |

> 血脂异常直接导致中风、冠心病等心脑血管疾病。常规检查+及时用药干预，健康获益非常明确。

## 三、体检数据背景（半佛仙人）

**2020年百万人体检数据（北京）**

| 异常指标 | 异常率 |
|----------|--------|
| 甲状腺结节 | 59.9% |
| 颈椎异常 | 57% |
| 超重/肥胖 | 51.6% |
| 脂肪肝 | 43.2% |
| 幽门螺杆菌阳性 | 36.6% |
| 血脂异常 | ~10% |

> 每年约3%的人需要手术，多数为甲状腺结节、胆囊息肉、乳腺结节等小手术。**体检发现异常不要过度焦虑，大多数观察即可。**

## 四、分年龄段体检重点

### 🟡 20岁+ — 查代谢 + 传染病

| 项目 | 说明 |
|------|------|
| 空腹血糖 + 餐后血糖 | 10%年轻人已异常 |
| 肝功能 | 转氨酶、胆红素 |
| 幽门螺杆菌检测 | 胃癌一级致癌因子 |
| 腹部彩超 | 肝胆脾胰 |
| 甲状腺彩超 | 结节检出率50%+ |
| **低剂量胸部CT** | 代替X光胸片（王立铭推荐） |
| 糖化血红蛋白（有家族史）| — |

### 🟠 30岁+ — 查结节 + 心血管萌芽

| 项目 | 说明 |
|------|------|
| 甲状腺彩超 | 每年必查 |
| 乳腺彩超（女）/ 前列腺彩超（男）| 每年必查 |
| 颈椎 + 腰椎 MRI | 久坐人群必查 |
| 同型半胱氨酸 | 心血管早期指标 |
| 颈动脉彩超 | 血管斑块筛查（正常则几年一次即可） |
| ⚠️ ~~肿瘤标志物~~ | **不推荐常规查**（见原则三） |
| 心脏彩超（有家族史）| — |
| 冠脉CT（有家族史）| — |

### 🔴 40岁+ — 查心脏 + 癌症早筛

| 项目 | 说明 |
|------|------|
| 心脏彩超 | 40岁后心脏开始老化 |
| 冠脉CT或冠脉造影 | 高危人群 |
| 胃肠镜 | 消化道癌症筛查金标准 |
| 低剂量胸部CT | 肺癌筛查 |
| 骨密度检测 | 骨质疏松 |
| 颈动脉彩超 | 斑块监测 |
| PSA抗原（男） | 唯一相对靠谱的肿瘤标志物 |

**女性加查**: HPV+TCT（宫颈癌筛查）、乳腺钼靶或MRI
**男性加查**: 前列腺特异性抗原（PSA），仅此一项

## 五、体检频率建议（修订版）

| 年龄段 | 体检频率 | 说明 |
|--------|----------|------|
| 20-30岁 | 每1-2年 | 基础套餐 |
| 30-40岁 | 每年1次 | 常规+专项 |
| 40-50岁 | 每年1次 | 全面深度 |
| 50岁+ | 每年1-2次 | 全面+专项复查 |

| 专项检查 | 频率 | 依据 |
|---------|------|------|
| 肠镜 | 正常→10年/次；有息肉→5-7年/次 | 息肉癌化需5-15年 |
| 颈动脉超声 | 正常→几年一次 | 风险主要来自血脂 |
| 散瞳眼底 | 60岁+或高度近视→每年或每2年 | 美国眼科研究所建议 |

## 六、专项筛查建议

### 有家族史必查

| 疾病家族史 | 筛查项目 |
|------------|----------|
| 高血压 | 24小时动态血压、心脏彩超、肾功能 |
| 糖尿病 | 糖化血红蛋白、胰岛素释放试验 |
| 心脑血管疾病 | 颈动脉彩超、心脏彩超、冠脉CT |
| 肿瘤 | 对应部位影像（⚠️ 不是肿瘤标志物） |
| 消化道疾病 | 胃肠镜（40岁前做一次） |

### 高危职业加查

| 职业特点 | 加查项目 |
|----------|----------|
| 久坐办公 | 颈椎/腰椎MRI、下肢静脉超声 |
| 熬夜频繁 | 肝功能、心电图、甲状腺功能 |
| 应酬多 | 肝功能、胃镜、幽门螺杆菌 |
| 压力大 | 甲状腺功能、心电图、**PHQ-9/GAD7情绪量表** |

## 七、体检前注意事项

1. **空腹8-12小时** — 抽血、腹部彩超需空腹
2. **避开月经期** — 妇科检查、尿常规
3. **停药咨询** — 高血压药可服，降糖药需问医生
4. **穿着宽松** — 方便检查
5. **带齐资料** — 既往体检报告、病历、用药清单
6. **关注变化趋势** — 年度对比比单次绝对值更有意义（王立铭强调）

## 八、给韩伟的个性化建议（2026年更新）

> 32岁、技术行业、已婚、久坐办公、高度近视

### 优先级 P0（今年必做）

- [ ] 甲状腺彩超（结节高发，关注家族史）
- [ ] 幽门螺杆菌检测 + 胃肠镜（40岁前做一次基线）
- [ ] 颈椎/腰椎 MRI（久坐办公）
- [ ] 同型半胱氨酸 + 颈动脉彩超（心血管基线）
- [ ] **散瞳眼底检查**（高度近视，新增）
- [ ] 血脂全套（总胆固醇/甘油三酯/HDL/LDL — 基线数据）

### 优先级 P1（建议加做）

- [ ] 糖化血红蛋白（代谢基础）
- [ ] 心脏彩超（基线数据）
- [ ] ~~肿瘤标志物~~ **取消**（依据王立铭分析，CEA假阳性15%假阴性30%，基本无参考价值）

### 备孕相关

- [ ] 优生优育检查（TORCH、精液分析）
- [ ] 传染病筛查（乙肝、梅毒、HIV）

### 长期健康习惯（参考特朗普）

- [ ] 不抽烟、少喝酒（特朗普完全禁绝）
- [ ] 保持运动习惯（特朗普打高尔夫）
- [ ] 根据体检结果及时干预（用药/生活方式）
- [ ] 接种推荐疫苗

## 九、给爱人/父母的建议

### 爱人（女性）

- 乳腺彩超（每年）→ 40岁后改用乳腺钼靶
- HPV+TCT（宫颈癌筛查）
- 甲状腺彩超（女性结节率更高）

### 父母（50岁+）

- 低剂量胸部CT（肺癌筛查，代替X光）
- 胃肠镜（消化道癌症筛查金标准）
- 心脏彩超 + 颈动脉彩超（心脑血管）
- 骨密度检测（骨质疏松）
- **散瞳眼底检查**（60岁以上，美国眼科研究所建议）
- PSA抗原（父亲，唯一靠谱的肿瘤标志物）
- 每年体检1-2次，关注指标变化趋势
