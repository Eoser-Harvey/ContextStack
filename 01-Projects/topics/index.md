# 话题工作台

这个文件夹存放技术话题和讨论记录的工作台文件。

## 关键文件

- [[TSN-protocol-analysis]] - TSN协议分析：时间敏感网络协议技术分析
- [[switch-pbr-analysis]] - 交换机PBR功能分析：策略路由在IPv4/IPv6/双栈环境的应用

## 话题内容

- **TSN协议分析**: TSN协议栈、配置方法、问题排查经验
- **交换机PBR功能分析**: 策略路由原理、IPv4/IPv6对比、双栈环境配置策略

## 工作台功能

- **技术讨论记录**: 记录技术讨论的过程和结论
- **问题分析**: 系统化分析技术问题
- **方案评估**: 评估不同技术方案的优缺点
- **知识积累**: 将讨论结果转化为可复用的知识

## 使用方法

1. 开始新技术讨论时创建话题工作台
2. 记录讨论过程、关键观点、结论
3. 整理相关参考资料和链接
4. 讨论结束后归档到相应目录
